# 《Calradian Kings》英文仓库梳理与证据边界（修订版）

先民、卡拉狄乌斯、城市起源、政治阶段与年代线索

材料性质：社区二创文本的来源审阅，不是原有设定的补充权威。

# 摘要：原有设定的稀疏与模糊必须保留

本底稿审阅《Calradian Kings》英文公开仓库中的文化描述、事件文本、建筑说明、朝圣文本、人物数据和书签简介。该仓库是社区二创作品，其中大量具体历史内容属于创作者自行补写。它可以提供民族分布、政治地理和历史过程的参考构想，但不能被当作原有卡拉迪亚设定已经明确记载的内容。

关键原则：原有设定没有明确说明的地方，不会因为二创文本写得更具体、更连贯，就自动得到答案。以下始终区分三层：原有设定可明确支持的内容；社区二创新增的叙述；研究者为解释历史提出的假说。现有材料无法支持的细节，必须保留为空白。

# 一、证据层次与使用原则

A｜原有设定：必须能在原有游戏文本或相关世界观材料中找到明确出处。逐条注明原始出处；不因二创重复就视为已获支持。

B｜社区二创：二创作者补写的年代、人物、战争、迁徙、民族支系、制度细节及因果解释。准确记录为该作品的主张；用于发现线索，不直接当作卡拉迪亚史实。

C｜研究假说：基于有限材料、逻辑推理与现实历史比较提出的解释。说明推理过程、替代解释与不确定性，不得倒写成原始记载。

D｜未完成／技术字段：被注释的文本、Placeholder、代码中的 created 日期等。除非确认其语义与用途，否则只作为待查线索。

原有设定没有明确记载某件事，不等于该事必然没有发生；但也不等于可以接受二创作者补写的版本。正确做法是把它列为开放问题，评估证据实际能支持到什么程度。

# 二、主要历史主题：二创文本说了什么，又不能证明什么

## 2.1 卡拉狄乌斯与早期政治共同体

仓库构造了一个政治阶段序列：卡拉狄乌斯率领流亡者进入卡拉迪亚；其王国后来演变为共和国；共和国之后出现帝国。另一段被注释的 Tekrean 文化描述草稿，补写了先到纳哈萨西岸、与当地首领冲突、再北上进入 Charasea 的路线。

证据边界：王国—共和国—帝国是该二创作品采用的历史框架，不能仅凭自身证明原有设定已经给出同样完整的制度史。纳哈萨—Charasea 路线来自被注释的未完成草稿，证据地位更低。现有材料不足以确定卡拉狄乌斯的出生、出发、首次登陆、建国或死亡年份，也不足以重建王国转为共和国的具体过程。

研究问题：登陆地点、第一处稳定聚落、第一块殖民地、早期政治中心与后世首都是否相同？这些概念可以重合，也可以不同，不能先验合并。

## 2.2 Charas 与 Charasea

仓库称 Charas 有卡拉狄乌斯圣殿和墓葬；一条建筑说明称，大图书馆由其曾孙 Alcarys 在卡拉狄乌斯死后第一个百年内建立；Pamphia 文化描述又把 Charas 写成财富集中的贸易中心。Charasea 则出现在登陆草稿及相关朝圣文本中。

这些内容能说明的是：二创作品赋予 Charas 纪念、宗教、文化与商业地位。它们不能证明 Charas 是第一登陆点、第一座殖民城市或最初首都。Charas 与 Charasea 是否异名、城与区域的关系如何，现有文本也没有充分解释。圣地、贸易中心、首都和登陆点不得视为同义概念。

## 2.3 巴旦尼亚人、帕拉人及大陆先民

仓库把巴旦尼亚人置于卡拉迪亚西北部丘陵与森林，并把他们与帕拉人描述为卡拉狄乌斯到来前已存在的居民；它将 Palaic 解释为帝国对多个原生部族的统称，并补写米泽亚、拉革塔、德律阿提亚、阿米塔泰等群体的不同命运。

可借鉴的结构性问题是：卡拉狄乌斯到来前，大陆是否存在多个居民群体、地方政治共同体和不同文化区域；扩张是否可能同时涉及征服、吸纳、文化替代、人口散居与混合。不能直接断言这些二创名称、支系边界、分布与具体遭遇已经属于原有设定。也不能把“帕拉人”不加区分地写成拥有统一语言、国家和自我认同的单一民族。

## 2.4 南方城邦、贸易与帝国整合

Pamphia 叙述强调东西贸易、早期殖民地、Charas 的财富集中与地区自治；Penthian 叙述构造了卡拉德商人与塔纳埃西斯湖沿岸居民接触、定居、控制贸易路线并将城邦纳入附庸关系的过程。

这些内容应转化为问题：贸易网络是否可能先于军事统治？商人定居如何影响地方社会？帝国是否对不同地区采用不同整合方式？它们不能证明上述过程在原有历史中必然以同样方式发生。

# 三、时间线：具体日期不等于可靠年代

下列日期只记录二创仓库中的主张。日期精确不代表历史可靠；代码中的文化 created 日期尤其不能直接等同于民族形成、征服、迁徙或合邦的发生日期。

• 卡拉狄乌斯时代（无绝对年份）：流亡者登陆、王国建立、后世在 Charas 纪念卡拉狄乌斯。处理：记录为二创总体叙事，不推定绝对年代。

• 卡拉狄乌斯死后百年内：曾孙 Alcarys 建立沙拉斯大图书馆。处理：二创建筑说明的相对年代，不能反推城市建成年份。

• 442.9.23：文化定义文件中 Lagetan 的 created 日期。处理：技术性日期，不直接视为征服或民族形成日期。

• 477 年：Catomenys 被描述为共和国之后的第一位皇帝。处理：二创内部年代设定，不作为确定史实锚点。

• 约 500 年：卡拉德商人与塔纳埃西斯湖沿岸城邦贸易，后续出现定居与帝国控制。处理：宽泛的二创阶段设想，需独立论证。

• 580.6.11：文化定义文件中 Myzead 的 created 日期。处理：不等于合邦日期或群体起源日期。

• 976、1084、1257 年：分别以叛乱与宗教冲突、继承争端、帝国遗产为书签背景。处理：二创作品的局势节点，不补写未被材料支持的中间史。

仓库内部存在值得保留的张力：Lagetan 的文化数据日期早于该作品设定的 477 年首帝称帝，而相关描述又使用“帝国征服”措辞。在没有确认字段语义、版本与用词范围前，不应擅自改年，也不应编造解释来抹平矛盾。

# 四、卡拉狄乌斯的宗教化与创立者记忆

圣殿、墓葬、朝圣路线和纪念性建筑说明，使卡拉狄乌斯在二创作品中成为宗教与文化记忆的中心。这可引出政治共同体如何借助圣地、节庆、墓葬与起源传说塑造共同身份的问题。

但政治功绩的纪念、死后神圣化、圣地崇拜与生前正式神化是不同层次。仓库的宗教性措辞不足以单独证明卡拉狄乌斯生前被奉为神，也不能证明存在统一、制度化的皇帝崇拜。

# 五、对照纪律：不可从二创倒推原有设定

卡拉狄乌斯：二创把他描写为流亡者领袖和政治创立者；不能据此声称原有设定已确定其完整生平、登陆路线、建城顺序或死亡年份。

Charas／Charasea：二创赋予 Charas 圣地、图书馆和贸易中心等身份；不能据此断言 Charas 必然是第一登陆点、第一殖民地、首都，或 Charasea 必然是其异名。

大陆先民：二创构造了巴旦尼亚人、多个帕拉群体及其他地方社会并存的格局；不能据此断言原有设定已确认所有族群划分、分布边界、遭遇和年代。

共和国与帝国：二创提出王国—共和国—帝国的阶段序列；不能据此声称原有设定已说明共和国制度、权力结构、称帝过程与转型年份。

具体年份：仓库文本和代码包含精确日期；精确日期不等于独立史料价值，也不能自动填补原有设定的空白。

宗教与神化：二创描写圣殿、墓葬、朝圣和神圣化记忆；不能据此断言原有历史中必然存在生前神化或制度化皇帝崇拜。

# 六、这份资料对真正历史研究的用途

这份仓库最适合用来发现问题，而不是提供现成答案。可继续研究：早期居民与外来殖民者的关系；殖民聚落如何发展为政治中心；贸易网络与军事扩张的先后关系；地方社会被征服、吸纳或同化的不同路径；共和国与皇权的关系；以及创立者的身后记忆如何转化为宗教或政治合法性。

现实历史研究可以检验这些机制是否合理，并提供比较模型，但不能因为罗马、希腊或其他社会出现过某种制度，就断言卡拉迪亚必然采用同样制度。比较历史的作用是扩大解释选项、检验因果机制，而不是替卡拉迪亚决定事实。

进入正式论文的每项关键主张，都应说明：原有设定实际说了什么；二创文本添加了什么；研究者推断了什么；是否存在替代解释；哪些空白目前无法解决。

# 结论

对这份仓库最合适的态度，既不是因其属于二创而完全弃用，也不是因其具体而轻信。它提供的是创作者构想的历史地图，可帮助我们发现先民、殖民、贸易、地方政治与帝国扩张之间可能存在的联系；地图上的地名、边界、年份与事件仍须逐项核对。

原有卡拉迪亚设定的模糊性必须如实保留。更精细的历史叙事应明确标记为研究者提出的重建，而不是假装原始材料早已提供答案。真正的工作，是从二创文本中提出问题、比较解释、检验机制，并在证据不足时留下空白。
