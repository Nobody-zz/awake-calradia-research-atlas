# CHC-KAN-MAR｜坎族海上网络、殖民记忆与多语种沿海遗产（专题工作稿 v0.2｜2026-10-25）

研究状态：独立专题工作稿 v0.2。本文从阿塞莱国家形成研究中拆出，专门考察坎族（Kannic）在珀拉斯海沿岸文本中的海上活动、城市权力、文化记忆与语言遗存。依据为项目提供的 SandBox、NavalDLC 等模块 XML 及其语言表；不赋予 H 编号，不把游戏内叙事直接等同于现实历史。

## 一、研究问题与阶段结论

核心问题不是“坎族是否建立过一个帝国”，而是：现有游戏文本究竟以哪些不同方式呈现坎族的海上活动和历史记忆？跨五个 ZIP 内全部 XML 检索 Kannic 后，得到五条独立的文本记录：古亚兹的商业共和国叙述、拉齐赫的前帝国海上殖民传统、俄耳堤西亚的殖民地与城邦权威叙述、阿塞莱流浪者的水手背景，以及 NavalDLC 版本奥德律萨的多语种涂写描述。原始 Settlement 节点、英文语言表、简中语言表以及 SandBox／NavalDLC 的重复字符串会重复出现这些文本，不能把每次出现都算作独立见证。

最稳妥的阶段结论是：游戏文本描绘了一种沿珀拉斯海活动的坎族海上文化与政治网络。古亚兹是贸易和城邦权力的核心，拉齐赫承载前帝国海上殖民起源传说，俄耳堤西亚显示坎族城邦曾影响一处卡拉德殖民地，流浪者背景则把坎族血统与航海身份联系起来。NavalDLC 另有一个模块专属的奥德律萨版本，描写多语种岩刻，其中包括坎族语。以上材料支持“海上网络与多层文化记忆”，但不足以证明统一的坎族帝国、连续不变的民族共同体或完整的殖民制度。

（3）SandBox／town_EW4／字符串 ID JhBSnWAe：俄耳堤西亚与坎族城邦古亚兹之间的早期权威关系。

（4）NavalDLC／backstory_a.spc_wanderer_aserai_0n／字符串 ID RQsjEaaL：一名来自古亚兹的阿塞莱流浪者自述坎族血统与航海经历。

## 三、核心证据与源级判读

### 3.1 古亚兹：商业共和国、坎族语与统治精英更替

SandBox 的 town_A1 使用字符串 ID 1ImuW3My。英文称古亚兹曾是一个主导西部海洋与珀拉斯海之间贸易的商业共和国，使用一种濒临消亡、与纳哈撒语相近的坎族语；帝国霸权逐渐压缩其贸易，随后当地统治者被来自纳哈撒的雇佣兵接替，古亚兹过去还曾间歇性臣服帝国，如今则是阿塞莱苏丹国巴努·胡勒延的重要领地。原文有语法不规范之处（“the rulers was taken over by mercenaries from the Nahasa”），但 mercenaries 的含义明确，不能据此把他们译成商人。

这条材料同时给出四个层面：贸易网络、城邦政体、语言关系和军事精英更替。它并未说古亚兹统治所有坎族殖民地，也没有提到统一的坎族中央国家。官方简中语言表没有检出该描述的同键译文；项目提供的中文百科将 mercenaries 译为“商人”，属于参考译文中的语义错误，而不是已核实的官方同键简中译文。将其改回“雇佣兵”，会把故事从商业人员接管改回军事人员取代统治者，政治解释因此不同。

### 3.2 拉齐赫：前帝国殖民起源传说与符号的延续

SandBox 的 town_A4／jXBnf2hQ 把拉齐赫描述为坎族探险家向珀拉斯海沿岸殖民时据说使用的出发基地，时间被放在帝国到来之前的数个世纪。船首纹饰与一位兼司财富、葡萄酒、爱情和战争的坎族女神相联系。叙述接着说，坎族语已被纳哈撒方言取代，原有宗教几近被遗忘，但符号仍被认为能够保护那些为利益或荣耀押上一切的人。

这是一段带有传闻标记的地方起源叙述，而非可直接核实的航海日志。它支持“存在前帝国海上殖民传统的记忆”，但没有提供精确年代、航线、殖民规模、定居点名单、国家组织或女神专名。尤其不能把“基地”自动改写成“首都”，也不能把“殖民”自动等同于军事征服。

该条目的官方简中同键文本确实存在，但有几处值得修订：把语言写成“口音”不准确；把“几近被遗忘”译成“彻底被遗忘”过强；把交织藤叶纹饰具体化为一尊葡萄藤编织的神像，超出了英文的明确表述；把符号据说能够保护冒险者改成“依旧诉说着故事”，则丢失了符号在当前民间信仰中的护佑功能。英文的 “the symbol lives on” 与 “said to protect those who risk all for the sake of gain or glory” 表明，存续的不只是图案，还有一项与利益、荣耀和冒险相连的保护性说法。中文还遗漏了 gain，不能只保留“荣耀”。

### 3.3 俄耳堤西亚：卡拉德殖民地与坎族城邦的权威

SandBox 的 town_EW4／JhBSnWAe 称俄耳堤西亚是卡拉迪人在珀拉斯海岸的第一批殖民地之一；在早期几个世纪里，该殖民地一度处于坎族城邦古亚兹的权威之下，后来帝国扩张又使其与母共和国重新合一。这里必须区分两件事：俄耳堤西亚在原文中是卡拉德殖民地，并非坎族殖民地；坎族城邦古亚兹对它的权威，是其早期政治经历的一部分。

这一条与古亚兹和拉齐赫并读，提示帝国扩张前的珀拉斯海沿岸并非空白地带：坎族海上活动、贸易共和国和其他殖民据点的权威关系已经交错。文本没有交代古亚兹何时、通过什么制度取得俄耳堤西亚的权威，也没有给出条约或战争细节。SandBox 与 NavalDLC 复用同一字符串 ID，但英文有小幅修订：SandBox 写 Bay of Charas，NavalDLC 改为 Gulf of Charas；“empire”也改成大写的 “Empire”。这些差异应作为模块文本版本变化记录，不宜过度解释为历史事件变化。

### 3.4 NavalDLC 流浪者背景：血统自述与航海身份

NavalDLC 的 naval_dialog_strings.xml 中，backstory_a.spc_wanderer_aserai_0n 使用字符串 ID RQsjEaaL。说话者自称来自古亚兹，是技艺娴熟的水手，声称坎族血液“有一半是海水”，自幼担任航海学徒，并在二十岁时攒够钱购买了一艘驶向翡翠海的船只股份。该文本的官方简中同键译文存在，核心含义基本准确。SandBox 的阿塞莱村落文本还把阿塞莱人所称的 Bahr al-Yeshm 称为 Jade Sea（例如 castle_village_A5_1），所以不能先假定流浪者说的是另一片遥远海域；但现有文字没有直接把 Jade Sea 与 Perassic Sea 等同，仍需结合地图和其他同名证据核验。

这是一段通用阿塞莱流浪者背景的一个变体，不是一个有独立姓名、可由家谱核实的历史人物。它证明游戏叙事允许一名来自古亚兹的水手把坎族血统和海上生活联系起来；它不证明所有古亚兹居民都有坎族血缘，也不证明这句“半海水”的说法是字面事实。同一角色的通用背景还称，来自古亚兹的水手航行得比沿海其他人更远，并强调其对风、洋流和星辰的知识。这些句子共同塑造了古亚兹的航海身份，但属于角色背景写作，不是独立的人口统计或航海档案。

### 3.5 NavalDLC 奥德律萨：多语种岩刻与模块专属地点

NavalDLC 的 castle_village_ES1_1 描述称，奥德律萨位于阿塞莱边境的卡勒西亚关口附近，岩石上覆盖着数千年来以卡拉迪语、纳哈撒语、达什语、坎族语和其他十余种语言写下的涂写，内容从征服者的胜利宣言到士兵思乡的抱怨不等。这为“坎族语曾出现在多语种书写环境中”提供了另一条游戏文本证据，但它与拉齐赫的海上殖民叙述并非同一类型：前者是多语种岩刻，后者是起源传说与符号记忆。

此处存在必须保留的模块差异。SandBox 中同一 settlement ID castle_village_ES1_1 的奥德律萨位于帝国远东边境、蒂亚具斯河和库赛特汗国附近，坐标为 posX 682.056、posY 323.76；NavalDLC 版本则把它放在阿塞莱边境的卡勒西亚关口附近，坐标为 posX 802.413、posY 234.152。两者不是可以直接合并的同一地图位置。更重要的是，NavalDLC 英文文本增加了多语种涂写段落，但该模块的官方简中表仍保留 SandBox 版本的远东边境描述，未翻译新增的岩刻内容。这是可复现的模块级本地化不一致；其原因尚不能仅凭 XML 判断。另外，英文“数千年来的涂写”描述的是整片岩石上涂写累积的时长，并未给每种语言的文字分别定年；不能直接说坎族语铭刻本身已有数千年历史。

## 四、最小历史模型：网络而非统一帝国

现有材料允许提出一个分层模型。第一层是前帝国时期的海上起源传统：拉齐赫据说是坎族探险家向珀拉斯海岸扩展的基地。第二层是城邦与贸易秩序：古亚兹曾是商业共和国，并主导西部海洋与珀拉斯海之间的贸易。第三层是沿海权威关系：俄耳堤西亚作为卡拉德殖民地，早期一度处于古亚兹的权威之下，随后随帝国扩张重新纳入其母共和国。第四层是帝国压力与精英更替：古亚兹的贸易被帝国霸权压缩，统治者后来被来自纳哈撒的雇佣兵接替，并间歇性臣服帝国。第五层是文化记忆的不同存续形式：拉齐赫的符号继续承担护佑冒险者的民间意义；流浪者背景把坎族血统与航海身份联系起来；NavalDLC 的奥德律萨文本则写到坎族语岩刻。

这个模型的优点是能同时容纳政治、贸易、语言、符号和角色身份，而不把它们压成一条“坎族曾建立国家、随后被阿塞莱同化”的单线叙事。不同证据的性质也不相同：城镇描述常以传闻或概括性叙述重建过去，角色背景是文学化自述，岩刻描述是模块专属的环境史设定。它们可以互相启发，但不能被当成彼此独立、同等级的历史见证。

## 五、翻译与版本审计

古亚兹：英文关键字是 mercenaries，项目提供的中文百科写成“商人”。官方简中表没有该描述的同键条目，因此应把它标为项目参考译文错误，而不是归咎于官方同键翻译。建议译为“后来，当地统治者被来自纳哈撒的雇佣兵取代”。

拉齐赫：官方简中同键存在，但“坎族口音”应改为“坎族语”；“彻底被遗忘”应改为“几近被遗忘”；交织藤叶纹饰不应未经证据具体化为藤编神像；“said to protect”表达护佑功能，不能改成单纯讲述往事；“gain or glory”应保留“利益或荣耀”两项。

俄耳堤西亚：官方简中同键存在。SandBox 与 NavalDLC 的英文分别使用 Bay of Charas 与 Gulf of Charas，并有 empire／Empire 大小写差异。应保留版本差异，不在没有其他证据时自行统一为某一历史术语。

奥德律萨：NavalDLC 英文描述比 SandBox 多出多语种岩刻内容；NavalDLC 简中表却仍是 SandBox 的旧描述。这里不是普通的词义误译，而是同键文本未随模块英文内容同步更新，导致中文读者完全看不到坎族语岩刻这一信息。

流浪者背景：RQsjEaaL 的官方简中同键译文基本准确。“坎族血液有一半是海水”应作为航海身份的修辞性说法理解，不作生物学或人口谱系证据。

## 六、竞争假说与反证条件

假说 A：坎族叙事指向一个沿珀拉斯海活动的海上网络，而非统一帝国。支持点是文本分别提到探险殖民、贸易共和国、城邦权威、航海角色和多语种铭刻；目前没有中央统治者、统一疆界、成文制度或共同军政组织的直接记载。若后续找到明确的统一王权或中央命令文本，该假说需要修订。

假说 B：坎族身份在语言与宗教衰退后，以符号、航海传统和血统叙事等不同形式局部延续。拉齐赫和流浪者背景支持“记忆仍在文本中发挥作用”，但不能证明实际社会中的连续人口或持续祭祀。若相关文本明确把符号说成纯装饰，或把流浪者背景标为戏仿而非自我认同，则应缩小解释范围。

假说 C：帝国扩张不是简单地把一片原本统一的坎族领土征服并同化，而是介入已有的贸易和城邦关系。俄耳堤西亚与古亚兹的关系、古亚兹贸易受压及统治者更替支持这种复杂过程，但目前没有精确年表、战争记录或条约文本。

假说 D：奥德律萨的坎族语岩刻属于 NavalDLC 的特定地图与叙事版本。由于同一 ID 在 SandBox 与 NavalDLC 中位置和描述都不同，不能把该岩刻直接定位到基础版地图上的同名奥德律萨。后续只有在地图资源、场景或更多同键证据支持时，才能讨论其地理关系。

## 七、目前不能推出的事项

不能推出存在一个统一的坎族海上帝国、共同君主或中央政府；不能确定拉齐赫殖民活动的确切年代、路线、规模或军事性质；不能为女神补造名字或完整神学体系；不能把俄耳堤西亚说成坎族殖民地；不能把古亚兹的雇佣兵误写为商人；不能把通用流浪者背景当成一位可追谱系的历史人物；不能把“坎族血统”理解为所有现代阿塞莱人的共同祖源；也不能将 NavalDLC 奥德律萨的多语种岩刻移植到基础版同名地点。

## 八、下一轮研究任务

（1）相关词项复核已完成：全库 goddess 检索只发现拉齐赫女神和一处无关的诺德荒野女神；藤叶纹饰、船首和 colonize 的对应语境均回到拉齐赫条目，未发现另一个坎族女神名称。下一步继续检索不使用 Kannic 一词的航海、祭祀和沿岸殖民文本。

（2）把古亚兹、拉齐赫、俄耳堤西亚与珀拉斯海沿岸其他聚落放入同一张证据表，逐项记录政治权威、贸易功能、文本版本与本地化状态；同时核验阿塞莱语境中的 Jade Sea／Bahr al-Yeshm 与其他文本中的 Perassic Sea 是否指向同一海域，不在地图或原文证据不足时先行合并。

（3）单独核对 NavalDLC 与 SandBox 复用 settlement ID 的地图位置、场景和文本覆盖规则，避免把模块专属位置误合并为同一地点的历史变化。

（4）对流浪者的其余背景变体做跨源比较，区分通用角色写作、文化刻板印象与可由其他游戏文本互证的历史信息。

（5）现实历史类比另行立题。当前论文只重建游戏内部证据，不以现实世界的海上殖民、语言替代或宗教遗存类比来填补卡拉迪亚文本的空白。
