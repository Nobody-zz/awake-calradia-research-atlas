# 瓦兰迪亚史研究阶段性总结与成果盘点

**CHC-VLA-GEN｜阶段总结 v0.1｜2026-10-24｜暂不分配 H 编号**

## 一、总结范围与总体判断

本阶段围绕“瓦兰迪亚如何从海外军事雇佣集团发展为拥有土地、贵族秩序与独立王权的政治共同体”开展第一轮国别摸底，并将问题分解为王权与封臣、地方征服与城市接收、乡村地权与叛乱、聚落地志的跨模块校勘、土地改造与资源经济五个互相联系的专题。研究使用项目资料库中的 Native.zip、SandBox.zip、SandBoxCore.zip、StoryMode.zip、NavalDLC.zip、官方简体中文语言表，以及用户上传的 `encyclopedia-zh-cn.md`；相关成果均归入 CHC-VLA-GEN，尚未申请 H 编号。

**当前最稳妥的总解释是：瓦兰迪亚的国家形成应被理解为帝国—边疆互动中的自主政治共同体形成，以及不同地区的征服接管、贵族结盟、地方生产与社会权利重组的复合过程。** 帝国提供了军事服务、土地与头衔交换、边疆堡垒和合法性谈判的条件；海外武装群体自身的组织能力、跨海移民、地方联盟、生产活动与贵族协商，则是其能够脱离原有帝国秩序、建立王权的必要解释变量。现有材料不支持“瓦兰迪亚只是帝国衰落的副产品”，也不支持“所有地区一经征服便被统一分封”的简单模式。

这是一项证据约束下的工作假说，不是已经完成的国别通史。各文本能支持的直接陈述、相对次序、历史推论与未知事项仍需分层记录。

## 三、目前最有把握的研究成果

### 3.1 国家形成：帝国提供条件，瓦兰迪亚人形成自己的组织能力

文化介绍与王国沿革共同呈现一条重要的制度转换：跨海而来的多语军事雇佣者服务帝国，报酬不只以现金支付，也涉及土地和头衔；军事人员逐渐定居、通婚、耕作并控制附近堡垒。其后奥斯里克夺取帝国西部海岸，帝国为求和平承认其王位；奥斯里克承认部属为男爵、伯爵，并授予其土地宗主权，以换取战时集结。

因此，瓦兰迪亚的形成不是“外来佣兵忽然建国”的单步事件，而是军事服务、土地占有、定居生产、地方联盟与政治承认相互作用的过程。其确切年表、各环节持续多久以及不同群体的先后关系，仍缺少独立编年资料，不应被压缩成未经证实的单一建国年份。

### 3.2 王权：不是无制约独裁，也不应因仲裁而被称为软弱

有效王国沿革和德泰尔传记支持一个制度性问题：奥斯里克通过承认副官的贵族身份、授予土地宗主权并要求战时集结来组织战争；德泰尔时期的叙述则显示王权还要应对叛乱、王位竞争及贵族之间的领地冲突。德泰尔的政治自述将王权表现为沉重且持续受争夺的责任，并提及奥斯里克与帝国金冠的记忆。

当前可提出的解释是，仲裁本身可能是协调拥有各自军事资源、并在德泰尔时期提出相互领地要求的贵族集团的一种统治方式。不能把这一后世领地冲突倒推为奥斯里克时代已经存在同样的土地权利结构；也不能仅凭德泰尔多次仲裁就认定其“软弱”，或认定仲裁始终有效。

特别需要保持材料层级：因加泰尔与卡拉蒂尔德相关的继承争议出现在 `spclans.xml` 开发注释中，不能当作有效游戏史述已经发生的事件。沙拉斯围城对白只称“戴·科尔坦男爵”，不能据此直接认定为因加泰尔；文本也未点名当时的国王是德泰尔。

### 3.3 地方建国：征服和接收存在多种路径

现有城市地志不支持统一的征服模板。帕拉汶德的故事强调谈判接收旧城；萨哥特牵涉马萨盟部、旧帝国聚落和军事记忆重写；奥克斯·霍尔被描写为旧巴旦尼亚飞地遭征服后的新建城镇；沙拉斯则与旧商港、戴·科尔坦家族财富及其政治雄心联系；杰屈朗保留自主农民和反复叛乱的记忆；奥斯蒂港与帝国港口、私掠及航海网络有关；罗瓦尔的地志还提到瓦兰迪亚入侵前的诺德移民。

这支持“地方接管和贵族结盟的非均质过程”这一解释。它仍不提供每座城市的绝对征服日期，也不能把1084年所有权直接投射到早期。

### 3.4 社会史：农地、城市劳动与战争市场不可忽略

绿林兄弟会的官方沿革将其起点描述为农民运动，并将长期生存中的粮食供应、控制告密和暴力勒索联系起来。佃农人物故事把地主伪造文书、改作牧羊与失地联系起来。杰屈朗地志则强调自主农民、异见和贵族资助叛乱以打击敌对家族。

NavalDLC 的沙拉斯流浪者故事进一步记述：行会首领引入绿林兄弟会反抗瓦兰迪亚国王，沿岸渔民为了高价运粮，戴·科尔坦男爵主持围城并搜查海岸，部分家庭逃往岛屿且指控有人乘机侵占家产。沙拉斯码头的另一人物背景还描述农村土地不足、移居港口、劳动竞争恶化和帮派暴力。

这些材料使研究不再局限于国王和男爵：地方统治还涉及土地使用权、城市职业组织、港口劳务、补给利润、逃亡和武装镇压。由于部分材料是人物证词，它们能确立人物的叙述与动机，不能独立证明全国法典、司法程序或同一场战争的完整年表。

### 3.5 土地与资源：生产空间的形成可能是领主权力的一部分

NavalDLC 的奥克斯·霍尔地志把征服、驱逐、排水开田和建造大堂连在一起；弗雷吉昂地志把排水工程归于瓦兰迪亚男爵；阿利斯维斯特则强调定居者排水后种植小麦与黑麦。Valanby 地志记载土地所有者在收回的河岸围场中养马。西岚达克地志称银矿大多枯竭后当地主要出口黏土，勒芒塔尔则出现银矿枯竭后转向盐业的版本叙述。

这些内容支持“征服后的地方权力不只靠城堡和军役，也可能通过土地利用、生产组织与资源交易持续化”的研究模型。它不能证明所有工程均由王室统一组织，也不能证明具体劳役、租税或产量。

## 四、版本和中文译名：已建立的控制规则

跨模块审计比较了 SandBox 与 NavalDLC 中共同的52个瓦兰迪亚聚落 ID，结果为：

- 52/52 的中心坐标 `posX/posY` 不同；
- 16个对象的城门坐标不同；
- 12个对象新增 `port_posX/port_posY` 字段；
- 35个聚落的英文描述发生变化，其中12个改用新文本键，23个沿用旧键；
- 18处实质性英文改写没有获得相应的简中内容更新；10处实质性改写通过新键获得新译文，另有7处主要是小幅措辞或拼写变化；
- 已比较对象的 `owner` 与 `culture` 未变。

这批差异属于模块资源与地图配置的版本差异，不能直接解释为故事世界内部的历史变迁。两份模块不是两位独立历史证人。

对 `village_V1_2`，英文名称从 Etirfurd 改为 Echarfurd，但 SandBox 与 NavalDLC 的简中名称表均仍为“埃蒂尔菲德”。因此可以确认源语言表沿用旧中文值，但在缺少完整模块注册和运行时合并证据时，不应声称已确认目标构建最终显示的名称。

研究继续遵循用户要求：官方英文是语义与叙述分析的首要依据；官方简中用于确认正式译名和定位翻译遗漏；同键翻译不算独立证据；不凭记忆自行新造中文名。此前对卡琉斯（Caleus）、因加泰尔（Ingalther）等名称的校勘应继续保留来源级说明，不能把二手译名证据冒充同键官方语言表证据。

## 五、史料覆盖和证据边界盘点

### 已经取得并使用的材料

- 项目 Library 中五个官方模块 ZIP：Native、SandBox、SandBoxCore、StoryMode、NavalDLC；本阶段多个专题已读取相关原始 XML 和对应简中语言表。
- 用户上传的 `encyclopedia-zh-cn.md`，其自身声明对应游戏 v1.4.8.119303，覆盖53座城镇、141个普通村庄和8个王国，但不含城堡及 `castle_village_*` 条目。
- 官方文化介绍、王国沿革、人物传记、政治自述、氏族配置、聚落地志、流浪者背景及 NavalDLC 航海对白。
- TaleWorlds 官方2017年《Vlandia》开发者文章，以及项目既有研究规范和登记材料作为背景与方法参考。

### 当前重要缺口

1. StoryMode.zip 当前仅有4个 XML，不含十九人主线访谈正文；但公开的 Bannerlord v1.4.5 反编译代码已恢复德泰尔、因加泰尔与恩泰里的官方英文采访字符串，现可作为 A2（官方程序集反编译恢复）使用。项目所存 v1.4.8.119303 程序集尚未逐字核验，故不得将 A2 冒称为该版原始 XML 或 A1。
2. 仍缺若干事件的绝对日期、围城男爵本名、沙拉斯叛乱时国王身份及独立编年证据。
3. 仍缺足以确认全国性地权法、三分之一义务普遍性、实际劳役制度、土地分配比例与经济产量的材料。
4. SandBox/NavalDLC 聚落 XML 的顶层属性与地志差异已审计；2026-10-26 的递归复核又发现 `Village.village_type` 6处、`Building.level` 14处、`Location.scene_name` 8处，以及新增 `Locations`／`Buildings` 子节点。旧稿“未发现其他 XML 属性值差异”表述过宽，已由独立补记纠正。目标构建的 `SubModule.xml` 注册、模块启用顺序、合并后对象与运行时最终显示仍未取得完整证据。
5. 官方英文与简中之间的局部滞后已经登记；不能把过时译文当作新版英文内容，也不能因为英文叙述更丰富就自行发明缺失的官方中文名。
6. 各角色的流浪者故事具有叙述者视角和谋生语境；它们不是法庭裁决、官方行政档案或中立编年史。

## 七、当前综合模型与反证条件

现阶段的综合模型包含五个相互关联但不可简单等同的过程：

1. **军事服务与土地化**：帝国以土地、头衔和堡垒机会维持海外军事集团；军人定居与生产使军事服务获得地方社会基础。
2. **征服与地方接管**：不同城市通过谈判、盟部合作、驱逐、财富控制或既有移民网络被纳入新政治共同体。
3. **贵族权利与王权协调**：国王承认领主的领地和军事义务，同时通过仲裁处理叛乱、继承和家族冲突。
4. **生产空间与资源网络**：排水开田、围场养马、矿业与替代资源、粮食供应和铁矿流通可能把地方权力转化为持续收益。
5. **权利冲突与社会整合成本**：佃农失地、农村武装、行会叛乱、海上补给、围城搜捕和港口劳动竞争暴露了统治秩序的社会成本。

该模型若要成立，需要未来找到能够独立确定事件时序的材料、具体领主与工程的连接证据、更多非人物证词的法律和生产信息，以及能验证实际经济配置的游戏数据。若后续材料表明地方开垦完全独立于贵族控制、王权仲裁并无实际政治作用，或现有事件被明确限定为个别夸张故事，则相应环节应降级或修改。当前模型不应被当作预先确定的结论。

## 八、下一阶段的优先任务

### 第一优先：补齐国家形成的相对年代与人物链

## 九、阶段结论

瓦兰迪亚史研究已经形成一个可以继续检验的整体问题结构：海外军事服务如何转化为土地占有与地方生产；地方征服如何形成不同的政治接管方式；贵族的地权与军事资源如何与王权仲裁并存；地方经济如何支持城市和军队；以及这些过程如何引发佃农失地、农村叛乱、港口冲突和战争镇压。
