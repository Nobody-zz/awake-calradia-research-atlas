# CHC-EMP-GEN｜帝国地方权威论文与既有 H/Q 研究范围去重审查 v0.1

**日期**：2026-10-26  
**审查对象**：论文候选稿 v0.10《帝国官方叙事中的地方权威关系：功能性利用、选择性吸纳与服从边界》。  
**目的**：落实 Q-0013 v0.5 的问题导向与论文去重要求，检查候选稿是否重复 H-0001—H-0005 或抢占 Q-0011 已提出但尚未正式立项的专题范围。  
**边界**：本文件为帝国研究线的范围审查建议，不修改公共 I/Q 文件，不授予 H 编号，也不代替中央协调线作最终优先级裁决。

## 一、候选稿的独立问题

v0.10 的主体问题不是卡拉德国家如何形成、如何征服帕拉社会、共和国机构如何建立、军权如何长期化，也不是1084年哪一方取得皇位的合法性竞争。它比较的是官方叙事如何呈现四种不同关系：

1. 秘密之手：组织通过对当局有用而取得活动空间，功能性利用、私人庇护与犯罪收益并存。
2. 自由民与安普雷拉：帝国选择性利用边疆知识与军事能力，但不必然获得地方群体对实际官权的全面服从。
3. 波罗斯：地方家族据称仅在争端双方邀请时介入，裁决被接受；传闻语气与缺乏具体判决记录限制结论。
4. 蛮族事务局医生故事：角色自述中的正式机构信息索取与私人关系胁迫，作为正式强制的对照。

因此，论文的独立贡献是**关系机制与服从结果的比较**，而不是提供一条帝国地方治理制度的连续年代史。它目前可以保留为未编号候选稿，但须避免把边界案例扩写成第二条主线。

## 三、与公共研究规范的关系

### I-0001 v1.4

候选稿已区分官方叙事直接陈述、人物自述、传闻、研究者推论与未知项；同一叙事链的连续 source key 不重复计证；英文原始文本优先，简中用于校勘。跨国反例来自同一官方游戏文本体系，不被当作独立外部史料互证。后续如继续修订，正文应保持历史论证为主，管理编号与源键详情留在附录或审计稿。

### I-0004 v2.2

CHC-EMP-GEN 继续作为本研究线的工作分类，不因本稿创建而申请新的 H 编号。该工作分类与正式论文领域代码不是同一件事；是否最终归入 CHC-EMP-POL 或其他具体分类，应在候选稿定型和中央协调时一并判断。

### Q-0009 与 Q-0011

本稿没有为波罗斯、安普雷拉、阿耳戈隆、密泽亚强加绝对年代，也没有把相对年代未知当作制度不存在的证据。Q-0011 对 H-0001—H-0005 的跨论文复核强调：共享同一官方回顾、相似术语或重复 source key 不等于独立互证；后期地方精英案例不能倒推早期共和程序。v0.10 与这些要求相符，但仍须防止边界章节膨胀。

### Q-0013 v0.5

Q-0013 当前要求先围绕可检验历史问题组织材料，优先完成 H-0003／H-0004 的实质性重构、H-0005 的制度链与 Q5-09、H-0001／H-0002 的针对性结案，再做统一质量复核；全大陆关系图谱优先于仓促启动更多 H 论文。因此，v0.10 可以作为未编号候选稿保留，但不能自动成为下一篇正式论文，也不应抢占现有优先级。

## 四、范围裁决与下一步建议

1. **保留 v0.10 为独立、未编号候选稿。** 其四种主体关系与 H-0001—H-0005 的核心问题有可说明的学术分工。
2. **冻结主体案例与13键主语料。** 不再添加城镇或家族简介来扩大比较矩阵；若出现新材料，先问它是否能改变某个核心机制判断。
3. **压住边界案例的篇幅。** 阿耳戈隆与密泽亚仅用于保护性整合的边界检验；被弃者军团仅用于说明合同军事服务不等于地方治理中介；阿塞莱守护者仅作为跨文化边界材料。它们不得发展成额外主线。
4. **为 Q-0011 候选 D 留出独立空间。** 拉革塔、阿耳戈隆、密泽亚、巴拉维诺斯与南方城邦的精英参与／保护／献纳／谈判比较，仍应作为另一项未编号专题的候选问题，不在本稿中预先完成。
5. **不授予 H 编号。** 当前应先由中央协调线结合 Q-0013 的优先级，决定 v0.10 是继续作为比较型工作稿、再压缩边界章节，还是待 H-0003/H-0005 结构修订完成后再推进。此裁决不修改 I-0002、I-0003、I-0004、Q-0011 或 Q-0013。

**总裁决**：v0.10 的核心比较可以与既有 H 论文共存；主要重复风险集中在阿耳戈隆／密泽亚（H-0002及 Q-0011 候选 D）和被弃者军团（H-0005及 Q-0011 候选 B）。通过维持其边界案例地位、停止扩充语料并明确交叉引用，可保留这份研究成果而不重复建立同一篇论文。
