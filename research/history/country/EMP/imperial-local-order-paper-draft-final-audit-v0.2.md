# CHC-EMP-GEN｜《帝国地方秩序的多重来源》论文候选稿终审记录 v0.2

**日期**：2026-10-24  
**审查对象**：imperial-local-order-paper-candidate-v0.1.md  
**结果**：通过进入跨线同行审查；尚不构成正式论文定稿，也不授予 H 编号。

## 一、论文结构与论证范围

- 标题为《帝国地方秩序的多重来源：正式权威、地方中介与非正式强制》，比“地方秩序的双重性”更准确地涵盖正式行政胁迫、非正式组织、社区认可、受邀仲裁、边疆中介与合同型私人军事服务。
- 正文区分六种机制：功能性庇护、正式行政胁迫、社区认可与受邀仲裁、边疆中介的选择性吸纳、反叛组织的强制抽取、合同型私人军事服务。
- 六种机制是研究者的分析范畴，不是游戏文本定义的六种法定制度。
- 阿塞莱巷区守护者明确标为跨文化比较；波罗斯地志保留 “it is said” 的传闻性质；真理之国与火焰余烬不合并；被弃者军团不等同于犯罪组织。
- 结论限定为“官方文本所描绘的权力机制”，不量化帝国全境的实际普遍性。

## 二、源级核验

- 候选稿所列15个不重复英文 source key 均在本轮上传的 SandBox 英文 XML 中找到。
- 14个 source key 在本轮可用的对应简中语言表中找到直接匹配。
- 唯一未在对应简中语言表中直接命中的是波罗斯地志 key rGXdJybe：英文 key 存在于 settlements.xml；项目百科 encyclopedia-zh-cn.md 有《波罗斯》中文条目，但当前 std_settlements_xml-zho-CN.xml 没有该 key。候选稿已明确将其列为待核的本地化来源链问题，不把辅助百科文本伪称为语言表逐键命中。
- 候选稿附15键源级证据清单、各类证据限制、相关 XML 与 ZIP 的 SHA-256；来源身份可复核。
- 源文件的 SHA-256 证明本轮使用字节的身份，不证明它们是2026年最新客户端版本；候选稿保留这一限制。

## 三、英汉本地化审计新增结果

1. **holy poverty**：英文把“白天靠捐献生活”与“劝说地主佃户接受 holy poverty”并置，形成对宗教动员、佃户资产与组织生计之间矛盾的讽刺。将其解释为宗教名义下攫取佃户资产的讽刺有文本根据，但原文没有直接叙述具体盗窃或诈骗手段。官方简中加入原文没有的“朝圣”，把讽刺简化为直接骗财。
2. **retinues**：自由民英文原文使用 “the retinues of archons and emperors”，简中译作“执政官和皇帝们的私兵”。候选稿采用语义更宽的“随从队伍”，不预先确定其法定军事身份。
3. **Aserai protector**：对应语言表用“守护者”，候选稿已统一为“阿塞莱巷区守护者”。
4. **Poros**：项目百科中文条目把 “Livestock rustling and blood feuds are common here” 译写为“嘶鸣的牲畜和流血的斗殴在此地成了一道靓丽的风景线”，未保留英文关于牲畜盗窃与血仇常见的具体信息。候选稿以英文为主证，并注明该中文条目的来源链尚未由当前随附语言表逐键复现。

## 四、保留的主要证据边界

- 秘密之手的“对当局有用”不等于正式授权；没有命令链、拨款或司法豁免证据。
- 蛮族事务局与真理之国主要通过角色自述呈现，须考虑自我辩护立场。
- 绿林兄弟会与火焰余烬的组织演变来自派系简介，不证明每个成员或每个时期均如此。
- 波罗斯材料含传闻标记，且没有具体判决记录。
- 自由民材料不能证明身份转换的法律程序或人口规模。
- 现有资料不是行政命令、判决书、税簿或军饷簿，不能据此量化制度发生率。

## 五、裁决与下一步

候选稿的结构、源键、官方简中术语与主要论证边界通过本轮内部审查。建议下一步进行跨线同行审查，重点检查：
1. “地方秩序”是否仍比材料能支持的范围更宽；
2. 六种机制是否有必要保留为同一篇文章，或应把边疆吸纳另列专题；
3. “holy poverty” 的讽刺解释是否在正文中充分区分原文直接陈述与研究者推论；
4. 波罗斯中文条目的来源链是否能由另一份明确版本的本地化资源补足。

通过跨线审查前，继续保留 CHC-EMP-GEN 临时分类，不申请 H 编号。
