## 摘要

本文考察《骑马与砍杀Ⅱ：霸主》官方英文文本如何呈现帝国地方权威关系，并比较三种不可预设为同一机制的关系：秘密之手所代表的功能性合作与非正式暴力、波罗斯地志所描绘的受邀仲裁与程序性接受，以及蛮族事务局医生故事所描绘的正式机构强制。本文不再把“地方权威接口”作为统摄案例的因果解释，而将其视为旧稿中的工作标签；当前研究采用关系描述与比较编码框架，分别追问行动者关系、资源基础、因果链、文本所述结果及竞争解释。自由民与安普雷拉、阿耳戈隆与密泽亚、被弃者军团及阿塞莱守护者分别作为机制边界或跨文化比较，不被视为同一制度类型。帝国主语料中的13个英文 source key 归并为9个叙事单元，均来自同一官方游戏文本体系，不构成独立历史见证。瓦兰迪亚跨国反例审查用于测试概念边界，不计入帝国案例证据；其结果进一步显示，生产收益、资格文书、贵族赞助、市场物流、空间退出、社区融资和正式封臣关系均可能形成不同因果链。本文结论限于官方文本的关系表征与机制比较，不推定这些关系在帝国境内的普遍程度，也不声称已复原一套统一的地方治理制度。

**关键词**：卡拉迪亚帝国；官方文本；地方权威关系；功能性合作；程序性仲裁；正式强制；史料批判

## 一、问题的提出

讨论卡拉迪亚帝国的地方秩序，容易陷入两种过度简化的解释。第一种将正式官署视为秩序的唯一来源，把地方中介、黑帮、反叛组织和私人武装一概视为国家权力之外的混乱因素。第二种则从秘密之手等组织的存在出发，反过来断言帝国地方治理普遍依靠黑帮或非正式暴力。现有文本都不足以支持这两种判断。

更精确的问题不是所有地方行动者是否都构成某种“接口”，而是：官方文本分别如何呈现功能性合作、程序性仲裁与正式强制？这些关系由谁参与，依靠什么资源或权威基础，经过怎样的因果链产生文本所述结果？哪些看似相似的合作、服从或抵抗，实际上可能由不同机制产生？

本文以三个核心案例进行比较。秘密之手的派系简介把对当局有用的服务、商业庇护与犯罪收益并置，但没有证明正式授权；波罗斯地志将地方仲裁描述为依赖双方邀请与裁决接受，同时保留“it is said”的传闻限制；蛮族事务局医生故事则由一名角色自述正式机构如何利用私人信息和职业关系实施胁迫。三者都涉及权威关系，却不能据此推断它们属于同一制度或同一因果机制。

自由民与安普雷拉、阿耳戈隆与密泽亚、被弃者军团及阿塞莱守护者用于检验上述比较的边界，而不是被强行归入三个核心机制。本文的贡献因此是对官方文本中的地方权威关系进行有边界的比较编码，并把具体机制、竞争解释和证据限制分开。它不试图从角色故事和聚落地志直接复原帝国行政制度，也不估计这些关系在帝国社会中的普遍程度。

## 二、史料与方法

本文使用《骑马与砍杀Ⅱ：霸主》SandBox v1.4.8 官方英文文本，主要包括派系介绍、流浪者角色背景、同伴背景和聚落地志。它们的证据性质并不相同。派系介绍往往以概括性语言解释组织的起源、活动方式和政治位置，适合分析官方叙事如何构造某个组织，但未必能说明每名成员或每个时期的实际行为。角色自述能够呈现人物如何理解自身经历，却可能带有自我辩护、怨恨或利益立场。聚落地志能够描述当地自治、纠纷和权威关系，但其中的 “it is said” 等措辞必须保留其传闻性质。不同文体可以互相限制解释，却不能被视为独立档案的简单累加。

旧稿使用的“地方权威接口”并非游戏文本中的法定制度名称，也不再作为本文的总因果解释。本文将其降为历史工作标签，采用关系描述与比较编码框架。每个核心案例分别考察四项内容：**行动者关系**（谁向谁提供服务、主张权威、请求裁决或施加强制）；**权威与资源基础**（组织服务、地方知识、社区认可、信息控制、私人赞助或支付）；**因果链与文本所述结果**（文本具体说明何种行动如何影响合作、服从、抵抗、接受裁决或退出）；以及**竞争解释与未知项**。若文本没有交代授权、指挥链、程序或结果，相关信息标为未知，不以概念推断补足。

本文以官方英文为主要解释依据，官方简中用于校验译义和人物身份。自由民英文原文称年轻人进入执政官和皇帝的 “retinues”，对应简中译为“私兵”；本文保留英文较宽的“随从队伍”，不预先判定其法定身份。波罗斯 key rGXdJybe 与阿耳戈隆 key LqPJY4s9 均存在于 settlements.xml，但未在本轮随附的 std_settlements_xml-zho-CN.xml 中找到对应 key；项目百科提供两条中文地志文本，因此在本稿中只将其作为辅助中文材料，不伪称为当前语言表的逐键命中。波罗斯百科将 “Livestock rustling and blood feuds are common here” 写成“嘶鸣的牲畜和流血的斗殴在此地成了一道靓丽的风景线”，存在明显修辞偏移，故相关解释以英文为主。

本文采用目的性差异选取，而非代表性抽样。13个英文 source key 归并为9个叙事单元：秘密之手派系简介、自由民派系简介、被弃者军团派系简介、蛮族事务局相关的同一医生故事、阿塞莱守护者相关的同一角色故事，以及波罗斯、安普雷拉、阿耳戈隆和密泽亚四条聚落地志。连续 key 只计为一个叙事单元；同一官方文本体系内的不同条目可以互相限定解释，但不能被当成独立档案累加权重。

瓦兰迪亚跨国反例审查另行识别出六组竞争机制。它们不计入帝国主语料的 source key 或叙事单元，也不作为帝国制度的直接证据；其用途仅是检验本文的概念是否过宽。该审查使用同一官方游戏文本体系中的跨文化材料，不构成独立外部史料互证。斯特吉亚跨国审查尚未完成，故本文当前的跨国压力测试仍不完整。

## 三、功能性合作与非正式暴力：秘密之手与正式授权的边界

秘密之手（Hidden Hand）的派系介绍把组织性犯罪与对当局的功能性服务放在同一段叙述中。文本称它控制帝国南部的乡村地区，有时也控制城镇，并通过 “making themselves useful to authorities” 而壮大。具体而言，它镇压动乱、压制惹麻烦的传教士，同时抢掠与其庇护者竞争的商人。文本还指出，同一成员可能一年中有几个月在山地当土匪，回到城镇后则作为打手和赃物商活动（SandBox v1.4.8，spclans.xml，hidden_hand，key nQOf27Rx）。

这一描述的关键不只是帝国境内存在一个黑帮，而是官方叙事把镇压、商业竞争、庇护关系和犯罪收益并列起来。秘密之手的活动空间似乎与其对当局的功能性价值有关，同时也服务于庇护者的经济利益。由此可以提出“正式权威与非正式暴力之间存在接口”的解释：地方组织可能通过提供某些权力机关需要的服务，获得继续经营其他活动的空间。

但“对当局有用”并不等于获得正式授权。文本没有说明具体官员、命令链、财政拨款或司法豁免，也没有量化秘密之手的实际覆盖范围。因此，不能将这段描述写成帝国由国家统一指挥黑帮治理的证据。更稳妥的结论是：官方叙事没有把国家与犯罪描绘成完全封闭的两个领域；功能性合作、默许、庇护和私人获利可能交织，但其制度性质仍需分别判断。

## 四、正式机构强制：蛮族事务局与私人关系

一名自述曾在帝国学院受训、并拥有富裕且有影响力病人的外科医生称，蛮族事务局最初负责分化外部部族，后来把权限扩展到帝国内部各种可能被视为威胁的事务。机构先要求医生提供病人的私人信息，随后又以揭露医生与病人的关系相威胁，迫使他参与逼供（wanderer_strings.xml，backstory_a.spc_wanderer_empire_10，key 0FHF0OXK；backstory_b.spc_wanderer_empire_10，key pzK7TN05；backstory_c.spc_wanderer_empire_10，key sfFLudTM）。这三个 key 属于同一角色故事的连续段落，不构成三份独立证据。

与秘密之手不同，这里描绘的是正式机构直接利用情报和私人关系实施胁迫，而不是通过地方黑帮行事。两者可以并置，但不能合并成同一机制：秘密之手体现非正式组织通过对当局有用而获得空间；蛮族事务局故事则是角色对正式机构越界的控诉。它们共同提示，地方权力不能只按“是否拥有正式职位”来分析，还要追问实际控制通过何种关系和手段发生。

这一材料的限制也很明显。故事由自称受胁迫的医生讲述，可能包含自我辩护；现有文本没有行政文件说明该局的正式权限、扩权时间或逼供行为的执行范围。因此，本文只论证官方角色叙事将行政扩权、私人信息与逼供联系起来，不把它升级为经独立档案证实的完整官僚制度史。

## 五、程序性仲裁与选择性吸纳：关系类型的差异

阿塞莱模板的一名角色把巷区守护者描述为受居民尊重、负责维护当地权益的地方中介。新任卫队长要求他掩盖手下强夺女性的行为并提供居民情报；守护者拒绝后遭到施压、父亲受威胁，最终举家离开（wanderer_strings.xml，backstory_a/b/c.spc_wanderer_aserai_4，keys LjkQ4fYp、Z8TfQDSV、PWpTT0NM）。其中 “We protectors, we serve the state, but we're not its tool” 是角色的规范性主张，不是法律条文。此例只作为跨文化比较，说明正式职位的要求可能与地方中介维持社区信任的需要发生冲突；它不能直接证明帝国拥有同样的制度。三个 key 属于同一角色故事的连续段落，不构成独立互证。

波罗斯（Poros）的聚落地志提供了帝国地区内的另一种地方权威模式。文本称当地牲畜盗窃与血仇常见；据说列奥尼帕得斯家族通常只有在争端双方都邀请时才介入，但一旦作出裁决，便会受到服从（settlements.xml，town_ES3，key rGXdJybe；官方简中百科《波罗斯》）。这里并非没有暴力：盗窃和血仇仍然存在。不同之处在于，地方权威被描述为通过双方邀请和裁决接受而生效，而不是每起纠纷都由中央官署直接处理。

波罗斯材料中的 “it is said” 必须保留。地志没有提供具体判决记录，也没有说明双方在谈判中是否平等。因此，这只能被称为官方地志所描绘的一种地方仲裁模式，不能被推广为全帝国统一的司法程序。与秘密之手和蛮族事务局并读，它说明地方秩序既可能通过胁迫运作，也可能通过社区认可和被接受的裁判维持；地方权威不能预先被定义为犯罪或压迫。

帝国边疆的自由民（Eleftheroi）则显示另一种中介机制。派系介绍称，他们最初是逃亡奴隶和债务人的后代，因熟悉边疆而受到当地帝国指挥官重视；其领袖获得头衔，年轻人进入执政官和皇帝的随从队伍，但群体仍对帝国的实际权威抱有敌意（spclans.xml，eleftheroi，key 9qAWNBvA）。这里既不是秘密之手式的犯罪庇护，也不是波罗斯式的受邀仲裁，而是国家对边疆知识和军事服务的选择性吸纳。它可以增加帝国对边境的行动能力，却不必然消除地方群体对日常官权的抵触。该材料来自派系简介，不能说明其身份转换的法律程序、自治范围或人口规模。

安普雷拉（Amprela）的地志为自由民案例补上城镇层面的军事场景：守望者通过边境要塞的信号预警，帝国招募自由民马弓手对抗草原骑兵，而具装骑兵则出城与斯特吉亚王公争夺伊勒坦湖区运输线的贸易控制权（settlements.xml，town_EN6，key YYYxOiCq）。这条材料直接支持自由民服务被纳入边疆防务，也将其放回边境交通和军事竞争的空间中；它仍没有说明自由民的法定身份、指挥链或征募条件。安普雷拉与自由民派系简介来自同一官方文本体系，属于不同文本条目的互补，不是独立档案的互证。

阿耳戈隆（Argoron）和密泽亚（Myzea）进一步限制“选择性吸纳”这一概念，但二者不应被当作同一政策的对照组。阿耳戈隆地志称当地拉科尼亚人把帝国视为抵御帕拉人的保护者，欢迎帝国移民、与其通婚，地方酋长加入元老院，而原有语言和习俗逐渐淡化（settlements.xml，town_EN4，key LqPJY4s9）。这是一种被叙述为保护、婚姻和精英入席共同构成的整合路径。

密泽亚则显示另一种结果。地志称元老李图以抵御草原掠袭者的保护促成帕拉诸部较和平地加入帝国；后来李图在元老院失势，试图将当地群体组织成仿古卡拉德共和国的竞争政权，最终遭帝国镇压，而当地居民仍被描述为对旧共和体制和共和派保有好感（settlements.xml，town_EN5，key 8UJ3cPrZ）。原文没有说李图属于现有的多伦托斯家族，不应因密泽亚当前的初始家园归属而把两者绑定。与阿耳戈隆并读，这两条地志只能说明官方叙事把保护关系与不同的政治后果联系起来。它们不是同一时期、同一政策或可比制度程序下的对照组；不能据此证明两地采用了相同的法律程序，也不能提供精确年代或地方制度的完整复原。

## 六、边界案例：被弃者军团与合同型军事服务

被弃者军团的派系介绍称，阿雷尼科斯在潘德拉克战役后废除了最后的常备军，转而依赖开销更少、且更适于控制领土的执政官私人随从队伍。军团成员憎恨这一变化，怀念旧军队的旗帜、部队历史和军营生活；但文本随即指出，军队若不能定期领饷便无法维系，因此他们也接受帝国与外国领主的合同（spclans.xml，legion_of_the_betrayed，key bhxVA9w7）。为保持与自由民材料的术语区分，原文 “archons' private retinues” 在本文译为“执政官的私人随从队伍”，不简化成具有更强制度含义的“私兵”。

这一案例限制了“私人权力等于犯罪强制”的概括。军团并非被描述为秘密之手那样的黑帮，而是一群具有专业军事身份、制度记忆和支付需求的武装人员。他们批判私人随从取代常备军，却又必须进入合同市场生存。这里的主要问题是公共军事组织、领主控制、领土治理成本与稳定支付之间的张力，而不是简单的治安犯罪。

因此，被弃者军团应作为边界案例，而非与秘密之手或绿林兄弟会合并。它表明，非中央化的军事力量可以表现为雇佣合同、私人赞助和忠诚竞争，不必然表现为对居民的勒索。只有区分这些机制，才能避免将所有地方或私人权力都塞进“非正式强制”这一单一概念。

## 七、讨论：关系描述框架与因果机制的边界

瓦兰迪亚跨国反例审查没有证明比较框架毫无用处，但明确限制了它作为总因果解释的地位。六组反例显示，看似相近的服从、抵抗、强制或地方自主，可以由不同机制产生。下表只记录对本文概念的压力测试，不将瓦兰迪亚材料当作帝国案例的支持性证据。

|跨国反例组|可辨认的竞争机制|对本文的限制|
|---|---|---|
|佃农资格保护、地主改牧与伪造文书（iPCX96mA）|生产用途变化、土地收益、法律资格与文书控制|正式保护规则可能存在但因资格操纵而落空；不能自动解释为地方中介失灵|
|杰屈朗贵族赞助叛乱（R6YJsK89）|地方精英赞助与家族竞争|反叛组织既不能一概视为底层自发力量，也不能一概视为国家代理；赞助者与政治竞争可能更接近因果核心|
|沙拉斯围城（TMdL4gJH、cc9JuNoL、9wYQGoha、IWzzeHb6）|城市政治联盟、粮价与商业物流、海岸军事管制、家庭迁逃|政治目标、交易、军事强制与空间退出并存，不能合并为一种服从机制|

|边疆安全、身份主张与迁居（W2x5Z40R、fGTeaCVU、sfgZhUgT）|袭击风险、地方身份、地形与退出选项|服从与抵抗受到安全和空间条件影响；退出不应被当作接口失灵的附属结果|
|正式封臣关系、军役集结与国王仲裁（cMO9JXvk、IudGLWQZ、EHiQI7ps）|封地、效忠、军役交换与王权仲裁|正式封臣关系不是非正式地方中介的同义词；国王仲裁封臣争端也不能推广为佃农司法机制|

其中最强的两组反例是杰屈朗的贵族赞助与佃农资格文书案。前者要求把政治赞助和家族竞争纳入解释；后者要求区分生产收益、法律资格、文件控制和申诉资源。沙拉斯围城则展示了复合因果链：城市政治联盟、围城粮价、海运供给、军事搜查和家庭迁逃可以在同一叙事链中出现，却不因此构成一种统一关系。

这些跨国材料来自同一官方游戏文本体系，文体包括角色自述、聚落地志、通用贵族对话和DLC角色背景；它们不是独立外部史料互证，也不能直接证明帝国拥有相同制度。其方法意义在于迫使本文把“关系是什么”与“行为为何发生”分开。若生产收益、贵族赞助、文书操纵、市场物流、共同体融资、空间退出或正式封臣关系能更具体地解释事件，就应优先检验这些机制，而不是将它们重新命名为不同的“接口”。

因此，本文只保留三种核心比较：**功能性合作**（秘密之手）、**程序性仲裁**（波罗斯）与**正式机构强制**（蛮族事务局医生故事）。自由民、安普雷拉、阿耳戈隆、密泽亚、被弃者军团和阿塞莱守护者是边界案例，用于说明哪些关系不宜并入三种核心比较，而不是组成一套更大的制度分类。

框架的解释价值取决于它是否能让具体机制更清楚，而不是能否把每个案例都装进去。若同一标签下的案例在行动者、资源、因果链和结果上无法形成有意义的比较，就应将其拆开；若后续证据显示某一案例主要由更具体的市场、法律、政治赞助或空间机制解释，则应让这些机制处于解释中心。对秘密之手，若发现明确命令链或制度化豁免，须修订“授权状态未知”的判断；对波罗斯，若出现具体纠纷与判决记录，须重新评估传闻地志与实际仲裁的距离；对自由民，若有明确身份或招募制度定义，须调整其边界案例解释。若未来跨文化核查发现所谓相似性只是互不相干的叙事模板，则本文应进一步收窄为官方文本表征研究。

## 八、结论

帝国官方文本并未把地方权威关系描绘成一种统一机制。秘密之手的故事把对当局有用的服务、商业庇护与犯罪收益并置，支持的是功能性合作与非正式暴力可能交叠的有限判断，并不证明正式授权；波罗斯地志描绘受邀仲裁与裁决接受，但“it is said”及缺乏具体判决记录限制了结论强度；蛮族事务局医生故事则呈现正式机构利用私人信息与职业关系实施胁迫的角色自述，不能代替行政档案。

自由民及安普雷拉、阿耳戈隆与密泽亚、被弃者军团和阿塞莱守护者不构成上述三种关系的统一扩展分类，而是检验概念边界的比较材料。瓦兰迪亚反例审查进一步显示，土地收益、资格文书、贵族赞助、市场物流、共同体融资、空间退出与正式封臣关系可能产生不同的因果链。它们仅用于限制比较框架的外推范围，不作为帝国制度的直接证据；同一官方文本体系内的跨文化比较也不构成独立史料互证。

本文的有限贡献，是比较官方文本如何呈现功能性合作、程序性仲裁和正式强制，并明确区分直接叙述、历史推论、竞争机制和未知项。旧稿中的“地方权威接口”不再被主张为独立因果机制，而只保留为历史工作标签。现有证据不能证明帝国存在统一的地方代理人制度，也不能推定这些关系在帝国境内的普遍程度。若要复原实际行政程序、法律执行或财政规模，仍需更具体的命令、判决、账目或其他相互独立的材料。
