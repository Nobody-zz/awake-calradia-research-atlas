# CHC-EMP-GEN｜跨文化村庄与城堡附属村庄的 NavalDLC 异文审计 v0.1

**工作包 A 子任务｜2026-10-24**  
**对象**：跨文化聚落接口回检中10条直接提及帝国土地、边界、市场或政治关系的非帝国文化村庄记录。  
**基线**：SandBox v1.4.8 与 NavalDLC v1.2.8 的官方英文 `settlements.xml`；对照两份归档中的官方简中 `std_settlements_xml-zho-CN.xml`。  
**目的**：判定文本差异是否改变历史解释，以及官方简中翻译是否反映 NavalDLC 的英文改写。

## 一、总发现：DLC英文更新了叙述，简中描述表却没有同步

10条记录的 SandBox 与 NavalDLC 英文描述均存在字符串差异。对照简中语言表后发现：

- 其中9条在 SandBox 与 NavalDLC 的简中描述文本完全相同，仍保留 SandBox 英文原文对应的地理、通道、社会角色或经济活动。
- `castle_village_V2_1`（Hongard）在 SandBox 简中表中有描述，但在 NavalDLC 简中 `std_settlements_xml-zho-CN.xml` 中未找到对应键。
- 因此，使用 NavalDLC 英文史料时，不能直接把随包简中描述当作已经更新的对照译文。它在9条记录中是旧版文本的复用，在1条记录中则缺少对应描述。
- 这不只是措辞问题：部分旧简中仍保留了 NavalDLC 英文已经删去的帝国通道、湖泊命名和贸易路线信息；另有新版英文新增了“向附近城镇陶工出售黏土”这种经济关系，而简中仍未写出。

## 三、版本审计结论

1. **10条均有英文字符串差异，不等于10条均发生同等程度的历史改写。** Hongard仅有极小的编辑变化；Ab Comer、Cantrec、Bryn Glas主要调整地理定位；Llanoc Hen、Tepes、Ismilkorg、Takor、Ath Cafal与Visibrot的差异会改变可用的社会、交通或经济证据。
2. **简中版本并未随DLC英文更新同步改写。** 9条描述在两份简中表中完全相同；Hongard的DLC简中键缺失。对照DLC英文时，必须把旧简中标记为旧版译文，而不是让它反过来覆盖英文。
3. **最关键的实质变化有三类**：一是删去或重写边境通道与双重地名（Llanoc Hen、Tepes、Takor、Visibrot）；二是改变袭掠方向与地理参照（Ismilkorg）；三是把资源描述具体化为销售关系（Ath Cafal）。
4. 这些变化证明的是模块文本版本异文，而不是游戏世界内部历史发生变化。不得把SandBox独有信息和NavalDLC独有信息合成一段“更完整的历史”。

## 四、后续使用规则

- 引用某一版地志时，标注模块与版本；同一 source ID 的差异要分别保留。
- 讨论帝国市场或边疆关系时，优先引用英文中仍明确存在的命题。若某命题只在SandBox出现，须明确写成“SandBox v1.4.8版本叙述”。
- 简中用于校验官方译名和译义；若DLC简中沿用旧版文本，应明确指出其未同步，不以旧译文替代DLC英文。
- `castle_village` 记录没有独立官方中文名称键的，不自创中文村名；英文源名与稳定ID作为索引。
