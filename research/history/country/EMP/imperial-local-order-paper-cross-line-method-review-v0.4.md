### 1. 语料数量与叙事单元

- 当前主体语料为13个英文 source key，附录一列出13个不重复键。
- 13键归并为9个叙事单元：秘密之手、自由民、被弃者军团、医生角色故事、阿塞莱守护者角色故事、波罗斯、安普雷拉、阿耳戈隆、密泽亚。

### 2. 原文与主要论证

逐项回读当前 SandBox v1.4.8.119303 官方英文 XML 后，主要论证均有对应原文支持，并保留其应有的不确定性：

- **秘密之手**：英文明确说其通过对当局有用而壮大；支持功能性利用的解释，但不证明正式授权。
- **自由民与安普雷拉**：英文支持边疆知识、领袖头衔、retinues、自由民马弓手招募与实际权威敌意；“选择性吸纳”是研究者的机制概括，不是游戏中的法定制度名称。
- **波罗斯**：英文地志明确以 “it is said” 引出双方邀请和裁决服从；传闻语气及缺乏判决记录的限制已保留。
- **蛮族事务局医生故事**：英文支持角色自述中的信息索取、扩权和逼供威胁；论文没有把它误写为已由行政档案核实的完整制度史。
- **阿耳戈隆与密泽亚**：英文分别支持保护、通婚和精英入席，以及保护性归附后出现竞争共和国和镇压的叙事；论文没有把两者写成同一政策的可控对照。
- **被弃者军团**：英文支持潘德拉克战役后废除最后常备军、依赖执政官私人随从队伍及军团接受合同的叙述；论文没有据此量化军制或财政规模。
- **阿塞莱守护者**：英文支持社区信任、拒绝配合、遭威胁与退出的角色故事；只作跨文化边界材料。

### 3. 官方中文名与本地化来源

- 项目百科 `encyclopedia-zh-cn.md` 中的城镇中文主名已逐项核定；正文采用中文名为主、英文名首次括注的方式。
- 当前13个英文 key 均命中英文 XML；11个 key 命中对应简中语言表。波罗斯 `rGXdJybe` 与阿耳戈隆 `LqPJY4s9` 两个描述 key 在当前简中聚落语言表中缺失，已明确标为辅助中文来源链，不伪称直接命中。
- `retinues` 采用“随从队伍”，不根据简中“私兵”一词提前推定正式法律身份。
- 当前源键核验详见《帝国官方叙事中的地方权威关系》源级与本地化审计 v0.3。

### 4. 斯特吉亚反例计数澄清

斯特吉亚报告的标题层级按 A—F 编为六个反例单元；其中 A 同时讨论森民的生产方式／空间可测量性与西比尔的直接征税／劳役。由于两者是可区分的竞争机制，帝国论文的比较表将其拆为七项机制。这是分析拆分，不是声称斯特吉亚原报告有七个编号章节。瓦兰迪亚报告仍按六组反例处理。

## 二、方法裁决

两条国别研究线的反例审查与本轮内部原文核对共同支持：论文的有效贡献是比较官方叙事中的功能性利用、选择性吸纳、受邀仲裁与正式机构强制，而不是证明存在统一的地方代理人制度。“地方权威接口”只保留为研究史工作标签与比较编码工具。

本文未把跨文化反例当作帝国制度的直接证据；未把角色自述当作独立行政档案；未把同一叙事链的连续 source key 重复计证；未从单篇地志推出制度普及率。城镇中文主名遵从项目百科；波罗斯与阿耳戈隆的本地化 key 缺口仍需在有新的语言表或版本证据时再追查，但不妨碍以英文原文开展有限的文本分析。
