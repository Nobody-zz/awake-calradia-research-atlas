# CHC-KHU-POL｜兀儿浑如何取得对旧强宗的支配权：征服、分配与条件效忠（专题工作稿 v0.1）

研究线：CHC-KHU-GEN / CHC-KHU-POL  
状态：专题工作稿 v0.1；未分配 H 编号  
日期：2026-10-24  
核心问题：兀儿浑如何将跨部族的军事领导转化为持续汗权，尤其如何处理阿契特的资深地位主张，以及库吉特等部族在征服中的损失与土地利益？

## 一、结论先行

目前最有解释力、但仍属 C 级的工作模型是：**兀儿浑的支配权由军事征服和强制军令建立，由城市征服所得、封地及筑堡资金等资源分配加以巩固，再通过誓约、保护需求和对既得土地的依赖维持；这并未消除旧部族的历史优先权主张，也没有消除部族之间的利益冲突。**

这个模型的证据并不均匀。官方生效叙述对兀儿浑领导征服、夺取城市、建立汗国并要求诸部按其命令出征有直接记载；文化总述也直接记载征服后命令那颜放弃游牧生活、授予封地和筑堡资金。相反，**阿契特究竟如何被纳入新汗权、是否曾被兀儿浑直接击败，现有生效叙述没有明确说明**。阿契特首领的先祖优先权是重要的政治主张，却不能单凭该主张证明其神话谱系或征服前的客观地位。

因此，本轮不把答案写成“旧贵族自愿让位”，也不写成“兀儿浑以一次战争消灭旧氏族”。目前证据更支持强制、资源交换与条件效忠并存，但各机制对不同部族的具体比重仍待检验。

## 二、证据层级与官方原文

### 1. 生效的官方概括：军事命令与征服资源

- SandBoxCore / ModuleData/spcultures.xml / Culture.khuzait / v5bWtXj1。英文先列纳察罕（Nachaghan）、阿契特（Arkits）、库吉特（Khergits）、喀拉库吉特（Karakhergits），再说明外部人通常以 Khuzaits 统称他们，因为某个部族在最近两代人的时间里将他们组织成征服军队。文本随后称，兀儿浑大汗接受草原边境贸易城市投降后，命令那颜放弃游牧生活，给予封地与筑堡资金，并鼓励他们将当地农民变成佃户。
- SandBox / ModuleData/spkingdoms.xml / Kingdom.khuzait / fGNdo1BK。该段回顾称，草原诸部长期以游牧、袭掠和贸易维持祖传自由；随后兀儿浑领导靠近帝国的游牧民进入帝国远东省份，征服城镇并建立汗国，迫使桀骜不驯的部族按他的命令出征。兀儿浑死后，统一精神衰退，但其后裔仍统治汗国，其他领袖则对现任可汗蒙楚格不满或希望取而代之。
- SandBox / ModuleData/heroes.xml / dead_lord_6_1 / L4b5EWdD。兀儿浑被记为征服帝国东部边疆、建立汗国的伟大可汗；部分人将其视为英雄，另一些人则怨恨他限制了先民的古老自由，将游牧领袖转变为王国封建主。

这三条材料互相补充，但不是三名独立证人：它们属于同一官方世界观体系。它们能确立官方叙述的主要机制——征服、统一军令和领地化——不能证明每个部族都以同一方式被纳入，也不能补出未记载的会战、盟约或行政程序。

### 2. 阿契特的主张：旧有优先权与条件盟誓

SandBox / ModuleData/world_lore_strings.xml / yqn4Wtwr 是阿契特领袖对蒙楚格表达的政治立场。其英文称阿契特是诞生库赛特诸部的伟大母狼的“eldest sons”，认为兀儿浑本应让他们领导征服战争；但发言者同时承认汗位与可汗旗帜，并说阿契特曾向兀儿浑宣誓，只有其继承人也守信，他们才会继续守誓。

这段话至少支持三个判断：

1. 阿契特并未在政治叙述中放弃对资深地位的主张；
2. 他们承认现存汗位和对兀儿浑所立的誓约；
3. 这种服从被表达为有条件的互惠关系，而不是承认自身永远没有独立权利。

但它是一个氏族领袖的自我陈述。母狼谱系属于起源神话；“本应领导征服战争”是政治正当性主张，不是关于当年会议或选汗程序的中立记录。它不能独立证明阿契特确实在征服前居于所有部族之上，也不能证明兀儿浑曾与阿契特签订一份具体条约。

### 3. 库吉特的经验：征战损失、土地风险与保护需求

SandBox / ModuleData/heroes.xml / lord_6_4 / ALtZaRzc 记载，墨速宜是库吉特首领；库吉特曾是联盟中最大的部族之一，却在兀儿浑的征战中蒙受重大损失，其土地随后受到其他部族觊觎。墨速宜也批评较小部族为汗国流血，却没有得到应有回报。

其政治对白提供了更具体的利益语言：

- dpYb59BB：库吉特在库赛特的战争中遭受巨大损失；
- RyrdJI5j：墨速宜解释其他部族觊觎库吉特的土地和财富，而她无法独力对抗所有对手；
- l4quU1x3：只要蒙楚格仍然强大，其他部族就不敢公然觊觎库吉特的土地和畜群；强大的可汗可以成为弱小部族的祝福。

这不是简单的“地方氏族都反对中央集权”。库吉特既对战争代价与分配不公感到不满，又需要一个足够强大的可汗威慑其他部族。保护需求与对汗权的批评可以同时存在。

### 4. 汗室的土地来源论：征服者为何要求服从

蒙楚格在 YZyaxSbH 中把先祖兀儿浑描述为攻陷城市、将土地分给各部族的人；在 zR1ONwM8 与 6roMVNMW 中，他又把不满首领的离开描述为放弃祖先授予的土地、回到大草原。

这是一套可辨识的统治正当性语言：汗室把征服与分地视为自身要求服从的依据。它与阿契特的“先代资历—互惠誓约”主张并不相同。前者强调谁有能力征服、授地和命令，后者强调谁有更古老的地位以及双方是否守信。

蒙楚格的话是统治者的政治主张，不是土地法典。它证明汗室试图以征服和分地正当化权力，不能证明所有氏族都承认其说法，或可汗已拥有普遍、无条件的撤封权。

## 三、开发注释：有价值，但不能当作正式世界史

SandBox / ModuleData/spclans.xml 的 XML 注释提供两条额外线索：

- 库吉特注释称，他们是最早被兀儿浑征服的部族之一，曾被武力纳入联盟，之后成为重要战士并从新征服的领地获得土地；战争导致其男性成员大量损失，阿契特后来曾试图争夺其领地。
- 阿契特注释称，该部族曾是库赛特故地最富有、最有威望的部族，而兀儿浑及其追随者起初只是地位较低的旁支。

这些内容是官方文件中的开发注释，不是生效的氏族描述或具名人物的正式历史传记。尤其阿契特注释把“图拉格（Tulag）”写成当时可汗，又把“蒙楚格（Monchug）”写成阿契特首领；这与生效字段和人物传记中蒙楚格执掌兀儿浑乃特、阿契特由另一名领袖执掌的配置不符。因此，这些注释很可能保留了早期设计阶段的人物安排，不能把其中的具体人名、年代和行动直接移植为终版历史。

它们可以作为设计史证据，提示官方创作曾有意构造“旧有声望—新兴军事统治”的对照；但不能作为独立证人，证明阿契特的历史地位、库吉特被征服的确切过程，或阿契特实际夺取了某块领地。

## 四、结构化数据能证明什么

生效的 SandBox / ModuleData/spclans.xml 将兀儿浑乃特配置为现任汗室所属氏族（clan_khuzait_1，领袖 Hero.lord_6_1），库吉特为 clan_khuzait_2（领袖 Hero.lord_6_4），阿契特为 clan_khuzait_3（领袖 Hero.lord_6_5）。英雄字段又记载，阿契特的库由格（Kuyug，dead_lord_6_3）曾任该部大那颜，而现任领袖的父亲字段指向库由格。

这些字段支持的是 1084 年开局配置及部分亲属关系。氏族 tier、当前据点和开局领袖不能反推兀儿浑时代的历史等级；库由格的官职也不能证明阿契特从征服前到 1084 年一直保持同样的权势。

## 五、竞争解释及当前证据评级

| 解释 | 支持证据 | 主要限制 | 当前判断 |
|---|---|---|---|
| 军事征服与强制指挥 | 王国沿革明确记载征城、建汗国和强制出征 | 没有明确说明阿契特具体如何被征服或接受汗权 | 对总体机制支持强；对阿契特个案不足 |
| 征服资源与土地分配 | 文化总述记载封地、筑堡资金、佃户安排；蒙楚格以分地解释统治权 | 不知道每一氏族实际获得何种资源、何时获得 | 对制度方向支持强；具体分配仍不明 |
| 旧强宗通过盟誓接受新汗权 | 阿契特的政治对白承认汗位并提出继承人守信条件 | 该对白是当事者主张，不能证明最初谈判过程 | 对政治意识形态支持中等；对历史事件仅间接支持 |
| 旧贵族自愿让位，或被彻底摧毁 | 没有足够生效叙述支持任一极端版本 | 缺少阿契特与兀儿浑之间的具体事件记录 | 暂不采纳 |

## 六、阶段性结论

兀儿浑的支配权最可能通过三个相互联系的机制形成：

1. **军事权力上移：** 从诸部自行决定何时出征，转向按可汗命令组织战争；
2. **征服收益再分配：** 城市、封地、筑堡资金和对农业人口的控制，为氏族精英提供了接受新秩序的物质利益，同时把其权利与汗室的征服功绩联系起来；
3. **条件效忠与保护关系：** 阿契特保留资深地位与盟誓条件，库吉特强调战争代价和安全保障，汗室则强调先祖征服与土地授予。这些不同主张使汗权既有实际资源基础，也持续受到氏族利益的约束。

**结论等级：C 级工作模型。** 军事征服、统一军令和领地化有直接官方叙述支持；“旧强宗的优先权被新兴汗室压过”是有材料支持的结构解释；但阿契特是否被兀儿浑直接征服、其服从最初由何种协议保证，仍然未知。

## 七、尚未解决的问题与下一步

- 阿契特的优先权主张究竟反映了可验证的征服前地位，还是主要是一种政治起源神话？
- 是否存在生效官方文本，明确描述兀儿浑与阿契特之间的战事、盟誓或权力交接？
- 库吉特的强制臣服与受封经历，是否能在其他氏族的生效文本中找到可比较的案例？
- 土地授予、筑堡资金与军事征召之间是否存在明确的条件关系，还是仅在不同叙述中被并列呈现？

下一轮优先转入 P2：将那颜领地化、喀拉库吉特抵制、普通生产者的强制定居与地方保护叙述放在同一框架，比较汗权如何通过强制、利益交换和安全保障改变不同群体的政治选择。
