# CHC-NOR-GEN｜诺德史下一阶段执行计划与验收门槛

版本：v0.7｜2026-10-24
状态：执行计划；不占 H 编号；不修改公共 I/Q 索引或世界书正典。

## 一、总目标

重建北方社会从区域性共同体、迁徙与海洋经济网络，到诺德维格王国形成、王权持续运行及1084年前后政治格局的历史过程，并解释这些变化与斯特吉亚、卡拉德帝国、巴旦尼亚、库赛特、瓦兰迪亚及大陆海洋交通之间的关系。

核心不是“写完诺德王国通史”，而是建立能回答下列问题的可审查证据结构：哪些社会变化早于统一；地方共同体如何连接；海洋财富何时、如何转化为政治资源；王权如何使用、替代或限制既有制度；国家统一后哪些地方关系仍然自主；海外诺德人与王国之间究竟有什么关系。

## 二、执行原则

1. 先用已有材料构建问题结构，不因发现新台词就自动开新论文。
2. 以有效官方英文原文为语义基准；官方简中用于核实译名、记录翻译差异，不以简中覆盖英文含义。
3. 区分游戏内历史叙述、人物自述、地方传说、结构化字段、开发日志和注释/废弃文本。
4. 采用相对年代与区域性分期；只有来源支持时才建立绝对年代。
5. 将诺德文化、北方居民、诺德维格臣属、海外诺德人及王室代理人分开识别。
6. 同一官方叙述在不同文件中的复述不算独立互证；其他国别线的共同事件只登记接口，不替对方定论。
7. 证据薄弱处明确保留未知；不以现实维京史或其他国家制度填补卡拉迪亚史料空白。
8. 每一阶段必须产生可回读的实际成果；计划、审查意见和索引更新均不能代替正文研究。

### 第5批｜解释模型比较与论文决策（第一轮完成，保持可修订）

第一轮综合稿已形成 CHC-NOR-GEN-relative-chronology-causal-test-v0.1.md；针对哈尔达尔继位与实际控制范围的证据矩阵已形成 CHC-NOR-GEN-halthdar-kingship-continuity-control-v0.1.md。当前暂定“选择性集中与地方权力并存”的复合模型：军旅财富提供条件，强制与收买推动臣属关系变化，土地、婚姻、职位确认和继承政治尝试延续统治；其后的合法性与执行能力仍然脆弱。此为 C 级解释而非正典。

只有当主要区域和时间层次有可审查记录、关键跨国关系已登记、重大资料空白已说明、至少两个竞争解释能由不同证据加以区分时，才决定下一篇论文。可能形成国别专题、区域比较、跨国关系史或社会史专题；不预先规定一定要写一篇完整通史。

## 五、与全大陆研究纲领的连接

诺德线优先接入全大陆问题图谱中的：
- RQ03：建立跨区域相对年代网络；
- RQ09：辨析不同共同体的最高统治权及地方权力；
- RQ17、RQ22：检验海外雇佣财富、土地授予与外围王权形成之间的关系；
- RQ37：检验各外围政治共同体形成时间是否真的同步；
- RQ40：解释诺德—斯特吉亚联系与不同王权道路；
- RQ41：评估海洋贸易是否要求重写以大陆帝国为中心的历史框架；
- RQ54：确定哪些发现会迫使研究放弃或修正宏观模型。

这些问题是优先接口，不是诺德线必须独立解决的全部问题。诺德研究对全大陆模型提供证据和反例，宏观综合由总协调研究处理。

## 六、阶段验收与停止条件

本阶段只有在以下条件同时基本满足时，才进入正式论文选题排序：
1. 主要北方区域均有基础记录，且不以诺德维格疆界代替整个北方社会；诺德文化聚落的全部叙述字段均已标注为实质分析、局部分析或未分析；
2. 主要事件拥有相对年代标签，未能排序之处明确保留；
3. 关系卡能够追溯到有效英文原文及版本，中文译名经官方语言表核实；
4. 关键跨国关系有对应研究线的核验状态；
5. 经济、宗教、家庭、普通劳动与地方司法的空白被单独登记；
6. 至少两种竞争性解释具有可区分的证据与明确反证条件；
7. 新论文的独立贡献、材料缺口和相对于既有工作稿的新增价值能够说明。

## 七、当前执行决定

当前主交付物仍是诺德历史过程的可检验证据结构，不是为了形式完整而撰写通史。相对年代、因果机制和哈尔达尔时期王权持续性已形成首轮综合稿；新完成的氏族/聚落覆盖审计明确纠正了此前“首轮覆盖”容易被误解为“逐条研究完毕”的问题。下一步先补完八条遗漏地志并登记八个跨国聚落接口，再回到有效英文原文核查王国沿革中“his sons rule”、哈尔达尔君主字段及阿丝葛莎传记的许尔夫统治说法，之后继续检验创立者死后哪些王权能力能够重复执行，尤其是军役、船只、土地与司法。每项判断必须回到英文原文及其版本，明确是直接记述、局部关系、历史推论还是未知；跨线材料只用于校验诺德问题，不取代诺德研究。所有成果回读 GitHub 和 Google Docs；不改公共 I/Q，不预占 H 编号，不把未证解释写入正典。
