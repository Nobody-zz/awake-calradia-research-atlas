# CHC-NOR-GEN｜跨国史料核验第一批：安普雷拉、厄毗诺萨、拉达克梅德与迪纳尔

版本：v0.1｜2026-10-25  
状态：第一轮跨线核验完成；政治年代与具名事件归属仍待查。  
主底本：Bannerlord SandBox v1.4.8 与 NavalDLC / War Sails v1.2.8 的官方英文聚落地志；官方简体中文仅用于译名核对及记录本地化异文。  
研究边界：不修改公共 I/Q，不分配 H-000x 编号，不把官方设定叙述的改写拼接成游戏世界内部的连续年代史。

## 一、核心发现：四处主要问题不是普通的“中文翻译错了”

四个聚落的同一对象/文本键在 SandBox 与 NavalDLC 英文中发生了显著改写，而随包官方简体中文描述仍保留较早的场景或叙事。因而第一步应定性为**跨版本文本改写与本地化内容滞后**，而不是笼统地把每一处都归为翻译质量问题。

这一区分直接影响历史论证：旧版英文与简中可用来说明早期官方叙事版本；NavalDLC 英文可用来说明当前 DLC 版本的官方叙述。二者不是游戏世界内两个先后发生的历史阶段，不能写成“后来河道改道”“原来捕毛皮、后来转捕海象”或“旧人口被新版人口替换”等连续历史事件。

## 二、四个节点的逐项核验

### 1. 安普雷拉 Amprela｜帝国城镇

**源定位**：`town_EN6`；地志文本键 `YYYxOiCq`；官方中文名称“安普雷拉”。

**SandBox 英文叙述**：帝国远东北部的主要城镇；北、东、西边境要塞以信号警示掠袭者；由 Eleftheroi 自由民组成的马弓手等待出击对抗草原骑兵；具装骑兵与斯特吉亚王公争夺伊勒坦湖间运输线的贸易控制权。

**NavalDLC 英文叙述**：城镇仍位于帝国东北部，但防务场景改为北、东边境信号；自由民马弓手等待对抗库赛特草原骑手、斯特吉亚森林战士或沿 Caracasos 河而下的诺德长船；具装骑兵在城堡庭院训练，准备在执政官需要时集结军队应对更大威胁。

**官方简中情况**：随包简中保留较早版本的叙述，未呈现 NavalDLC 英文新增的诺德长船威胁，也未完整反映“更大威胁—执政官集结军队”的新版结尾。

**可直接支持**
- NavalDLC 的帝国边境视角明确将沿 Caracasos 河南下的诺德长船列为潜在军事风险之一。
- 同一段同时列举库赛特骑手、斯特吉亚森林战士与诺德长船，说明帝国东北防务面对不同方向和方式的威胁。
- 自由民马弓手与具装骑兵在同一城镇地志中出现，但文本没有建立两者属于同一编制、同一战役或同一指挥链。

**不能推出**
- 不能据此断言诺德长船已经袭击安普雷拉、实际抵达某个具体河段，或发生过一场可命名的战役。
- 不能把“诺德长船”直接等同于诺德王国正式舰队；地志没有说明船只所有者、指挥者或行动授权。
- 不能将边境信号、自由民招募、斯特吉亚竞争和诺德船只威胁合并成同一历史事件。
- 不能由单篇城镇地志重建帝国常备军、正式征兵制或长期固定边界。

### 2. 厄毗诺萨 Epinosa｜帝国村庄

**源定位**：`castle_village_EN7_1`；地志文本键 `Settlements.Settlement.text.castle_village_EN7_1`。现有语言表未发现独立的官方中文聚落名称键；“厄毗诺萨”沿用项目现有研究工作译名，不冒称专名键官方译名。

**SandBox 英文叙述**：该地位于帝国极北、伊勒坦冰川湖运输线以南；船只在拉科尼斯湖与塔奈西斯湖之间拖运；人口稀少，绿色高地放牧大群牛只。

**NavalDLC 英文叙述**：该地被描述为河流环绕的舌形地；北支 Caracasos 的名称源于斯特吉亚语 Karakaz，而 Karakaz 又源自库赛特语；诺德人称该河为 Jumne，并将其解释为源自斯特吉亚语中“barrow（墓冢）”一词；南支称 Davuna；当地人在河岸沼泽草地放牧牛群。

**官方简中情况**：仍保留旧版冰川湖拖船、两湖之间转运及高地牛群的叙述，未呈现当前 NavalDLC 英文的河道分支与多语地名链。

**可直接支持**
- 当前英文官方文本明确把 Caracasos、Karakaz、Jumne 置于一个相关的跨语言命名链中，并称 Davuna 为南支河名。
- 文本把诺德语名称与斯特吉亚语词源联系起来，也把 Karakaz 与库赛特语言来源联系起来。
- 该聚落仍被描述为畜牧地带，说明河流与沼泽草地也承担生产空间功能。

**不能推出**
- 不能凭这一段重建完整的诺德语、斯特吉亚语和库赛特语谱系，也不能将文本词源解释当成独立语言学证据。
- 不能在缺乏地图拓扑校验的情况下断言 Caracasos、Jumne、Karakaz 在所有河段、所有版本中完全重合。
- 不能把旧版伊勒坦运输线和新版河道地志拼接为同一时间、同一地理状态。
- 不能因为地名有跨语言联系就断言存在某一特定民族迁徙、国家边界或战争年代。

### 3. 拉达克梅德 Radakmed｜斯特吉亚村庄

**源定位**：`village_S6_2`；斯特吉亚城镇西比尔所属村庄；官方简中名称“拉达克梅德”。

**SandBox 英文叙述**：位于车尔特格山脉盆地，崎岖荒野以狐狸、貂和兔子等毛皮动物著称。

**NavalDLC 英文叙述**：村庄改为比亚里海沿岸环境；当地许多家族追溯到南迁诺德人，或追溯到放弃森林游动生活的瓦肯人；居民夏季向北远航捕猎海象，肉供食用、象牙用于交易、脂肪用于照明。

**官方简中情况**：仍保留基础版的山地盆地与毛皮动物场景，未反映当前英文的沿海位置、诺德家族祖源和远北海象捕猎。

**可直接支持**
- NavalDLC 叙述把当地部分家族的祖源记忆与南迁诺德人联系起来，同时也提到瓦肯人；当地社会被描绘为混合来源，而非单一族属。
- 夏季远航捕猎海象将季节性劳动、海洋资源和家庭生计联系起来；文本还区分肉、象牙与脂肪的用途。
- 该地属于斯特吉亚聚落，却具有诺德祖源记忆和远北海洋活动，说明文化联系、经济活动与政治归属不能混为一谈。

**不能推出**
- 不能将该村庄的海象捕猎视为诺德王国组织的国家行动。
- “许多家族追溯到南迁诺德人”是官方地志所述的祖源记忆，不等于完整家谱、精确迁徙年代或所有居民的族属统计。
- 不能把基础版的毛皮经济与 NavalDLC 的海象经济写成当地历史上已证实的产业转型；这是同一 ID 的跨版本叙事改写。
- 不能从夏季远航推定船只所有权、船员组成、收益分配或固定贸易合同。

### 4. 迪纳尔 Dinar｜库赛特村庄

**源定位**：`castle_village_K6_1`；相关城堡为 `castle_K6`（Dinar Castle）；两者均归入库赛特聚落记录。当前帝国聚落源级表没有发现另一个帝国 Dinar。官方简中地志未同步当前 NavalDLC 英文内容。

**SandBox 英文叙述**：寒冷、近乎无树的山丘与冻结河风；居民饲养羊群，以厚羊毛适应严寒。

**NavalDLC 英文叙述**：近期诺德扩张迫使朱姆内河谷的难民向南迁移；他们与近期从草原抵达的部族通婚，并在草原地带放牧绵羊。

**官方简中情况**：保留旧版寒冷山丘、冻风与羊毛适应描述，遗漏新版的诺德扩张、朱姆内河谷人口南迁和通婚关系。

**可直接支持**
- 官方当前英文将诺德扩张与朱姆内河谷人口向南迁移明确联系起来。
- 文本称这些难民与新近从草原抵达的部族通婚，且现于草原牧羊。
- 这是目前四处材料中最明确直接涉及诺德扩张所造成的邻国人口后果的一条。

**不能推出**
- “recent”是相对于地志叙述时点的相对时间，不能转换为某个确定年份。
- 文本没有给出具体战争、诺德国王、军队、战役、人口规模或迁徙路线。
- 不能认定所有难民均为诺德人，亦不能认定通婚全由强制、全由自愿或由某种正式政治条约安排。
- 不能把此条与安普雷拉的诺德长船威胁自动串成同一次军事行动；两条文本没有明确的同期或因果连接。

## 三、四处材料合起来能说明什么？

目前可以建立的，是一个**区域关联模型**，不是一条已完成定年的统一战争史：

1. **海上与河道军事风险**：安普雷拉的当前英文地志将诺德长船沿 Caracasos 河而下列为帝国边境需应对的威胁。
2. **跨语言地理知识**：厄毗诺萨地志保留 Jumne、Karakaz 与 Caracasos 的命名关系，表明该地区在官方设定中是多语言接触地带。
3. **人口与家庭来源**：拉达克梅德地志把部分家庭祖源与南迁诺德人联系起来，也记载瓦肯家族及夏季海象猎捕。
4. **扩张造成的人口后果**：迪纳尔地志明确记载诺德扩张迫使朱姆内河谷难民南迁，并与草原新来者通婚。

这四点使“诺德活动超出本国疆域，并改变邻近地区的军事想象、人口构成和生计网络”成为合理的综合解释。但仍不能宣称四条材料记录同一次扩张、同一支舰队、同一位君主或同一年代。当前最稳妥的因果判断只存在于 Dinar 自身的句子内部：官方叙述明确把诺德扩张与难民南迁联系起来。

## 四、对诺德史核心解释的影响

### A. 军事征服与个人威望

安普雷拉和迪纳尔支持诺德扩张具有军事与人口后果的设定，但没有提供可识别的国王、将领、战役或绝对年代。它们暂时不能证明王权集中是扩张的原因，也不能证明扩张完全由王权统一组织。

### B. 海洋经济与财富集中

拉达克梅德直接呈现海象肉、象牙和脂肪的不同用途；安普雷拉则呈现长船作为帝国边防所关注的军事风险。两条材料共同说明海洋活动具有生计和安全两个面向，但没有证明海上财富流入诺德王室，更没有证明王室控制海象或河道贸易。

### C. 地方社会、混合家庭与边疆整合

拉达克梅德的祖源叙述与迪纳尔的通婚记载都提醒研究者：人口迁徙不会只表现为王国疆界移动。移民家庭、当地居民和新抵达的草原群体可能在地方社会中形成混合关系。但目前没有足够材料确定婚姻如何影响土地、牧场、身份、语言或政治忠诚。

**暂时判断**：三种国家形成解释仍然都未被排除。四处材料更适合证明诺德扩张的区域性影响，而非直接解释诺德王权自身如何建立。

## 五、证据独立性与版本纪律

- EMP、STU、KHU、NOR 与 CGEO 的相关工作稿对同一聚落地志的引用属于多线分析，不是多份独立原始证词。
- 当前英文与官方简中不一致时，应保存为同键版本/本地化异文。不得用旧简中补全当前英文，也不得把旧版与 DLC 版自动编成世界内部的前后年代。
- Epinosa 的“厄毗诺萨”是现有研究工作译名；未找到独立官方中文专名键，引用时应保留 Epinosa 原文。
- “Nord longships coming down the Caracasos River”是官方文本的威胁场景，不是某场已证实袭击的战报。
- Dinar 的“recent Nord expansion”是相对年代词，禁止凭空换算成绝对年份。
- Radakmed 的南迁诺德人属于地志中的家族祖源叙述，不应直接等同于诺德王国领土扩张。

## 六、下一批最值得追查的问题

1. **“recent Nord expansion”指什么？** 对照诺德王国沿革、沃尔比约恩相关叙述、诺德人物传记与其他官方英文地志，查找是否有具名统治者、战事或相对年代锚点。若没有，应保留为未识别的扩张事件。
2. **朱姆内河谷的边防网络是什么结构？** 将安普雷拉、厄毗诺萨、罗卡那（Lochana）及哈加德的当前 NavalDLC 英文地志逐条对读，区分防御位置、河道命名、市场和潜在运输路线。
3. **诺德移民与斯特吉亚地方社会如何连接？** 把拉达克梅德与克沃尔、卡格雷夫、瓦尔诺瓦波尔、西比尔等条目比较，分别识别祖源记忆、季节性劳动、商人据点和军事夺取，避免归为单一扩张机制。
4. **库赛特边境的人口后果是否有独立线索？** 复核迪纳尔及卡拉哈利的当前英文地志，寻找其他聚落对流民、通婚、牧场和诺德—斯特吉亚争夺的记载。
5. **跨版本的语言表滞后是否系统性存在？** 以四条为样本，继续检查其他 NavalDLC 同键英文发生大幅改写、但简中仍保留 SandBox 内容的聚落；把“翻译错误”与“版本文本未同步”分开登记。
