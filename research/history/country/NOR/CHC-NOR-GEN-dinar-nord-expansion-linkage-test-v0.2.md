## 一、v0.2 对上一版的修订

v0.1 正确地没有把迪纳尔的“recent Nord expansion”归于某位具名国王或某场战役，但其调查范围没有充分纳入 NOR 既有关系卡 05 已登记的诺德流浪者朱姆内经历，也没有将 Hargard、Faergap 与 Grud 等东向聚落叙述作为一组比较。此处补正。

**修订后的判断是：具体事件仍未识别，但“诺德向朱姆内河谷推进”已有一组不同叙述体裁的官方文本共同描绘。** 这些文本能支持一个关于迁徙、定居、资源竞争和边疆人口变化的区域模型，却仍不足以证明它们记录同一次行动，或由诺德王室统一组织。

## 二、最直接的材料：迪纳尔地志

**源定位**：`Modules/NavalDLC/ModuleData/settlements.xml`，聚落 ID `castle_village_K6_1`，文本键 `Settlements.Settlement.text.castle_village_K6_1`；官方名称 Dinar，简中“迪纳尔”。

当前 NavalDLC 英文称，迪纳尔位于库赛特联盟最北部的喀拉卡孜河沿岸；近期从草原抵达的部族与因“recent Nord expansion”而被迫从朱姆内河谷南迁的难民通婚，村民在草原开阔地带牧羊。

**直接支持（A）**
- 官方文本明确把近期诺德扩张与朱姆内河谷难民南迁联系起来。
- 难民与新近从草原抵达的群体之间发生通婚。
- 地志把这批人口与迪纳尔的草原牧羊生活放在同一叙述中。

**不能推出**
- 没有具名国王、雅尔、军队、战役、绝对年份、迁徙人数或完整路线。
- 没有说明难民是瓦尼人、瓦肯人、斯特吉亚人或其他特定族群。
- 没有说明“expansion”专指王室军事征服；它也可能包括领土推进、移民定居和对既有土地使用方式的挤压。
- 不能把该条直接与某一场诺德战争、安普雷拉的长船威胁或沃尔比约恩的统一战争合并。

**版本与翻译**：SandBox 同 ID 的旧英文描述仅谈东北草原吹来的冰寒冬风与羊毛厚重；当前 NavalDLC 英文改为人口迁徙与通婚叙述。随包官方简中仍保留旧版气候与羊毛场景。因此这里应登记为同 ID 的跨版本文本改写及简中内容滞后，不是普通的局部漏译，也不能把两版拼成产业/人口的先后变化。

## 三、补入的关键材料：诺德移民的第一人称经历

**源定位**：`Modules/NavalDLC/ModuleData/naval_dialog_strings.xml`，人物背景 `spc_wanderer_nord_2n`；关键语言键为 `hl0oYfvf`、`PG95aHx1`、`gGLcvhD9`、`DN6XgaS3`、`gjU6kqvS`。随包官方简中语言表 `std_naval_dialog_strings_xml-zho-CN.xml` 对这些段落均有对应条目。

这是一段诺德出身的治疗者讲述自己家庭经历的第一人称背景，不是王室编年史，也不是对整个河谷人口的统计。

**叙述内容**
1. 叙述者出生在特龙德拉格附近的农场，家人后来迁往朱姆内河附近的新土地。
2. 家人因听说当地有可供占用的耕地而迁入；到达时当地已有瓦尼人。叙述者说瓦尼人住在树林中，并起初容许新来者使用河边开阔草地。
3. 为确定土地使用安排，叙述者被嫁给瓦尼酋长之子，并伴随布匹和斧头等物资交换。
4. 后来更多诺德人跟进。瓦尼人认为新移民的来去破坏狩猎资源，因而认为原有安排已被破坏。协商没有结果，瓦尼人杀死了田野中的一些诺德人。
5. 叙述者的诺德兄弟随后要求她毒害瓦尼丈夫的家人；她拒绝并在夜间离开，既不愿回到兄弟身边，也不愿回丈夫家。

**直接支持（A，限于该人物的自述内容）**
- 诺德人向朱姆内迁移的一个动机是获取耕地，而非文本明示的王室军事命令。
- 当地原有群体与新来者曾通过土地使用安排、婚姻和物资交换协调关系。
- 后续移民增加后，土地和狩猎资源压力使安排破裂，并引发谈判失败、杀戮及亲族内部的报复要求。
- 迁徙过程涉及家庭选择、跨群体婚姻与个人离开，不只是王国边界线的变化。

**不能推出**
- 这位叙述者的故事发生于迪纳尔所说的同一波“近期扩张”；文本没有提到 Dinar 或南迁难民。
- 瓦尼人被迫南迁。自述只说部分诺德人被杀，且瓦尼人希望其他诺德人离开；它没有记载瓦尼人随后逃往南方。
- 瓦尼人与瓦肯人是同一族群。Hargard 地志分别使用 Vakken，而人物自述使用 Vanni；在没有额外官方文本前必须保留这一区别。
- 所有诺德迁徙均由诺德维格王室组织，或婚姻安排是全国统一制度。

**译文校勘**：本段官方简中对家庭迁移、耕地动机、瓦尼人既有居住、土地安排、婚姻交换、后续移民及冲突过程均有对应，没有发现像迪纳尔地志那样的整段内容滞后。因此这条材料可按当前 NavalDLC 英文叙述分析，无须把其核心问题归咎于中文翻译。

## 四、与河谷地志组成的空间—时间链

### 1. 哈加德 Hargard：较早的东向推进

**源定位**：`settlements.xml`，`town_N4`，文本键 `zh2tG1MX`。

地志称诺德部落向东推进至黑暗森林，并在“several generations ago”建立哈加德要塞。该要塞俯瞰诺德人称为朱姆内的河流；在叙述当前时点，河流是诺德王国东部领地的主要交通动脉，也是诺德人、瓦肯人、斯特吉亚人和部分森林地带草原族群交换河谷财富的场所。

**支持（A）**：官方设定直接描述了较早的诺德东向推进、建堡，以及后来河谷交通和多族群交换的作用。  
**限制**：不提供绝对年份、具体战争、统治者姓名或王室命令；不能将其与迪纳尔“近期扩张”认定为同一次战事。

### 2. 法尔加普 Faergap：迁徙路线的物质痕迹

**源定位**：`settlements.xml`，`village_N4_3`，文本键 `PKlv8jCB`。

该地志描述一条连接比亚里海东岸与朱姆内河谷的山口通道，并称旅人可以看到诺德移民刻在巨石上的如尼铭文，以感谢诸神保佑旅途平安。

**支持（A）**：官方文本将该山口与诺德移民进入朱姆内河谷的旅程联系起来。  
**限制**：铭文没有给出具体移民群体、年代或迁徙原因；不能仅凭铭文推出国家殖民计划。

### 3. Grud Grud：雅尔属员、河东前哨与指代歧义

**源定位**：`settlements.xml`，`village_N4_1`，文本键 `dwkbyCqk`。

地志称Grud是哈加德雅尔的 thegn，并把他、朱姆内河东岸的前哨和以其名命名的村庄联系起来。但英文“who established an outpost”的关系从句存在指代歧义：它可能修饰Grud，也可能修饰离它更近的哈加德雅尔。简中“后者在朱姆内河东岸建立了一座哨站”也没有消除这一歧义。

**支持（A，限于文本直接关联）**：Grud与哈加德雅尔存在属员关系；文本还记载朱姆内河东岸有一座前哨，并称村庄以Grud命名。  
**限制**：前哨建立者的语法指代并不确定，不能把它作为“Grud本人建立前哨”或“哈加德雅尔亲自建立前哨”的定论。建立时间、军事规模、土地授予条款及王室是否参与也未知。

### 4. 于利克舍恩 Ulikshorn：另一条南迁叙述，但不是同一批难民的证据

**源定位**：`settlements.xml`，`castle_village_N9_1`，文本键 `0kDUOy2G`。

该地志称朱姆内河穿过伊勒坦辛德伦山丘；边境另一侧的山区部族曾被进一步向南驱赶，并被库赛特联盟吸收。

**支持（A）**：官方叙述中存在边境山区群体被向南推移并纳入库赛特联盟的过程。  
**限制**：该句指的是山区部族，未把他们称作朱姆内河谷难民，也未将其南迁归因于诺德扩张。不能拿它来确定迪纳尔难民的身份。

### 5. 特拉阿托普 Thralathorp：河谷流出人口的另一种原因

**源定位**：`settlements.xml`，`castle_village_N9_2`，文本键 `DJCei132`。

该地志称此地由朱姆内河谷不同领地的逃亡者和逃跑者建立，位于诺德主要聚居区以东的草原边缘，并遭遇频繁的库赛特袭击。

**支持（A）**：朱姆内河谷人口向外迁出不仅被描述为诺德扩张导致的难民南迁，也存在逃离领地的另一种情形。  
**限制**：文本没有说明这些逃亡者与迪纳尔难民是同一群体，也没有说他们是因诺德扩张离开。

### 6. 卡拉哈利 Karahalli：更广泛的边疆竞争

**源定位**：`settlements.xml`，`castle_village_K6_2`，文本键 `VbQhrOU9`。

当前 NavalDLC 将该地描述为斯特吉亚人与诺德人争夺的北部边疆；SandBox 旧英文只点名斯特吉亚人。

**支持（A）**：当前版本把诺德人与斯特吉亚的竞争纳入库赛特北部边疆叙述。  
**限制**：未给出战役、年代或与迪纳尔难民的直接联系；这是区域竞争背景，不是同一事件的战报。

## 五、与诺德王国沿革及王室人物的对照

**源定位**：
- `Modules/NavalDLC/ModuleData/kingdoms.xml`，`Kingdom id="nord"`，文本键 `m6ZgnpN9`；
- `Modules/NavalDLC/ModuleData/heroes.xml`，`dead_lord_7_1`（沃尔比约恩，`wKMRsw16`）与 `lord_7_1`（哈尔达尔，`Bule74H4`）。

王国沿革把沃尔比约恩回乡并统一北方置于“一代人以前”，称他在帝国卫队服役十年后带着财富返乡，以战斗、收买及内部倒戈迫使酋长向其宣誓成为雅尔。当前叙述时点由其儿子们统治，并说他们“may”通过让臣属关注征服来加强王国纽带。哈尔达尔传记则强调地方雅尔对其父以血腥和诡计建国的不满。

**可以建立的关系**
- “数代以前”哈加德的建堡与“一代以前”沃尔比约恩统一，在文本的相对时间表述上呈现不同历史层次；不应将所有东向扩张都压入王国统一战争。
- 王国沿革把征服列为当前统治者可能采用的策略，但 “may” 不是已发生征服的证据。
- 迪纳尔没有指名沃尔比约恩、哈尔达尔或王室军队；Grud 则将一位雅尔属员、河东前哨与以其名命名的村庄联系起来，但未明确前哨建立者。由此，区域扩张可能涉及不同层次的政治和社会行为者。

**仍不能确定**
- 迪纳尔的扩张是否发生于哈尔达尔统治期间。
- 是否有一场正式王室远征迫使某一特定族群南迁。
- 地方雅尔、属员、普通移民与王室在各次迁徙中分别承担什么角色。
- Dinar 的难民是否为 Vanni、Vakken 或其他河谷群体。

## 六、竞争性解释与当前判决

### H1｜迪纳尔记载的是沃尔比约恩统一战争的一部分

**判断：缺乏直接支持。** 王国沿革明确记载统一，但没有提到朱姆内河谷、迪纳尔或这批难民。相对年代也不能直接对接。

### H2｜这是沃尔比约恩儿子们发动的王室征服

**判断：可能，但未证。** 王国沿革提出通过征服加强臣属纽带的可能策略；没有文本证明这项策略已经实施，更没有将它与迪纳尔联系起来。

### H3｜这是持续数代的诺德东向拓居与边疆扩张中的较新阶段

**判断：作为区域模型，支持度上升（C）。** 哈加德的早期建堡、法尔加普的移民铭文、Grud与河东前哨的关联、诺德移民的耕地迁入和后续资源冲突，以及迪纳尔的南迁难民叙述，共同呈现出从移民拓居、地方协商到边疆冲突与人口移动的多层次过程。但它们并未证明是同一条无间断的历史链，也未识别迪纳尔扩张的具体行动者。

### H4｜“扩张”可能同时包括人口定居和土地使用方式的推进，不必然等同于王室战役

**判断：有解释力的竞争模型（C）。** 第一人称故事把迁移动机写成获取耕地，并把后续冲突归因于移民增加、狩猎资源受损和谈判失败；Grud条目则将一位雅尔属员、河东前哨和以其名命名的村庄联系起来，但未明确建立者身份。这些材料表明，官方设定中的东向推进可以通过家庭移民、地方协商和属员拓居等形式表现。它们没有排除军事征服，只说明不应把“Nord expansion”先验地限定为国王指挥的战争。

### H5｜迪纳尔的难民就是瓦尼人或瓦肯人

**判断：不支持（D）。** 瓦尼人出现在第一人称移民故事，瓦肯人出现在哈加德地志，但迪纳尔没有命名难民群体；Vanni 与 Vakken 也不能仅凭名称相似合并。

**当前判决**：保留事件名为“具名行动者与年代未识别的诺德扩张”。同时，把较宽泛的区域过程登记为“朱姆内河谷的诺德东向拓居、地方协商与资源冲突，以及较晚的南迁难民叙述”。前者是尚未识别的具体事件，后者是由多条官方叙述综合出的 C 级区域模型，两者不得混写。

## 七、证据独立性、版本与翻译纪律

1. 所有材料均来自同一官方游戏文本体系；地志、人物传记和流浪者背景是不同叙述体裁，不是现实世界中独立档案的互证。
2. 同一流浪者的 `PG95aHx1`、`gGLcvhD9`、`DN6XgaS3` 属于同一人物背景的连续段落，不能按三个独立证词计数。
3. 当前 NavalDLC 的哈加德、法尔加普和Grud叙述在官方简中中有对应内容；朱姆内流浪者自述也有对应简中段落。本轮未发现这些关键内容被简中整段遗漏。
4. 迪纳尔当前英文与官方简中仍保留明显不同的地志叙述；应记录为跨版本改写/本地化滞后。
5. “数代以前”“一代以前”“近期”均是相对时间，不得换算为确定年份。
6. “难民”“逃亡者”“移民”“诺德部落”“雅尔属员”是不同文本中的不同身份，不能默认指向同一群体或同一组织。

## 八、下一步需要查证的问题

1. **身份问题**：是否有其他当前 NavalDLC 英文文本直接称呼朱姆内河谷南迁群体的族名、首领或原居地？没有就继续保留未知。
2. **机制问题**：将 Grud 所涉的雅尔属员、河东前哨关系与 Dinar 的扩张叙述对读，检查其他河东聚落是否也呈现由雅尔、属员或家庭移民推动的拓居。
3. **政治归属问题**：继续核对沃尔比约恩、哈尔达尔及其他诺德人物背景，寻找明确的东部征服命令、战事或王室动员；不能把“may conquer”当作证据。
4. **边疆人口问题**：把 Vanni、Vakken、斯特吉亚人、草原部族、河谷逃亡者分别登记；只有文本明确说明时才将其联系起来。
5. **地理问题**：对照 Hargard、Grud、Faergap、Gauksdal、Thralathorp、Ulikshorn、Dinar 与 Karahalli 的地图位置，检验可能的迁徙与交通路线；地图只用于可行性核查，不独立证明事件和年代。
6. **版本问题**：保留 SandBox 与 NavalDLC 的同 ID 地志差异，不把 Dinar 的羊毛描述与难民叙述编成当地产业或人口的历史演变。
