# CHC-NOR-GEN｜诺德史社会群体覆盖与证据单位审计

版本：v0.1｜2026-10-24  
性质：对既有 CHC-NOR-SOC、CHC-NOR-ECO、CHC-NOR-REL 与综合摸底稿的覆盖审计；不是新社会史论文，不重复改写已完成专题，不分配 H 编号。

## 一、审计目的与结论

现有诺德史材料并非只写国王与雅尔。已归档专题对家户财产、继承、女性政治行动、海上劳动、村庄派役、地方司法、逃亡者、俘虏/奴隶市场和地方宗教均有直接或间接材料。因此，下一步不应笼统地“补普通人”，而应分清：

1. 哪些社会群体已经有直接文本；
2. 哪些只在单个人物背景中出现；
3. 哪些机制是从个案推论，尚未形成制度证据；
4. 哪些群体或指标在当前官方资料中仍基本缺席。

核心判断：**诺德社会史已有较强的定性材料覆盖，但证据单位有限，制度与分布信息明显不足。** 关键风险不是缺少有趣故事，而是把同一人物背景的多个字符串当作多份证词，把个案推成全国规则，或用其他文化的明文制度填补诺德资料空白。

## 三、证据单位审计：字符串不是证词数量

源键审计已识别出下列连续背景链。每组内的多个 key 是同一人物背景的分段，不应当作多个独立见证：

- nord_2n：PG95aHx1 → gGLcvhD9 → DN6XgaS3；
- nord_3n：FVwyrKBh → ijmUcJWt → KfUc1Hhl → 97mvKD9y；

- nord_0n：ZlbiEKZL → d5lpGY8m → Gtdo9T3r；
- nord_7n：aEEnTzJY → l0jyALdX；

- nord_6n：前置 g0mUObp7 与 iyfKyaRB → W01GTKJa → Y1fwBgHt。

这些背景具有社会史价值，因为它们具体描述了土地冲突、个人财产、婚姻、欠薪、职业流动、捕鲸和跨国服役。但它们是游戏人物背景文本，不是随机抽样的口述史或多份独立档案。某条故事的多个段落可证明该故事内部的连续关系，不能因拆成四个 key 就把它算成四个互证案例。

另外，主线奴隶贩运字符串描述的是卡拉迪亚范围的土匪与海盗网络，不是诺德王国的专属制度；Thinglaw 的 outlaw 个案描述司法制裁，也不能与逃亡者、奴隶身份混同。跨文化比较可以用于校勘术语，不得把库赛特、阿塞莱、帝国的明文制度移植为诺德法制。

## 四、现有专题之间的覆盖与重叠

1. CHC-NOR-SOC《社会等级、家族财产、劳动与依附关系》已提供总体社会矩阵；本审计不再复制该矩阵，而是指出哪些类别有直接文本、哪些仍是单一人物故事。
2. CHC-NOR-SOC《俘虏、奴隶市场、逃亡者与依附劳动》已做 NavalDLC 词项检索，明确区分 captive、slave、fugitive/runaway、outlaw、wage worker、debtor 与 kinship dependent。后续应继续保持这些类别边界，不另造“诺德奴隶阶级”的统一分类。
3. CHC-NOR-SOC《婚姻、继承与家族政治》已覆盖家户继承、瓦尼—诺德土地婚姻、战败精英婚姻与伊丽卡的王朝行动；但没有证明普遍继承法或婚姻法。
4. CHC-NOR-ECO《船员、船主与跨国服役》已覆盖工资竞争、村庄供役、私人船只和跨国雇佣；但没有证明统一王室海军或固定征船制度。
5. CHC-NOR-ECO《从掠获到统治》已区分俘虏、奴隶市场、战利品、财富与财政；它确认奴隶市场存在，却没有证明王室垄断或固定收益。
6. CHC-NOR-REL《圣地、祭祀与王朝权威》已覆盖若干地点和伊丽卡的叙事；不支持中央祭司体系或统一国家宗教。
7. 第一批关系卡与源键审计补充了版本和语义校勘：圭卡案疑点指向圭卡及统一派，而非国王买凶；“machinations”比官方简中“运筹帷幄”更负面；当前 NavalDLC 英文的地理和海岸叙述有时未被官方简中同步。

## 五、后续工作优先级

### 优先级 1：把现有证据单位标准化

每条社会史材料都标记为：独立地志、人物传记、连续人物背景、王国概述、结构化字段或通用玩法/对话文本。对连续人物背景按“一个人物故事链”计算证据单位，不按字符串数量计数。

### 优先级 2：补普通女性与家庭制度的直接证据

当前女性材料主要集中于精英婚姻、王后政治与一名捕鲸者。后续只在找到直接文本时讨论普通女性的财产权、继承、婚姻同意、劳动和法律人格；不能由少数案例推导统一性别制度。

### 优先级 3：地方司法与共同体参与范围

Thing 个案与旧氏族集会显示地方协调存在，但谁能参与、妇女和外来者是否能起诉、裁决如何执行、国王与雅尔是否有上诉权均未证。优先寻找第二个独立司法叙述或明确的制度性规则；若没有，应将其保持为孤证。

### 优先级 4：边疆身份与依附关系

继续区分奴隶、俘虏、逃亡者、流民、债务人、欠薪劳动者、fyrdman 与普通雇佣船员。任何身份转换必须有文本动作支持，例如出售、赎买、释放、继承或强制役使；不能仅因人物贫穷、逃离或为领主工作就归入奴役。

### 优先级 5：不再用个案替代量化资料

当前没有人口、工资、物价、产量、船队、税额和市场交易量的可靠序列。若后续没有新型资料来源，应明确承认这些问题无法量化，而不是通过地志数量或人物故事数量制造统计。

## 六、对国家形成研究的影响

社会覆盖审计没有推翻现有复合解释，反而明确其证据边界：

- 家族、地方共同体和个人财产构成社会基础；
- 船员技能、私人船只、跨国工资和海洋生计提供多中心资源；
- 王权可以通过财富、强制、职位确认与授地重新分配资源；
- 地方司法、迁徙、私人武装和持续不满表明王权没有被证明已统一控制社会所有关系；
- 奴隶市场存在是直接事实，但其法律结构和财政权重仍未证。

下一步应将这些社会机制接入时间—空间—关系图谱，检查它们在王权统一前、沃尔比约恩崛起时、哈尔达尔统治时以及1084年前后分别能被证明到什么程度。

本审计仅整理已有材料的覆盖和证据边界，不改公共 I/Q，不签发正典，不预分配 H 编号。
