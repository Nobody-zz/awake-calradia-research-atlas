# 潘德拉克战争原始资源审计与证据矩阵

CHC-BAT-GEN｜史料审计专题 v0.2｜2026-10-24
状态：工作稿；不分配 H 编号，不修改公共 I/Q 索引。

## 摘要

本专题对本项目当前可读取的 SandBoxCore.zip、SandBox.zip、Native.zip、StoryMode.zip、NavalDLC.zip 与官方简体中文地志文件进行逐文件审计，目标不是把现有潘德拉克战役转录重新写成完整战报，而是明确哪些战役命题由项目持有的官方 XML 直接支持，哪些来自官方游戏采访对白的反编译恢复，哪些只是人物立场或仍依赖玩家手录的传抄比较，哪些因为版本差异而无法逐字核校。

核心结论是：项目所存官方 XML 直接支持的战役事实较窄，但公开的 Bannerlord v1.4.5 反编译 C# 代码已经恢复主线任务 BannerInvestigationQuest.cs 中的采访英文字符串，包括卡拉多格、埃尔贡和梅利迪尔。它们可列为 A2（官方游戏对白经反编译源码恢复），不再只能依赖玩家转录；但反编译仓库不是 TaleWorlds 官方源代码发布，且 v1.4.5 文本尚未与项目 v1.4.8.119303 程序集逐字比对。StoryMode.zip 只有四个 XML 文件且不含采访答话，这个覆盖结论仍然成立；它不能被解释成游戏中不存在采访原文。

## 一、资源范围与审计结果

本次实际检查的压缩包文件清单如下：

- SandBoxCore.zip：3 个文件——spcultures.xml、英文语言表、简体中文语言表。它可以用于核对巴旦尼亚文化概述，但不含战役采访对白。
- SandBox.zip：30 个文件，包含 heroes.xml、settlements.xml、world_lore_strings.xml、wanderer_strings.xml、companion_strings.xml、spclans.xml、spkingdoms.xml、comment_strings.xml、concept_strings.xml 及对应语言表。可用于核对人物志、聚落传说、角色背景和政治修辞。
- Native.zip：9 个文件，主要为模块通用字符串、原生游戏字符串和语言表。
- StoryMode.zip：4 个文件——module_strings.xml、story_mode_settlements.xml 及其英文／简中语言表。当前包中没有提供逐位领主访谈的专门对白资源，也没有完整对话脚本。
- NavalDLC.zip：21 个文件，包含聚落、人物、氏族、王国与海军对话字符串。其潘德拉克村落文本可用于版本对照，但不能代替主线战役访谈。

这是“本项目现有资源包的覆盖范围”结论，不等于宣称游戏安装目录中不存在其他对白资源。当前材料不全，故对玩家手录访谈的核验应记为未完成，而非断言游戏内没有这段对白。

## 二、证据矩阵

### A 级：当前官方英文 XML 直接记载的文本事实

**A1｜巴旦尼亚高王卡拉多格的继位叙述**

来源：SandBox/ModuleData/heroes.xml，Hero.lord_5_1，字符串键 8SiW73EF；原文件 SHA-256：e615d8106ae2e59b18c752bc7a90ef79dc15d109da51ce3dcd454eae41a0348b。

英文原文要点：现任巴旦尼亚至高王卡拉多格是出色的战争领袖，被前王埃里尔收养；埃里尔后来在神秘情况下死亡。尽管继位存在疑问，卡拉多格仍获得较小氏族的支持，因为他们欣赏他扰乱传统氏族等级秩序；其芬·格鲁芬多克氏族因战友和婚姻联盟而壮大。

可支持：官方人物志明确并置“收养—前王神秘死亡—继位疑云—小氏族支持—战友网络与婚盟”。它不直接指控卡拉多格杀害前王，也不说明这些战友在潘德拉克具体担任何种军职。

**A2｜埃尔贡对卡拉多格的有保留服从**

来源：SandBox/ModuleData/heroes.xml，Hero.lord_5_3，字符串键 HjGYftkH；同一文件 SHA-256 如 A1。

英文原文要点：埃尔贡是芬·登吉尔首领，也是失踪国王埃里尔的兄弟；该氏族怨恨卡拉多格，认为这个出身低微的暴发户可能与“King Uthelhain”的失踪有关，但埃尔贡坚持要求亲属效忠新王。文本随后说芬·登吉尔长期支持强王权，并不愿让巴旦尼亚重回过去大部分时期的无政府状态。

校勘说明：同一段先称 vanished king Aeril，后称 King Uthelhain's disappearance。结合本项目已确立的官方姓名规范，应将人物规范化写作“埃里尔·乌瑟莱恩”，并把英文中名与姓的表达不一致保留为原文层面的命名现象；不能误造两个失踪的国王。该条支持“怀疑与服从并存”，不证明埃尔贡亲眼目睹弑君，也不证明存在书面效忠契约或固定出兵义务。

**A3｜肖农地志对埃里尔失踪的叙述**

来源：SandBox/ModuleData/settlements.xml，town_B4，键 X3MsaG39；SHA-256：e92bb2079526dcc4a125b6a7ae21b76240e5176d143aca98d083be9ce8c32524。

英文叙述把埃里尔王失踪之处放在肖农附近的树林，并说此事为卡拉多格的崛起扫清道路。官方简中地志对应文本为：“在那之后的日子里，这片土地时常受到斯特吉亚掠夺队的袭击，而不远处就是埃里尔王的失踪之地，卡拉多格正是借此机会才得以崛起。”可支持的是“失踪”与“政治崛起”的叙事关联；不支持弑君判决、确切日期或具体作案者。

**A4｜帝国军团在巴旦尼亚森林遭伏击**

来源一：SandBox/ModuleData/wanderer_strings.xml，键 DzyAgYIX；SHA-256：5ba4524baef253eec8b57f2024e57f4f62b62d1c2266e178e183fc6ff8dd2c0d1。角色说德罗修斯·涅雷采斯把精锐军团带进巴旦尼亚森林的伏击；说话者自称当时因病未参战，许多同袍没有回来，之后一切都不同了。

来源二：SandBox/ModuleData/companion_strings.xml，键 mk0l1BfB；SHA-256：9c4ca26f9b3776e0219cf52114f0641a5b335dd12620fac7e1ecca6b2580fafc。帝国老兵背景重复称德罗修斯带领最后一批真正的军团进入巴旦尼亚森林伏击。

证据判断：两处是不同角色背景中的官方叙述，可证明游戏世界反复把“德罗修斯—巴旦尼亚森林伏击—军团损失”联系起来；但它们属于同一游戏文本体系中的人物记忆，并非两个可完全独立的历史目击证人。它们不提供具体林地、兵力、伤亡数字、战斗时长或盟军逐部队战术。

**A5｜潘德拉克之后的帝国军制改革记忆**

来源：SandBox/ModuleData/spclans.xml，Faction id=legion_of_the_betrayed，键 bhxVA9w7；SHA-256：318afe49eb3a7e4b7b92877da58c69af5571925b31e13c0a3851ba995e47b070。

英文原文称：“The Last Legion was created after the Emperor Arenicos abolished the last of the Empire's standing armies in the wake of the battle of Pendraic”，并称阿雷尼科斯改依赖更便宜、也更善于控制领土的总督私人扈从；该派系成员怀念旧军队，但也承认军队若不能定期得到薪酬便无法维持，故会接受帝国和外国领主的合同。

可支持：官方阵营简介明确把潘德拉克之后的常备军废除与军事组织、成本及领土控制联系起来。这是当前资源中关于战役后果最强的制度史材料之一。其叙述带有“被背叛军团”派系的立场，故“更便宜、更善于控制领土”应作为文本所表达的改革理由，而非作者无立场的客观评价；也不能由此推断所有帝国军队立即消失或帝国不再有正规军事能力。



### A2 级：官方游戏采访对白经反编译源码恢复（版本有界）

公开仓库 [BannerlordCode/bannerlord-1.4.5](https://github.com/BannerlordCode/bannerlord-1.4.5) 的 README 说明，其 C# 代码由 Steam 版 Bannerlord v1.4.5 官方托管程序集经 ILSpy 10.1.0 反编译生成；它不是 TaleWorlds 官方发布的原始源码。文件 [BannerInvestigationQuest.cs](https://github.com/BannerlordCode/bannerlord-1.4.5/blob/main/Bannerlord.Source/Modules.StoryMode/StoryMode/StoryMode.Quests.FirstPhase/BannerInvestigationQuest.cs)，blob SHA dfe5b4ebf469860d08014ae6926a0d5ef40e9146，在 BannerInvestigationQuest.SetDialogs() 中以 TextObject 保存采访英文文本。

巴旦尼亚三名受访者的代码分支及文本键如下：

| 人物 ID／官方简中名 | 文本键 | 可核的叙述内容 |
|---|---|---|
| lord_5_1 卡拉多格 | Y6OJHdMH、bmitHhDt、XEuhxpCX、aMBoh7gL | 埃里尔失踪后卡拉多格即位；卡拉多格称氏族呼吁战争；巴旦尼亚人在林地隘口两侧伏击帝国先头部队，先射击、后以近战兵冲击 |
| lord_5_3 埃尔贡 | 4Oc6MEvR、WUa1gnkS、2DZOCsy5、x3KpQouT | 叙述埃里尔失踪与卡拉多格继位争议；描述帝国前卫未获弓兵掩护，卡拉多格号角发令后巴旦尼亚弓手从两侧射击，近战兵随后攻击 |
| lord_5_5 梅利迪尔 | SFJFIaAD、T7ye4wUT、vjOHmHOH、kJxPtbHo | 称埃里尔曾与皇帝订立誓约休战；批评卡拉多格继位后发动战争；称斯特吉亚人对抗帝国主力、瓦兰迪亚人对抗骑兵，并质疑巴旦尼亚最终所得 |

这些答话是官方游戏人物的主线采访文本，但人物均有自身立场：卡拉多格解释自己的战争领导，埃尔贡既谈旧王失踪也强调战术功劳，梅利迪尔则质疑战争收益并重述旧誓约。它们支持的是“官方叙事确实如此呈现”和“人物之间存在立场差异”，不能把任何一人的归责直接提升为中立战报。

**版本限制：**项目所存官方 XML 资料包标注 v1.4.8.119303，而上述反编译代码仓库标注 v1.4.5。若未取得同版本运行时程序集，A2 只能证明 v1.4.5 官方游戏对白的恢复文本；v1.4.8 是否逐字相同仍待核。2020、2026 玩家手录继续保留为 B 级传抄材料，用于交叉核校、发现漏字和版本差异，不与其所抄的游戏对白计作独立见证。

### B 级：官方文本中的政治修辞与叙述者立场

**B1｜卡拉多格的牧人比喻**

来源：SandBox/ModuleData/world_lore_strings.xml，键 91wurGIB、7poObaCF、Sy7dajDq。卡拉多格自称是上天赐予巴旦尼亚的强王，并把顽固的老公牛比作可能带领牛群跌落悬崖的氏族领袖，继而称明智的牧人会宰杀这些老公牛以保护整个牛群。

这不是对实际清洗行动的事实报告，而是强制统治的自我正当化修辞。它可与潘德拉克后王权强化的假说对照，但不能单独证明他真的处决了反对氏族。

**B2｜埃尔贡的共同体论证**

来源：world_lore_strings.xml，键 vzYQuR5r。埃尔贡把卡拉多格描绘为凶残、出身可疑，却承认他能把巴旦尼亚人维系在一起，并表示愿为此容忍相当程度的暴政。该字符串 XML id 为“str_political_philosophy_lord 5_3_for_lord_5_1”，含空格，是否被现行游戏正常调用尚未确认。因此它可以列为官方保存的角色政治构想材料，但在运行状态核清前，不应写成已确认触发的逐字游戏对白。即使有效，其内容也只是人物立场，不是中立的王权评价。

**B3｜梅利迪尔与芬·乌万**

来源：world_lore_strings.xml，键 wv2jPN3Q。文本称芬·乌万氏族在至高王为女儿安排婚姻时被排除，最终选择卡拉多格；发言者表示此事已成过去，大家都已向卡拉多格宣誓，所以让他统治。该字符串 id 同样含空格（“str_political_philosophy_lord 5_5_for_lord_5_1”），运行状态未确认。

它可以支持一个有限解释：婚盟竞争可能制造氏族不满，而宣誓和维护共同政治秩序可以与不满并存。它不能证明王女姓名、婚姻的法律效力、继承权条文，也不是梅利迪尔在潘德拉克战役采访中对旧王休战条约的直接陈述。

**B4｜跨帝国服役与“巴旦尼亚”身份争论**

来源：wanderer_strings.xml，键 wH5GepOD、WmGxA0P1、7QFCINsI、kqbifZIo。帝国老兵称自己及许多同龄巴旦尼亚人曾为帝国服役，并质疑卡拉多格称王后年轻人把为帝国作战视为“叛国”；他否认“巴旦尼亚”曾是统一共同体，称之为一群相互争斗的军阀。

这是一名带有强烈立场的退役军人的政治抱怨，不是全体人口的民意调查，也不证明卡拉多格颁布了正式禁令。它说明“巴旦尼亚是否构成共同政治体、跨境军职是否忠诚冲突”本身是官方文本内存在的争论。

### C 级：版本差异与官方简中校勘

**C1｜潘德拉克村落并非战场地图**

SandBox/ModuleData/settlements.xml 的 castle_village_B4_1 将潘德拉克描述为位于乌卡利翁北坡、面朝瓦尔切格湾、长期遭瓦兰迪亚、巴旦尼亚与斯特吉亚劫掠队袭扰的村落。NavalDLC/ModuleData/settlements.xml 同一 ID 改为班·卡拉赫山下、面向泰瓦尔湖且靠近通往帝国的山地通道；两版地理描述不能拼合成同一稳定地形。当前官方简中文件 encyclopedia-zh-cn.md 保留的是卡·班塞斯、肖农等地志，并不包含逐场战役路线图。

因此“潘德拉克战役发生在村落附近某一条具体道路”不能由聚落条目直接确认。必须分开记录地名、地图版本与玩家战役转录。

**C2｜卡·班塞斯地志的 vanished / 已逝**

英文 settlements.xml 键 QD3oaaNK 称至高王蒙是“vanished High King Mon”，并说忠信者希望有朝一日看见他的船归来。项目官方简中 encyclopedia-zh-cn.md 把它译作“已逝至高王蒙”。“vanished”更接近“消失／失踪”，中文“已逝”则明确暗示死亡。这是语义差异，影响王权复归传说的解释；应引用英文原文并保留官中译文，不应悄悄把两者视作完全等义。此问题与潘德拉克战役具体战术无直接因果关系，列入巴旦尼亚史共享校勘项。

## 三、玩家手录的十九位领主采访：可用但不能升级为原始资源

跨国潘德拉克工作稿引用了 Reddit 上玩家手录的十九位领主采访（2026-06-29 整理），并注明同一整理者的 2020 年十八人旧稿不算独立互证。现已从 v1.4.5 反编译代码恢复卡拉多格、埃尔贡、梅利迪尔的对应英文字符串及键值，故可逐句核对其文本内容；但在同版本 v1.4.8 程序集未核实前，不能将该恢复文本冒称为项目版本的原始文件，也不能把玩家手录与其所抄的游戏对白计作两份独立见证。

当前证据等级应按命题拆分，而不是将整段转录统一视为真或假：

- “德罗修斯·涅雷采斯率军进入巴旦尼亚森林伏击”：有官方人物背景与派系介绍支持。
- “伏击的具体地形、帝国前卫布阵、弓箭与近战冲击顺序”：当前官方资源未给足细节，暂以玩家转录的待核重建处理。
- “斯特吉亚步兵承担主力正面攻坚、瓦兰迪亚骑兵承担特定任务”：当前所持官方 XML 未直接记载，保持二手转录级。
- “埃里尔·乌瑟莱恩与帝国订立了具体休战誓约、卡拉多格继位后何方先违约”：当前所持资源未找到直接条约或官方对白文本，不能当作已经证实的事实。
- “战后因战利品分配发生某种确切争执”：当前所持官方 XML 未直接记载，仍是玩家转录中的待核说法。
- “潘德拉克战后帝国废除常备军、依赖总督私人扈从”：官方 spclans.xml 的 Last Legion 条目直接支持，但具体改革过程仍通过一个怀念旧军团的派系叙述呈现。

此种拆分保留了二手转录的研究价值，同时避免将其叙事细节无条件提升为官方事实。

## 四、历史解释：战争胜利、王权和国家能力是三个不同变量

当前官方材料支持三个彼此相关但不能合并的层面：

1. **战场层面**：帝国军团在巴旦尼亚森林遭伏击，德罗修斯·涅雷采斯的军事领导被官方角色背景视为重大损失来源。
2. **帝国制度层面**：潘德拉克之后阿雷尼科斯废除剩余常备军、依赖总督私人扈从的改革，被“最后军团”视为帝国衰败的起点，却被其原始政策逻辑描述为降低成本和改善领土控制。
3. **巴旦尼亚王权层面**：卡拉多格被官方人物志描述为借战友网络、婚盟和对传统氏族等级的挑战获得较小氏族支持；埃尔贡的人物志则呈现旧王亲族怀疑他却要求族人效忠的局面。

这三层材料共同允许一个受约束的历史推论：潘德拉克可能成为巴旦尼亚新王政治声望上升和帝国军事组织重构的重要节点，但它不能独自证明卡拉多格控制了所有巴旦尼亚氏族，也不能证明帝国改革仅由这一战役单一决定。尤其不能把帝国军制变化反过来直接当作巴旦尼亚所有参战氏族的统一动机。

最优模型仍是“氏族为基础的复合王权”：王权通过战功、宣誓、亲族关系、婚盟和共同体话语争取服从；战役能增加其正当性，但要变成固定征兵、持续财政与常态命令执行，还需要其他直接证据。该模型允许政治承认与私人怀疑、联盟合作与战后争议、军事胜利与中央能力不足同时存在。
