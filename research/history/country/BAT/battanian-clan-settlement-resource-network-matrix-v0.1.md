《巴旦尼亚氏族—聚落—资源—通道—风险矩阵》
CHC-BAT-SOC｜数据审计与制度分析工作稿 v0.1｜2026年10月24日
状态：源级关系矩阵；不占 H 编号；不修改公共 I/Q 索引。
研究问题：1084年初始数据中，地方资源、城镇／城堡所有权、交通通道与边疆风险如何分布于八个贵族氏族？这些分布能够支持哪些关于至高王权的判断，又有哪些结论不能从游戏数据推出？

摘要

本稿将 SandBox/spclans.xml、SandBox/settlements.xml、对应官方简体中文语言表，以及 NavalDLC 同 ID 聚落数据逐项连接，建立“氏族—主要聚落—附属村庄—资源类型—地志关系—版本异文”矩阵。统计以 XML 字段为准：八个贵族氏族控制字段对应的13处城镇／城堡，33处村庄通过 bound 指向其中一处中心。村庄自身通常没有独立 owner 字段，因此本稿把村庄关联至其 bound 中心的 owner 氏族；这是一种数据关系，不是独立的历史地权或税权证明。

33处村庄在 SandBox 的 VillageType 字段中分为10类：谷物农场6、黏土矿6、葡萄园5、木材5、养猪3、马场2、铁矿2、毛皮捕猎2、银矿1、亚麻1。卡拉多格所属芬·格鲁芬多克拥有最多的中心和最广的资源类型组合，但没有垄断整个生产网络；芬·登吉尔拥有邓格拉尼斯这一王权象征中心及葡萄园、谷物、木材和黏土；芬·乌万与芬·潘拉克各自拥有城镇和一座城堡，但其资源结构和边疆联系不同；彭·坎诺克的所属氏族芬·吉尔则呈现黏土与铁矿相连的生产组合。

NavalDLC 中，33处村庄的 ID、bound 关系、中心 owner 和 VillageType 全部保留；30处英文地志文本发生变化，另3处文本不变。唯一的生产类型变更是托·梅利纳从 clay_mine 改为 wheat_farm。大量地理描述的改写不能当作同一世界内的历史变迁；但它们会影响我们对交通、海岸、山口和地方风险的空间理解，故必须与旧版并列保留。

一、材料、字段与译名规则

1. 原始材料
- SandBox/ModuleData/spclans.xml：clan_battania_1—8 的 name、owner、initial_home_settlement、super_faction。
- SandBox/ModuleData/settlements.xml：town_B1—town_B5、castle_B1—castle_B8 的 owner；33处 village / castle_village 的 ID、name、Components/Village/@bound、@village_type 与 text。
- SandBox/ModuleData/Languages/CNs/std_spclans_xml-zho-CN.xml：八个氏族的官方简体中文名称。
- SandBox/ModuleData/Languages/CNs/std_settlements_xml-zho-CN.xml：可用的官方简体中文地志译文。
- 本项目《encyclopedia-zh-cn.md》：核对五座巴旦尼亚城镇及普通村庄的官方中文显示名。
- NavalDLC/ModuleData/settlements.xml 与对应官方简体中文语言表：逐一对照同 ID 节点。
版本基线：当前材料清单标记基础 SandBox 为 v1.4.8，NavalDLC 为 v1.2.8。这里比较的是两个模块版本中保存的文本与字段，不是按年代排序的游戏内事件。

2. 数据关联规则
- 主要聚落 owner 指向某个 Faction.clan_battania_N，是该中心的直接数据所有权字段。
- 村庄的 bound 指向一个城镇或城堡；本稿以中心 owner 作为村庄的“所属氏族关联”。这不等于证明该氏族直接收取村庄全部收益、拥有现代意义上的完全产权，或能无条件征调村民。
- VillageType 是当前游戏系统的聚落分类，不能直接等同于产量、收入、劳动力规模或军需贡献。
- 游戏文件中的 hearth、prosperity、建筑等级等机制数值未被用作古代人口或财政数据。

3. 官方中文名称规则
五座城镇及普通村庄名称按本项目《encyclopedia-zh-cn.md》核对；城堡附属村庄名称优先按官方简体中文地志文本核对。若现有官方中文材料没有对应名称，则保留英文，不自行音译。Lindorn 是本矩阵中唯一未能在当前官方简中地志或《encyclopedia-zh-cn.md》中核得中文名称的村庄，故保留英文。八座城堡本身也保留官方英文名称，因为当前可核材料未提供可确认的官方中文城堡名。

五、跨村关系：原料、市场、通道和防卫

1. 城镇加工与乡村原料
最明确的地方生产链出现在彭·坎诺克：杜恩与盖恩塞斯将黏土运往城镇陶工。克莱格·班的旧版地志也称黏土卖给巴旦尼亚城镇陶工。格伦利斯里格向邓格拉尼斯与卡·班塞斯供应木材；托·莱阿德的林地被描述为长期照料并持续采伐、销售；乌瑟莱姆木材则直接卖给建筑工和造船工。此类文本可以支持村镇分工与商品流通的存在，但不能确定交易是否使用货币、交易频率、价格、税额或由谁征税。

2. 跨境市场并非国家边界的镜像
阿布·科梅尔的白葡萄酒受到帝国与瓦兰迪亚贵族欢迎；布林·格拉斯的深红葡萄酒同样受到这两方重视；格林托尔的马匹受到斯特吉亚商人与劫掠者青睐。这里至少出现三种不同角色：消费贵族、贸易商人和劫掠者。不能将它们统称为“外国需求”，更不能推断有正式外交协议。政治敌对与经济接触能够并存，但其规模和制度形式尚不可知。

3. 地方资源与防卫成本
格纳特·纳尔地志直接写到护林人帮助卡·班塞斯抵御斯特吉亚及其他掠夺者；旧版潘德拉克地志写到警戒号角与把猪群赶入山中藏身处；旧版肖尔达斯地志称乌瑟莱姆要塞保护暴露农田免受斯特吉亚劫掠，而 DLC 版改写为战时面对斯特吉亚和帝国袭击、缺乏天然防护。上述文本支持生产与安全之间的联系；不能确定防卫由村民自发、氏族首领、城镇领主还是至高王组织。

4. 交通地理的版本敏感性
旧版拉诺克·亨强调两条山口，分别通往瓦兰迪亚和帝国；旧版阿布·科梅尔位于特朗河上游陡坡；旧版因韦斯位于特朗河与埃蒂尔河汇合处。DLC 改写多处河谷、山脊和海岸位置。若后续制作地图或通道网络，应为 SandBox 与 NavalDLC 建立独立图层，不可将不同版本地理描述叠加为同一张无时间标记的历史地图。

六、对至高王权研究的解释与反证

发现一：卡拉多格所属氏族的资源基础较多样，但不等于国王垄断资源。
芬·格鲁芬多克关联8村和5类资源，在13个中心中持有3个；其他7个氏族仍掌握10个中心。这个结构与“王权和地方资源所有权并非同一层次”的解释相容，但不足以判断谁更富、谁能出兵更多。

发现二：象征中心与统治者家族并不重合。
邓格拉尼斯由芬·登吉尔持有，而不是卡拉多格所属的芬·格鲁芬多克。芬·登吉尔还拥有葡萄园、谷物、黏土与木材。王权仪式地点的控制与资源基础相结合，使埃尔贡成为一个具有独立地方基础的政治行为者；这不证明他反叛或以领地要挟国王，只说明其政治位置不能仅按“王弟”或“反对者”描述。

发现三：资源专门化可能造成不同的政治利益，但具体立场必须另有证据。
芬·吉尔的村庄组合偏向黏土和铁矿；芬·莫卡尔偏向养猪且旧版突出通道；芬·凯尔纳奇关联葡萄酒外部需求；芬·潘拉克有马匹和木材；芬·乌万兼有毛皮、木材与边防线索。这些差异可用来提出关于战争成本、市场安全和氏族议价的假说，但不能从资源类型直接推导任何一位族长的外交选择。

发现四：政治权力至少应分成四种可观察能力。
- 合法性：诸氏族是否承认某人有资格成为至高王。
- 动员：国王提出战争或征调请求时，氏族是否响应。
- 指挥：各自成军的氏族与雇佣战队能否持续置于同一指挥下。
- 经常性控制：国王是否能不依赖每次协商而持续征取收入、惩戒拒命者、重新配置领地。
现有村庄与 owner/bound 数据主要帮助理解资源位置；它不能单独证明上述任何一项能力。要检验王权，必须与埃尔贡的效忠声明、卡拉多格的联盟和战功叙述、氏族人物志、边疆聚落地志及可核的军队动员对白交叉。

竞争解释与可证伪条件：
A. 传统王权整合模型：若发现早期连续的王室直接征取、固定军役或任免地方领主证据，该模型将增强；目前古老冠礼不足以证明这些机制。
B. 氏族自治基础上的联盟王权模型：若发现国王能常态化直接征收各氏族资源、无需协商即可强制动员并撤换领主，该模型需修正。当前村庄分散关联、地方首领影响生产及不同资源组合与其相容。
C. 战争驱动的王权集中模型：若要证明战争使王权集中，必须找到战后持续的征税、军令、司法或领地管理变化；仅有战功、警戒或战争叙事不够。DLC 的文本改写不能被当作世界内战争导致资源变化的证据。

七、资料质量与未决问题

1. Lindorn 的 text 键异常：节点 ID 为 castle_village_B4_2，text 属性却引用 Settlements.Settlement.text.village_B2_5。其英文叙述在 SandBox 与 NavalDLC 保持不变，但当前官方简中语言表与《encyclopedia-zh-cn.md》未提供可核中文译名。故本稿保留英文名称，不以相似地名猜测译名。
2. 城堡附属村庄的中文名可从官方简中地志文本开头核对，但城堡中心名称本身在现有官方中文资源中未能逐一核得；中心名保留英文，不额外加造中文名。五个城堡附属村庄节点复用了 village_* 文本键：Imlagh→village_B2_4、Lindorn→village_B2_5、Tor Melina→village_B3_4、Seordas→village_B4_5、Inveth→village_B5_4。这属于资源键与节点 ID 不一致，不能因此把这些村庄合并成同一地点；其中 Lindorn 的对应官方简中译文仍缺失。
3. 同一村庄在 SandBox 与 NavalDLC 中有30处英文文本变化，其中大多数改变地貌、路线或叙事强调；只有托·梅利纳改变 VillageType。对比时必须把“文本变化”“地理定位变化”“生产类型变化”分开统计。
4. 当前 XML 不提供村庄产量、贸易额、税额、人口统计、军役配额或王室实际可支配收入。任何相关数字都不能由 village_type、hearth、prosperity 或村庄数目直接替代。
5. 本稿的“所属氏族”对村庄是由 bound 中心 owner 推得，不是村庄直接 owner 字段；应持续使用“关联”“隶属中心”措辞，而不是无条件使用“氏族直接拥有每一村民财产”的表述。

结论

本矩阵使“氏族自治”不再只是抽象标签：它对应的是分散的中心所有权、不同的村庄资源组合、明确的原料供应关系、部分跨境市场需求以及分布不均的边疆防卫风险。但这些资料尚不能把资源潜能直接换算成政治权力。下一步的关键证据必须来自资源如何被动员、拒绝动员会产生什么后果、氏族是否可独立对外服役，以及至高王能否持续征取和重新配置资源。
