# I-0001｜《卡拉迪亚大陆历史研究》研究总纲与交叉校验规范

## 版本：v1.1｜2026年10月22日｜适用对象：全部 H 系列论文

# 研究目标

以官方《骑马与砍杀》系列史料为基础，建立覆盖卡拉迪亚大陆各社会、不同历史时期和政治经济文化领域的研究型论文体系。通过证据约束、比较历史解释及可修订论证，尽可能重建官方资料允许的历史。研究成果为可持续修订的学术论文，不是设定百科与二次创作。

# 一、编号体系

H系列：每篇完整论文稿完成后，按实际完成先后顺序分配H-0001、H-0002……；分配后固定。H号不表示历史年代、学术类别或质量顺位，现有H-0001—H-0005全部保留。
CHC：卡拉迪亚历史分类法（Calradia Historical Classification），依I-0004的固定层级分类树分配；分类号与H档案号相互独立，不是标签组合。  
I-0001：研究制度、跨论文总目录和管理索引。  
S-0001：官方史料来源或可独立识别的史料条目；相同官方原文不同译本可在条目内登记版本，不重复制造独立史料。  
E-0001：历史事件或可严格证明的相对时间关系。  
P-0001：可被讨论、反证和修订的历史命题。  
D-0001：跨论文差异、争议、歧义与证据冲突。  
N-0001：专有名词与古今名称对照。  
M-0001：历史研究实际使用的地图来源、版本和证据性质登记，不代替独立地理研究档案。

# 二、证据分级

A级：官方文本明确记载的事实或“此说法/传说存在”的事实。官方转录的来源和版本必须明确。  
B级：官方资料直接、严格支持的局部推论，例如某事件确在另一事件之后；不得自动延长为完整年代学。  
C级：有文献线索和合理历史机制支持、需要讨论竞争解释的研究性解释。  
D级：材料不足、无法验证或来自二创的假设；仅作为研究问题存档，不能充作正史。  
附加标签：直陈/传说/宣传/人物主张/后世概括/译文待核。A级“存在传说”与A级“事件真实发生”绝不等价。

# 三、核心索引字段

史料S：编号｜标题｜官方原文身份｜来源层级｜游戏版本｜条目ID｜原语原句/译文｜文种｜发布时间/读取日期｜可能冲突｜研究主题。  
事件E：编号｜事件名称｜空间｜参与者｜可证相对年代｜不可知年代｜依赖S｜研究用语限制。  
命题P：编号｜一句话命题｜A-D｜具体原文支撑｜合理推理链｜反证/替代解释｜提出论文｜状态｜最近修订记录。  
争议D：编号｜冲突或竞争模型｜涉及H/P/S｜差异原因｜待补证据｜临时判定｜是否影响论文。  
专名N：编号｜中文主名｜原文/其他译名｜族群/地名/人物类型｜最早可证使用期｜后代名称｜疑义｜来源。  
论文H：档案号（按完整稿完成顺序分配、分配后固定）｜全文标题｜CHC正式主分类号｜研究分期与主辅线｜独立研究贡献｜所引S/E/P/D｜稿件版本｜校验状态｜Google Docs链接。

# 四、跨论文复核程序

1\. 为每一结论指明P编号，并回溯S原文。不接受“另一篇论文已说过”作为史实证明。  
2\. 检查两篇论文是否引用同一段地方志；同源引用不产生双重独立证据。  
3\. 先分别校验地点、人名、日期、文本版本和叙述角度，再比较因果解释。  
4\. 把不能裁决的分歧写入D索引并保留两种假说；不得为了写通史而臆造中间事件。  
5\. 区分史料确认、历史学观察和研究模型，不把现实罗马/拜占庭/其他社会的制度填进卡拉迪亚。  
6\. 论文修订不得改变旧编号，须登记版本号、修订日期、改动的P编号及支持的新S来源。

# 五、四阶段并行与研究顺序

第一阶段：早期大陆社会与卡拉德国家形成，容纳帕拉、坎尼、巴旦尼亚、南方城邦及卡拉德政治共同体。  
第二阶段：共和国扩张与帝国政治权力形成，军权、元老院地主寡头、城市精英、财政与地方治理。  
第三阶段：帝国鼎盛、长期行政社会经济文化转型以及边疆。  
第四阶段：帝国危机、权位继承、1084年分裂与后帝国时代。  
上述分期为档案安排，并非先验历史断代。不同阶段并行推进，后期材料不得未经评估倒推早期制度。

# 六、地图、译名和版本管理

原版《霸主》和《War Sails》的官方地图不完全一致；设计差别本身不等于历史海岸变化、河流改道或战争结果。历史论文必须记录所用地图版本、地图能支持的事实及不能支持的推论，不把1084年行政辖区投射为古代边界。优先采用官方简体中文译名，并登记英文名、古名及歧义。

# 七、现有资料及限制

直接史料基座：TaleWorlds 2018-02-08开发者历史介绍《Empire \- Part 1》；项目保存的 Bannerlord v1.4.8.119303 官方游戏百科中文转录（聚落 settlements.xml、诸国 spkingdoms.xml 等）。后者为已标明版本的文本转录，不能假称已将所有条目与2026年最新版、War Sails逐条核查。  
旧稿 H-0001—H-0003 属阶段性研究；可修订，不作为后续论文的独立原始史料。  
《Calradian Kings》及其他社区二创文献只作为创作史或世界构建对照，不可用于历史事实认证。

# 八、论文写作与审校

正文具备摘要、关键词、问题、资料批判、实质论证、竞争解释、可证相对年代、结论、限度和注释。审校检查原文准确、叙述层次、是否使用推论冒充原文、是否虚构绝对年份、是否出现跨论文循环引证、是否不当移植现实历史、是否存在后期地图倒置及二创渗入。每次完成一篇研究稿，先以“进行中”状态存放，审校通过后移入“已完成专题论文”。

九、历史论文的叙述立场与质量底线（2026-10-22新增）  
本项目的研究文体是史学专题论文。正文首先确立能够争辩的历史问题，并以制度运行、社会关系、空间条件和连续变迁组织论证；不得按照游戏势力介绍、设定百科、开发者日志、玩家可见机制的次序组织篇章。地名、人物、职官与时代应在历史叙述中发挥分析作用，而不是仅被罗列以显示资料覆盖量。  
要像研究真实历史一样追问：一项政治惯例解决什么具体问题、在什么条件下失效、权力转变改变了哪些群体之间的关系、资料允许哪一种竞争解释。但不能假冒存在失传的档案，也不能将现实罗马史、拜占庭史或其他历史的成例移植成卡拉迪亚的事实。  
正文尽量使用“卡拉德国家”“共和国”“元老院”“军营”“统帅”“城邑”“边疆”等研究概念，不频繁出现“游戏”“设定”“开发日志”“开发者”“某条目说”等编撰信息；这些必须透明存在于脚注、史料批判或编辑说明。严禁为了掩盖世界的创作属性而伪造“古代史家”的身份和未存在的史料。  
证据分级S/P/E/D、项目版本、跨论文关系和审计流程主要服务档案，原则上放在文末、旁注或独立I/Q登记簿，不能成为正文的内容骨架。每一章至少需要清楚的核心问题、细密推理、反证或限制以及与全文论点的联系；不以资料罗列、抽象分析模板与大量“不能推断”代替实质解释。  
在史料很少时，应缩小命题和研究范围，而不是用重复改写或猜测堆积篇幅。特别注意一份综合性官方回顾只能形成一条文本传统，不应拆成十余项登记便宣称多重独立互证。完成初稿之后还须做单独的文体审校：删去游戏/制作方术语侵入正文、行政性语句侵入结论、后期资料倒推早期制度和未经证明的现实历史类比。  
改写实例：H-0005 v0.1文本具有设定汇编与项目报告化倾向，v0.2调整为“军事授命的期限—战争常态化—公共集会的空间变化—地主与军人利益—继承危机”的制度史主线；尚待独立质量审查。
