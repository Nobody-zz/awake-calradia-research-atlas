# 卡拉迪亚大陆河流水系与湖泊研究

## ——湖盆汇流、河谷聚落、干旱洪泛与水陆转运的比较

CGEO-S-HYD-001｜系统地理专题｜实质性论文初稿 v0.1｜2026年10月22日

# 摘　要

卡拉迪亚的水文地域并非单一的通航河网。北中部和东部较大的湖泊接受不同河流来水，部分河段出现急流、瀑布与转运地；北方朱姆内河谷连接山海之间的聚落活动；南方达马尔河穿越贾尔贾拉崖地，洪水与沉积为河岸农业创造条件；东南部卡尔西湖沼地带则有平行河流、湖泊和潟湖交错。本文将有名称的水体、村镇水文叙述与已经观察的局部地表画面结合，考察主要水文单元及其与定居、农田、交通的空间关系。研究提出：卡拉迪亚至少存在湖盆汇流型、山河通道型、干旱洪泛型及滨海湿地型等不同水文地域结构；它们之间的关系应通过明确的河道入湖、支流汇合、分水界和河口位置逐步验证，不能凭贸易往来或地名同时出现就假定水体直接连通。拉科尼斯湖西部急流与河名的异文、塔纳西斯湖同卡尔西湖沼地带之间的提及关系，以及朱姆内河与两大湖的连续性，仍是现阶段的重要考证问题。本文以地理叙述为主，将地图版本与材料可靠性问题集中列为证据界限；所建立的是可进一步实测的水文关系框架，而不是完成的流域测绘。

# 引　言

大河与湖泊往往同时构成自然地域的界面和人类活动的轴线。它们汇集周围山地或平原的径流，维持湿地与河岸土地，可能在某些河段成为运输路线，也可能因瀑布、浅滩和分汊限制水上往来。在卡拉迪亚，不同地区的水文地理有显著差异：北方湖泊与河谷可出现相互关联的贸易聚落，干旱南部则见洪泛与局部地下水，近海低地还有盐沼和潟湖。若不区分这些地貌和水文过程，便难以说明河流与区域之间的真正关系。  
研究水系的基本问题首先是拓扑关系：河流在哪里发源，是否汇入另一条河，流向哪一座湖或海，分水界位于何处。其次才是水文条件及其后果：流速、洪水、湖滨沼泽、航道障碍、可耕地与聚落。两类问题需要不同的证据。聚落位于河边，不代表河流全程可航；两座湖泊之间有船货往来，不代表具有无障碍连续水道；城镇与洪泛平原相邻，也不等于已经知道洪水频率与河流流量。  
本文优先采用能够独立辨认地名和水文关系的文字材料，并对公开地图图像仅能显示的局部形态作有限利用。部分聚落叙述现由第三方站点转录，虽标注来自《卡拉迪亚百科》，但研究者尚未核对对应版本的原始文本文件；故本文把它们称为“待原档复核的百科转录记载”，不将二次网站本身说成官方独立证据。关于朱姆内河与北方水域的总体方位，另有TaleWorlds公开文献可直接证实。全文不提供未经实测的坐标、河长、流域面积、坡降或流量。

# 一、湖泊与河流的地域组合：以拉科尼斯湖为中心

拉科尼斯湖（Lake Laconis）是中北部内陆水文考察的重要中心。涅维斯河（Nevys River）的存在及其入湖关系，在多个互相独立的聚落条目转录中得到一致指认：阿特里翁（Atrion）位于涅维斯河谷，马桑加拉（Masangara）处在河岸，而阿拉提斯（Alatys）所在的拉科尼斯湖南端低地被描述为涅维斯河形成的三角洲。阿尔戈隆（Argoron）的城市描述则直接将其置于涅维斯河与拉科尼斯湖相遇之处。〔1〕〔2〕〔3〕〔4〕  
这些记载可以支持一个相对具体的空间序列：涅维斯河存在上游河谷与沿河聚落，其末段进入拉科尼斯湖，并在湖缘形成低平、湿润且泥沙较多的地带。阿拉提斯附近的湖水被描述为浅且混浊，河道上游则有不同的渔获叙述；这有助于区别河流水环境和入湖浅水湖滨，但无法据此测定真正的三角洲规模或长期沉积速率。上述村庄之间的精确先后位置也未通过同一张可测量地图加以确认。  
拉科尼斯湖的另一侧出现了更复杂的地形。关于梅卡洛维亚（Mecalovea）及乔尔诺巴斯（Chornobas）的转录记录，均提到一段从高地坠入湖中的急流或瀑布，并称之为Galchasic Cataracts。这一地点的陡崖与水流落差为湖缘提供了与涅维斯河三角洲不同的地貌对照：前者为落差显著的河道及崖壁，后者为浅水、淤积与低地。〔5〕〔6〕  
不过，两份记录把流经该急流的河称为Miron River；另有马扎丹（Mazhadan）条目在湖西侧提及Galchas River的源头，而部分次级地名文献也把“Galchasic”直接理解为Galchas河。〔5〕〔6〕〔7〕就目前证据而言，不能证明Miron与Galchas是同一河流的两种名称，也不能证明前者是后者的支流。对同一湖侧急流的命名差异，必须先核对百科原文、地名及版本，再考虑其真实上下游关系。  
由此可知，拉科尼斯湖已经能够区分至少两类湖缘环境：涅维斯河口的浅水沉积低地，以及带有急流和陡崖记载的另一处入湖河段。两者在经济利用、聚落位置与岸线形态上可能各有特点，却不能未经地形剖面或连续水道核验就提出完整湖盆汇流模型。

# 二、塔纳西斯湖与东部来水：支流、河口和急流

塔纳西斯湖（Lake Tanaesis；草原语言中另称Tanaz）为另一处重要的内陆湖盆。关于马凯布（Makeb）的聚落叙述指出，该城位于湖的北端，邻近卡拉卡兹河（Karakaz River）进入湖泊处的急流，过往商人需在急流附近转运船只。这里出现了三个相互关联的地理因素：河流入湖、河口附近落差与阻碍，以及因障碍而产生的转运节点。〔8〕  
北面河系内部也有支流关系的文字线索。沙佩什特（Shapeshte）所在的位置被描述为扎汉河（Zakhan River）和卡拉卡兹河相会之处；特佩斯（Tepes）则据称俯临卡拉卡兹河的一条支流。〔9〕此外，东部山地及草原地名汇编提及扎汉河由较高山地来水并同卡拉卡兹汇流，最终至塔纳西斯湖北端。这些细节之间具有较好的内部一致性，但现有来源主要是百科转录与社区整理，尚须核对原始聚落文本以及地图河线。  
目前因此可以谨慎提出“卡拉卡兹—扎汉汇流—塔纳西斯湖北岸”作为待实测的局部水系组合。河谷低地的木材漂流、盐矿交易和船只绕过急流等史事，反映不同河段与湖岸的利用方式可能不同；但聚落传说或交通叙述不足以回答河流全程坡降、各河段季节通航能力及实际入湖水量。  
塔纳西斯湖南部另有提及Teyagh、Tiagys等名称的地理记载。应特别警惕把所有相近的河名拼成一条连续大河。有关Tiagys的另一批转录文本将其与卡尔西湖沼地带的卡尔萨河并列；而社区地名汇编却将Teyagh视为Tiagys的另一名称，并记为流入塔纳西斯湖南端。〔10〕〔11〕在缺少严格的名称对应和地图核验之前，这一分歧无法解决，不宜由其中任意一项推导出跨越两处水域的巨型连续水系。  
塔纳西斯湖对区域交通的影响，也不能仅从其面积或城镇数量猜测。马凯布北端急流及绕行需要说明，湖盆之间即使存在显著商业联系，其运输也可能依赖上岸、搬运或改换交通工具，而不是一条从河源直达各港的畅通水路。

# 三、伊尔坦转运地区与两湖之间的关系

拉科尼斯湖与塔纳西斯湖之间，现存地域名称特别指向伊尔坦转运地（Portages of Iltan）。关于巴尔塔坎德（Baltakhand）的聚落记载将其描述为扼守由湖泊和河流组成的水网，位于斯特吉亚与库赛特地域的接触地带；另一项地名整理则明确把它置于两湖之间，描述商旅在水体之间存在陆上转运的可能。〔12〕〔13〕  
“转运地”一名具有重要的历史地理意义。两处水体之间可以因为距离较短、商路连续或需要将船只上岸拖行而形成联系，但这些情况并不等于两湖在天然水文学意义上直接连通。两湖间可能有多段河流、较小湖泊、急流、分水界或短距离陆路；究竟是哪一种组合，只有在明确地形与流向之后才能判断。  
对两湖关系至少应区分三项概念：水文连通指水流存在明确的河湖通道；航运连通指船只在某一时期可以直接或借助设施通过；贸易连通只意味着货物、人群跨越两地。现有巴尔塔坎德记载较有力地支持第三项，并对第二项中的转运机制提供线索，但不能单独证明第一项。故本文将“拉科尼斯湖—伊尔坦转运地—塔纳西斯湖”记为历史地理联系链，而不是未经验证的连续自然水道。  
更应注意，北方的朱姆内河与两湖存在沿岸活动和远距离往来的官方叙述；它仍不足以消除两湖间可能存在的转运瓶颈。若后续版本地图将一段水面绘成连续航行区域，也应先记录该版本的几何事实，再同较早百科文字对照，不能直接把地图设计差异编造成世界内部的河流贯通过程。

# 四、朱姆内河：北方山地、河岸城镇与南向联系

朱姆内河（Jumne River，社区译名另有“尤姆讷河”）所在区域位于诺德维格以东。官方文字说明这条河向南延伸至库赛特相关地域，并使北方人群能够在拉科尼斯湖与塔纳西斯湖沿岸从事贸易和袭扰。北方哈加德（Hargard）则位于朱姆内河的岩岸，与河谷物产交换有关。〔14〕〔15〕  
此前核对的2025年开发阶段地图截图还能直接观察到：哈加德邻近一段宽阔的曲流，水道沿岸另有据点，局部出现支河与主河相接的形态。这证明至少该地区存在河道转弯和局部支流式交汇的图像证据。不过，从局部画面不能确定整个河流的源头、全部支流、向南哪一段实际入湖，以及河水在交汇点的真实方向。地图图像所见与文字方位相互补充，但各自的空间证明力不同。〔16〕  
从地理作用看，朱姆内河可能兼具北方山海地域通向内陆的地形廊道及河岸城镇集散功能。哈加德的聚落位置使它成为研究山区水道与贸易腹地关系的合适案例。然而，“向南联系库赛特”有可能指河流及其沿岸道路共同组成的往来路线；若未证明水体连续性，便不能把北方海岸到两湖的贸易活动全部写成无中断的内河航行。  
因此，本专题将朱姆内河单列为北方河谷系统，并暂缓判断其与拉科尼斯湖、塔纳西斯湖之间是否具有单一流域上的上下游关系。此种暂缓并非否认空间联系，而是将已知的人类往来与尚待证明的自然水系区别开来。

# 五、达马尔河：干旱地区的洪泛、冲积与聚落

与北中部湖盆相比，纳哈萨南部的达马尔河（Damar River）体现不同的水文地理类型。其河道穿越贾尔贾拉崖地（Jarjara Escarpment），沿途村庄关于洪泛平原、河水带来的细泥以及小麦或椰枣种植的记载相当集中。扎尔姆（Zalm）位于河流自纳哈萨较高地带进入崖地通道的地点；纳赫兰（Nahlan）、基德纳尔（Qidnar）和马布瓦兹（Mabwaz）的转录记载，则将当地农地与达马尔河定期漫溢后沉积的肥沃土壤联系起来。〔17〕〔18〕〔19〕〔20〕  
这里能够提出一条较有根据的地域认识：在广大干旱地区，河流季节性涨水及携带的细粒沉积物，可以使特定河谷形成相对集中的农耕带。洪泛平原并不是同周围荒漠隔绝的另一片大陆，而是处于局部汇水、河谷地貌和土地利用相互结合的位置。达马尔河由此成为南部自然地域内部差异的重要线索。  
阿斯卡尔（Askar）的城市叙述进一步称该城控制达马尔河中游，河流在崖地间曲折，历史上曾出现较大规模的河道越岸或迁移。〔21〕这里值得提出两个不同层次的问题：一是年度或季节性的洪水与沉积是否维持农田；二是更长时期的河道改移是否影响定居中心。后者在目前属于文本记载的历史事件，而非已经完成地貌测绘的河道迁移证据，不能据此自行绘制旧河道或推断其年代。  
值得强调的是，纳哈萨同时存在绿洲地下水和季节性干河床，并不能因为达马尔河沿岸有农耕就把整个干旱地区归入常流河灌溉体系。这里的水文条件应至少区分汇水河谷、可能具有洪泛冲积的土地、地下水供给的绿洲以及缺少稳定水源的广大地区。关于达马尔河究竟在哪些河段常年有水，现阶段仍缺少直接测量。

# 六、卡尔西湖沼、滨海潟湖与河口分汊

帝国东南部与阿塞莱接壤的低地，还存在一种不同于北方大湖与南方洪泛河谷的水文组合。卡尔西（Calsea）在聚落文本中被描述为河流、湖泊和潟湖交织的区域。凯拉（Caira）坐落其中，邻近卡尔萨河（Calsa River）与蒂亚吉斯河（Tiagys River）的平行洪泛平原，当地水源条件维持小麦生长；另有村庄条目将此地的一些潟湖同被沙嘴阻隔的旧海湾联系起来。〔11〕〔22〕  
这一记载支持将卡尔西暂归为湖沼—河口低地型水文地域。其关键并非某条孤立河流，而是平行河道、低地湿地与可能曾同近海相连的潟湖共同存在。河水带来的沉积、浅水滞留、盐度差异和局部排水不畅，都可能影响土地利用；但目前仅有文字描述，不能进一步推定盐度数值、潮汐范围、古海岸线年代或沙嘴成因。  
同一大区域的塞提斯河（Sethys River）又提供一条值得注意的河口记录。阿特菲尼亚（Atphynia）的百科转录称其位于河口附近，塞提斯河在名为Tripotamia的谷地附近分为三支，并通向珀拉斯海（Perassic Sea）。〔23〕如果这一记载经原文和地图证实，便可以构成典型的河口分汊与盐田利用个案。但目前不能把“三分汊”直接等同于已完成测量的三角洲形态，更不能擅自连接塞提斯河与卡尔西所有水道。  
与塔纳西斯湖有关的Tiagys别名问题需要在此再次提出。若某些地名汇编将Teyagh与Tiagys视为同一河流，又分别把它的水体归属写入塔纳西斯湖和卡尔西地区，那么可能存在名称混用、版本差异、转录失误或者真正复杂的流域关系。现阶段没有充分证据选择其中一种解释，故两种文献语句均应保存，并标注为需要实际水系图核验的冲突。  
滨海湿地的研究还应区分地理史料明确叙述的沙嘴隔海现象与不同地图版本的水面修改。前者若出自原始世界内部地理文本，可以被当作区域地貌过程的待核线索；后者则只是两套空间表示资料的差异，不能因其出现时间较晚就编造海侵或内海形成史。

# 七、从河湖地域到大陆水文结构

以上案例揭示，卡拉迪亚可识别的水文结构至少包括四种不同类型。其一为大型湖盆的多源汇流与湖滨定居，拉科尼斯和塔纳西斯分别提供了入湖河流、浅水低地、急流和河口聚落的案例。其二为北方山河廊道，朱姆内河及哈加德反映曲折河谷与跨区域活动之间的关系。其三为干旱洪泛型河谷，达马尔河沿岸的周期性沉积与农耕形成鲜明的局部集中。其四为滨海湖沼与分汊低地，卡尔西及塞提斯河口线索说明近海低地可能具有较复杂的水陆界面。  
四种水文结构并非互不相容。湖泊可能接受山地河流，而入湖急流可能构成交通障碍；河流穿越干旱地带时既可以有洪泛农业，又可以在其他河段水量不足；一处低地如果同时承受内陆来水和海岸影响，则可能形成湖沼、潟湖与盐田。区域之间的联系，不能简单用一条贯穿大陆的大河加以概括。  
从水文科学的角度，真正的“流域”必须依据分水线、流向及汇水关系确定。政治边境、湖岸贸易范围、同名聚落或相邻城堡都不是流域边界的替代物。对目前证据的最合理表述，是建立若干具有明确地名和局部来水关系的水文考察单元，并保留那些尚不知道是否属于同一流域的河段。  
比较水文和聚落的关系时，还需防止环境决定论。河流或湖泊提供水源及交通机会，并不必然产生城镇；同一条河谷可以随不同时代的权力、工程和贸易活动而改变其利用方式。地理研究要说明这些约束与机会，历史地理研究则应进一步考察其具体实现过程。

# 八、证据等级、异文与复核顺序

本文采用四种来源层级。Ⅰ类：TaleWorlds直接发布的地理叙述，主要用以确认朱姆内河总体方位及《战帆》地图的资料范围。Ⅱ类：第三方站点明确标为《卡拉迪亚百科》条目的转录，若几个地点相互指向一致，可作为较强的待原档复核线索，但不能代替对应版本的原始百科文件。Ⅲ类：日语等社区地名汇编和维基词条，可用于提示别名、交通地名及待考地物，不能当作直接官方证据。Ⅳ类：具有时间和来源信息的公开地图截图，只证明该幅画面实际可见的局部空间形态，不能自动证明源流和完整连通性。  
重点异文有三类。第一类为Miron、Galchas与Galchasic Cataracts之间的名称与河道关系；第二类为Teyagh/Tiagys是否指同一河、其究竟属于塔纳西斯湖还是卡尔西相关水系；第三类为朱姆内河与两大湖之间是否具有实际连续的自然水道。三者都涉及拓扑关系，不能靠汉译一致或叙述通顺来消除冲突。  
对地图工作而言，已有公开画面可以辨认哈加德曲流、局部汇合、罗泰附近的宽河道、桥梁与部分海陆岸线，但尚缺乏同尺度覆盖全部河段的水面与地形场景。因此，当前不绘制连续的大陆水系成图，也不赋予上述局部关系虚假的精确坐标。若制作概念性连通表，必须注明“文字叙述的入湖关系”和“实测确认的水道连通”是两种不同字段。  
2026年8月10日，官方已经发布《War Sails》地图编辑工具，允许检查和编辑世界地图及水流方向图。〔24〕这使未来直接核对水道拓扑和水流方向有了官方技术入口。就本研究当前可访问资料而言，尚未运行该工具或载入对应完整场景；因此不能称已完成原版与DLC全大陆水文测量。下一轮应指定一组版本，导出或逐段检查拉科尼斯及塔纳西斯两湖、伊尔坦转运地、朱姆内河、卡尔西及达马尔河的地形与水体，形成地物—坐标—流向—证据来源登记。  
在这些工作完成前，论文可建立的确定性结论主要是局部、文献性的：涅维斯河据聚落转录入拉科尼斯湖；卡拉卡兹河系统据聚落转录流向塔纳西斯湖北端；达马尔河河岸存在明确描述的洪泛农田；卡尔西是平行河道和湖沼交错的区域；朱姆内河可据官方文字确定南向联系。所有这些关系都需要在原始档案或地图版本中核准后才能作为完整地理图志的依据。

# 结　论

卡拉迪亚大陆的河湖格局并非单一的东西或南北向水道体系。拉科尼斯与塔纳西斯两处湖盆、北方朱姆内河谷、南部达马尔洪泛河谷以及东南卡尔西湖沼，分别体现出不同的地形水文组合。这些水体的地理意义既在于来水与沉积，也在于它们改变了沿岸土地的利用机会、城镇选址及区域间联系。  
拉科尼斯湖的涅维斯河入湖低地与急流崖岸相对照，塔纳西斯湖的卡拉卡兹入湖与伊尔坦转运地凸显了水文连接与运输连接的差别；朱姆内河沿岸人群活动并不能代替其与两湖完整水系关系的证明。纳哈萨的达马尔河则说明沙漠地域内部可以存在由洪泛冲积支持的局部密集农业；卡尔西所示的河湖与潟湖低地，是对“大河与大湖”模式的重要补充。  
因此，本文最主要的结论不是宣告某条贯穿大陆的统一河网，而是提出一套能够逐地物接受检验的水文地域解释。未来应优先解决大湖入湖河段、支流汇合、转运地与分水界、河名异文及海岸湖沼的实际拓扑；对于仍无法确认的部分，宁可保持问题开放，也不以想象性地理补足证据缺口。
