# CGEO-S-CLM-001｜卡拉迪亚大陆气候与自然环境研究

## ——季节性、地形影响与局地水分差异的官方文本证据

系统地理专题｜研究初稿 v0.1｜2026-10-24

## 摘要

现存卡拉迪亚官方地志提供了若干明确的季节性天气、冷热差异、风雾现象、降雨节律与局地水分条件描述，但这些材料不是连续气象观测，也没有统一的温度、降水或风速数据。本文以基础版 SandBox 与《战帆》NavalDLC 的官方聚落 XML 英文原文为主要证据，并用《卡拉迪亚百科》简体中文文本核对基础版语义，初步比较北方山海地区、德夫赛格高原及东部内陆、纳哈撒干旱地域、西部海岸与河谷的环境描述。研究发现，官方文本强调的不是单一、均质的大陆气候，而是季节性、地形暴露、海陆气流、湖泊调节和局地汇水条件共同形成的差异。本文只提出定性的自然环境模式，不绘制未经验证的气候分区图，不把不同版本的地志差异解释为卡拉迪亚内部的气候变化。

## 关键词

卡拉迪亚；气候与自然环境；季节性；地形影响；局地水分；版本校勘

## 一、研究问题与结论边界

本专题回答三个问题：

1. 官方地志直接描写了哪些气候与自然环境特征？
2. 这些特征如何与山地、山脊、河谷、湖泊及海岸等地貌条件相联系？
3. 基础版与《战帆》版本的文本变化，哪些可以用于描述各自版本的环境，哪些不能合并成同一套自然地理事实？

本专题属于自然地理研究。气候、天气、降雨、积雪、风雾及局地水分条件是研究对象；聚落经济、土地所有权、市场交换、农业制度与人口组织不在本文论证范围内。作物或畜牧适生性只作为官方文本如何描述环境的辅助线索，不能单独证明某种气候类型。

所有结论均限定在卡拉迪亚的虚构世界及相应游戏版本。官方叙述可以证明“该版本如此描写”，但不能替代连续气象观测。本文不推算真实温度、降水量、风速、积雪深度、蒸散量或气候变化趋势。

## 二、资料与方法



### 2.1 官方原始文本与版本

主要使用两套官方聚落 XML：

- 基础版 SandBox：`Modules/SandBox/ModuleData/settlements.xml`，归档版本标记为 Bannerlord v1.4.8；ZIP SHA-256：`54c358e5b318ffeda8a69ce41a7e665f3b9bef06a6e49b142a972c80ea9c1d55`。
- 《战帆》NavalDLC：`Modules/NavalDLC/ModuleData/settlements.xml`，归档版本标记为 NavalDLC v1.2.8；ZIP SHA-256：`e41ad1c75665e736cad7d02319193a2cc6e0ed68e8bf2e44e1f151b62020b468`。

两份 ZIP 的校验值与项目的官方原始资料归档清单一致。该归档是经过选择的官方 XML 文本资料，不是完整游戏资源镜像。现存 `encyclopedia-zh-cn.md` 标注基础版 v1.4.8.119303，来源为 SandBox 聚落与王国文本及其简体中文本地化；它不包含《战帆》新增地志，不能作为 NavalDLC 文本的中文旁证。

### 2.2 语料扫描与限制

基础版聚落 XML 中有 327 条带地志文本的实体记录，《战帆》有 365 条；两版共有 327 个实体 ID，其中 56 条英文文本逐字相同、271 条存在文本差异，《战帆》另有 38 条文本记录。按天气、季节、冷热、风雾、降雨和干湿等词项进行初筛，基础版命中 96 条，《战帆》命中 112 条；在 271 条有差异的同 ID 文本中，107 条至少有一版包含这些词项。

以上数字是文本定位和版本差异统计，不是独立气候观测数，也不代表 107 条全部发生了气候语义变化。拼写、扩写、地理位置重述与气候信息增删必须逐条区别。本文选取能清楚说明自然环境的代表性记录，未把关键词扫描结果直接当作气候分类。

### 2.3 证据等级

沿用项目既有规范：

- A：官方明确文本。本文中的 A 级只表示官方叙述确实作出该描述，不表示它是实测气象数据。
- B：选定版本地图直接呈现的空间证据。
- C：研究者根据多个 A/B 级材料提出的解释性归纳，须保留反例与可证伪条件。
- D：非官方或二创材料，本文不用于建立气候结论。

当前可访问的官方文本 ZIP 不含完整原始地形、海岸和导航网格二进制。需要区分的是，前序地图研究曾从当时可读取的原始 terrain.bin 恢复原版与《战帆》两套 4097×4097 16-bit HGHT 高程栅格，并对《战帆》港口／登陆标记开展过原始 Navmesh 面内检验；这些是已归档的前序直接分析，不是本轮重算。RES-018 核查发现，当前可访问的研究档案保留了派生 CSV、脚本和图件，但未包含完整 Navmesh 顶点／面或原始 bin 字节；早期直接读取过的原件是否仍在旧附件的其他存储层尚未确证。故本文不宣称独立复算这些结果，也没有执行新的海拔、坡度、海岸线或气候空间叠合；不把既有导航网格分类当作自然气候证据。

## 三、官方文本所支持的初步自然环境格局



### 3.1 北方山海地区：寒冷、积雪、山风与海雾

北方与高地文本反复出现寒冷、冬季积雪、山地冷风及海雾，但它们对应不同的局地环境，不应被合并成同质的“北方气候”。

- 阿兰塔斯（`village_V9_1`）被描述为位于多山的埃博半岛中央，天气寒冷。该描述同时提及土壤薄，但土壤贫瘠与寒冷天气是不同的环境变量。
- 布基茨（`village_S5_2`）的地志写到从伊勒坦山吹下的刺骨阵风，支持山地风暴露的局地描述，不足以证明整个山系的主导风向或风速。
- 佩亚姆（`castle_village_K9_2`）被描写为一年大部分时间积雪，融雪开始后才进入播种期。这是季节性描述，不提供积雪实际持续天数。
- 西林达克（`castle_village_V5_2`）位于埃博半岛高脊之下，地志称其受到西北来的强冷风一定程度的遮蔽。它支持“地形可改变局地风暴露”的官方叙述，但没有测量遮蔽效应。
- 卡南克（`village_V8_2`）被描述为潮湿的林丘、海雾环境；但其基础版地点指向莱恩诺北部丘陵，《战帆》则改写为埃博半岛。海雾描述可以作为相应版本的文本证据，不能跨版拼接出一条连续的雾区边界。

因此，当前材料可以支持北方若干地点具有寒冷、积雪、山风或海雾的定性环境描写；不能据此计算纬向温度梯度，也不能将“森林”“高地”自动等同于寒冷气候。

### 3.2 东部内陆与高原：干季、冬雪、融雪泥泞和冷热季差

德夫赛格高原及周边材料表明，“干旱”与“冬季积雪”并不互相排斥，季节转换是理解当地自然环境的关键。

- 基斯姆利（`castle_village_K5_1`）位于德夫赛格高原的一处盆地。文本明确写到当地大部分时间干燥，但冬季会降雪，春季则泥泞；融雪与降雨形成的积水也是地志直接提到的现象。
- 乌伦占（`village_K4_4`）的描述同时提到炎热夏季与严寒冬季，支持显著季节反差的定性判断。但基础版将其放在高原西缘、阿克坎山脚，《战帆》改为高原东缘、苏兰达格山脚。气候句子相近，不代表两版空间定位相同。
- 胡加（`village_A2_3`）的地志将当地描述为大部分时间贫瘠、春季出现草与花的荒漠草原。它支持季节性生长窗口的叙述，不能用来推算年降水量或完整植被季相。
- 马津（`village_K3_3`）在《战帆》文本中新增“塔奈西斯湖缓和当地北方冬季寒冷”的说法。这是一条官方的局地湖泊调节假说；基础版同 ID 文本没有这项气候表述，故不能把它写成两版共同证实的结论。

这些材料说明，干湿、冷热和季节性需要分开分析。不能因高原大部分时间干燥就推断全年无雪，也不能因冬季积雪便将整个区域归入同一种寒冷气候类型。

### 3.3 纳哈撒：少雨背景下的短时强降雨与局地汇水

纳哈撒的官方地志不是简单的“无水沙漠”叙述，而是将稀少降雨、地形汇流与不同形式的局地蓄水并列描写。

- 阿斯麦特（`castle_village_A2_2`）记载山坡在罕见暴雨时出现向下的洪流，当地拦蓄这些水。这能支持“少见但强烈的降雨事件”这一文本命题，不能提供暴雨频率、峰值流量或重现期。
- 梅德尼（`castle_village_A4_1`）提到短暂雨季及干谷对崖地径流的拦蓄；巴克（`village_A1_2`）则将海风带来的有限降雨与内陆高地联系起来。
- 萨赫勒（`castle_village_A2_1`）的文本称山脊接收来自耶什姆海的雨云，并受到东南方向季风影响。这是特定地点的官方环境描述，不能外推为整个纳哈撒都具有季风气候。
- 胡加的春季草花与基斯姆利的融雪春泥说明，季节性水分条件可以在不同自然地域形成不同结果；它们不能被合并成同一套降水机制。

自然地理上必须区分常年干燥背景、短时强降雨、山坡径流、地下水与河流洪泛。后两者属于不同水文过程，不能因为都能提供水源就推断它们具有相同补给区或水力连通。

### 3.4 西部海岸与河谷：暖季、海风、雾气和地形遮蔽

西部及南部沿岸地志更常使用温暖、海风、河谷雾气及山脊遮蔽等局地描述。

- 菲尔贝克（`village_V5_1`）被描述为一年大部分时间温暖。该句是定性概括，不提供温度阈值或暖季长度。
- 帕利松（`village_V3_4`）的文本将凉爽海风沿特朗河谷上溯与温暖午后并置。这支持海陆气流与日内环境差异的叙述，不足以确定风向的全年稳定性。
- 阿尔萨索斯（`village_EW2_3`）被明确称为气候相对干燥，但地点存在自流井。这里的关键区别是气候干湿与局地地下水供给不能相互替代。
- 凯拉（`castle_village_ES1_2`）在《战帆》文本中被描述为受珀拉斯海海气与卡勒萨丘陵影响的潮湿平原。这是 DLC 版本新写的局地气候描述，不能倒填到基础版的同 ID 地志中。
- 西林达克的山脊遮风与帕利松的河谷海风说明，地形可能改变局地暴露、气流路径和雾气出现方式。但没有风场、湿度或温度实测，不能将其量化为完整的山地气候模型。

因此，现有文本支持海岸、河谷与山脊环境存在局地差异；不支持把整个瓦兰迪亚或帝国南部简单归类为某一种现实世界气候类型。

## 四、跨版本差异与中文本地化边界



### 4.1 不把版本差异写成世界内部的气候变化

基础版与《战帆》是两套不同版本的地图与地志表达。相同实体 ID 的文本发生改变，不自动意味着虚构世界内出现了气候变化、河流改道或地貌演替。

- 马津（`village_K3_3`）：基础版讲述湖河捕鱼，《战帆》新增湖泊缓和冬季寒冷的气候描述。
- 拜特·哈提夫（`village_A7_2`）：基础版把地点放在达玛尔河洪泛平原，《战帆》改为受罕见强降雨切割的干谷，并强调地下水。此项同时涉及水文与地貌，本文只用它说明版本不可混合，详细水文讨论归 CGEO-S-HYD-001。
- 乌伦占（`village_K4_4`）：冷热季节描述近似，但地点由阿克坎山脚改为苏兰达格山脚。不能把相近气候句子当作同一坐标的重复测量。
- 鲁伦德（`village_V3_2`）：基础版描写特朗河中游的林地河谷，《战帆》改写为河以北的多风海岸。它是明显的空间叙述变化，不应拼接为同一地点同时拥有两种互不核验的环境位置。
- 卡恩特里昂（`village_ES4_3`）：基础版称其所在平原比其他部分降雨更多；《战帆》改写了位置与叙述，没有保留这一比较性降雨断言。此差异说明定性气候命题也需要逐版本登记。

以上例子与项目已有地名及英汉同键校勘相衔接，本文不重复裁定全部实体的地理位置。

### 4.2 简体中文百科不是《战帆》文本的替代品

`encyclopedia-zh-cn.md` 的范围是基础版 v1.4.8.119303 的城镇、村庄与王国条目，且不含城堡附属村庄。它适合核对基础版简体中文名称和译文，不适合作为《战帆》新增或改写内容的证据。

本轮发现两处与气候语义有关的翻译风险：

- 菲尔贝克英文原文是“warm most of the year”，中文百科写作“全年气候温暖”。中文表达将“大部分时间”扩大为“全年”，在严格气候论证中应以英文原文的限定范围为准。
- 泽翁尼卡的 Zeonic Wind 在英文原文中被称为一股每年夏季吹过珀拉斯海的 “gale”，中文百科译为“季风”。英文文本确实说明这是季节性风，但没有把该风直接定义为气象学意义上的 monsoon。研究中应称“泽翁娜之风／夏季强风”，除非引用的原文另有明确季风表述。

这两处并不意味着中文百科整体不可用，而是说明气候术语的分类强度不能超过原始文本。

## 五、阶段结论

现阶段最稳妥的结论是：卡拉迪亚官方文本描写了多种季节性与局地自然环境组合，而非一个可以直接从文字中恢复的统一气候分区。

1. 北方与高地的代表性文本突出寒冷、冬雪、山地冷风及海雾，但这些特征并非每个北方地点都同时具备。
2. 东部内陆与高原同时出现长期偏干、冬季降雪、春季泥泞、冷热季反差及春季短草等描述，表明干湿和季节性不能简化为单一指标。
3. 纳哈撒文本突出少雨背景下的短时强降雨、地形汇流和局地水分蓄留；这些机制不能合并为一条已证实的统一灌溉或地下水系统。
4. 西部海岸与河谷的温暖、海风、雾气和山脊遮蔽是局地描述，不足以将整个区域套入现实世界的气候分类。
5. 《战帆》重写了大量基础版地志。两版应分别记录；任何版本间差异都不能自动被解释为世界内部的气候变化。

这些结论属于 C 级综合归纳，其前提是相应 A 级官方文本确实存在；它们仍需接受同版本空间证据与反例检验。

## 六、下一步研究与可证伪任务

下一步不应立即绘制气候分区图，也不应继续扩写一篇覆盖全大陆的泛论。建议先完成一份以稳定实体 ID 为索引的气候证据矩阵，针对两版关键词命中记录逐项登记：

1. 原始模块、版本、实体 ID、英文原文与对应中文文本；
2. 直接天气描述、季节性描述、地貌暴露、水文过程及农业/植被线索的分类；
3. 同键文本的气候命题是新增、删除、保持不变，还是仅发生地点重述；
4. 每条推论的前提、证据等级、可反驳条件及与 GEO/HYD/BIO 论文的责任边界。

优先抽查三组自然环境对照：埃博半岛的冷风与海雾、德夫赛格高原的干季—冬雪—春季融水、杰尔贾赖峭壁与纳哈撒的短时降雨—局地汇水。若之后能够恢复原始地形和地图二进制，再对地形高差、坡向、海岸及水文地域进行空间检验。在此之前，所有定量气候图、真实降雨梯度与气候变化判断均保持未证。
