# CGEO-S-HUM-001｜卡拉迪亚大陆城市形成与聚落体系研究
## ——殖民城邑、贸易节点与边疆聚落的历史空间组织
系统地理专题·历史人文地理｜研究初稿 v0.1｜2026-10-24

# 摘要

卡拉迪亚大陆的城镇并非同一时期、同一制度下形成的均质聚落集合。滨海殖民、政治中心转移、林地资源交换、草原边缘贸易与干旱地域的水源约束，分别促成不同的定居方式和城市功能。本文综合城市沿革、区域地志与现有历史地理研究，从城市发生的社会机制而非单纯的地形位置出发，考察沙拉斯、巴拉维诺斯（今帕拉汶德）、俄耳堤西亚、斯特吉亚林地河谷城镇、朱姆内河岸的哈加德，以及草原边缘与纳哈撒绿洲的聚落组织。研究认为，大陆聚落体系至少存在殖民与政治整合、资源汇聚与交换、边境控制与交通转换三种互相交叠的形成机制。城市的文化起源、主权归属、政治地位与经济职能并不必然一致；聚落体系也不应以某一时期的王国疆界分割成相互封闭的单元。现有史料可以支持功能类型和若干历时变化，却不足以复原大陆各城镇的统一等级、人口规模与市场范围。

关键词：历史人文地理；城市形成；聚落体系；城市功能；殖民地理；市场腹地；边疆城镇；卡拉迪亚

# 一、引言：从城镇位置转向聚落形成机制

城市地理研究需要回答的不只是“城镇位于哪里”，而是“何种人群、资源、权力与交换关系使聚落在这里形成，并使其得以维持”。沿海港湾能够提供运输条件，但不会自行产生殖民政权；森林蕴藏毛皮和蜂蜜，也不会自动形成商业城市；山口或河谷可能便于通行，却未必拥有持续的市场需求和治安保障。聚落的存在因此既受自然条件约束，也取决于移民、土地分配、征服、交易、税收和地方政治组织。

本文将“聚落体系”理解为具有分工、往来与相对等级关系的城市、城堡、村庄及其他定居地点的组合，而不是一张按既定政权颜色划分的城镇清单。研究尤其区分四个层次：一是聚落形成时的社会起源；二是其所处历史阶段的政治管辖；三是实际经济与交通职能；四是同周边乡村、其他城市和流动人群的联系。四者既可能重合，也可能发生错位。本文先建立可以比较的类型，再以有限的地方材料检验其解释力。

# 二、殖民城邑：海岸定居、土地组织与政治中心的分离

沙拉斯（Charasea）在城市传统中被视为卡拉德人于新大陆海岸建立的第一处殖民地。这里的“第一”属于特定殖民记忆的排序，而非经过完整纪年证明的大陆第一座城市。其地理意义在于：沿海移民定居首先需要一个能够把跨海抵达的人群、物资与陆地腹地联系起来的地点。即便不知最初登陆港址、移民规模和土地分配细节，海岸定居与内陆农业供给之间的关系仍是值得检验的社会地理问题。

巴拉维诺斯（Paravenos，今帕拉汶德〔Pravend〕）被称为卡拉狄乌斯建立的第二座**重要**殖民地，后来取代沙拉斯成为首都。该称谓不能误写成“第二座城市”。它揭示的不是一条已被测绘的迁都道路，而是殖民共同体内部政治中心的重新配置。首都迁移意味着统治、贵族活动及资源汇聚的地理重心可能改变，但并不必然导致旧港口衰落。沙拉斯后期仍有海务、贸易和贵族消费活动，恰好说明**政治中心与经济交通中心可以长期分离**。

两座城市的关系还提示，应把“殖民地”视为一种定居与权力组织过程，而不是永久不变的城市类型。殖民起源可以转化为行政中心、地方市场或后来的被征服城市；同一聚落在不同历史时期所承担的功能不必相同。后期帕拉汶德地方元老参与与瓦兰迪亚统治者奥斯里克的谈判，说明城市地方精英在主权转移中具有行动能力；但不能据此反推其早期便拥有同样的自治制度，更不能将地方元老与帝国中央元老院混为一谈。

# 三、殖民文化与政治主权错位：俄耳堤西亚的个案

俄耳堤西亚（Ortysia）被称为卡拉德人在珀拉斯海（Perassic Sea）的首个殖民地，但城市沿革同时记载，其早期相当长时期处于坎尼城邦古亚兹（Quyaz）的统治下，后来才随共和国扩张而被纳入。它与沙拉斯的“第一殖民地”叙述并不直接矛盾：两者分别指向不同的地理范围。

更重要的是，这一案例显示：**文化上的殖民定居不等于国家主权的即时扩张**。某地可以保存移民文化与建城记忆，却在税务、海上安全和政治裁决上受另一个城市国家约束。研究俄耳堤西亚时，至少应分列殖民记忆、实际统治、港湾交换和后期共和国整合四个层次。把后来的帝国城市身份倒投至最初建城时期，会抹去珀拉斯海早期多政治中心并存的空间结构。

由此可以提出一个具有大陆比较意义的命题：沿海城市网络未必先于政治统一而形成单一国家的“内部贸易网”。相反，跨主权贸易、殖民社群和地方城市国家可能共同塑造海岸聚落体系。要证实这一机制，需要更多港口关税、商人活动及城市外交记载；现有材料支持的是主权与殖民起源的错位，而不是某条具体海运线路的持续经营。

# 四、森林资源与河谷市镇：东北部的交换型聚落

斯特吉亚林地的毛皮、野生蜂蜜和沼铁资源，为东北地区的聚落形成提供了不同于滨海殖民的社会经济条件。现有地域叙述把远方商人进入林区、资源交换扩大和沿河城镇兴起联系起来。这至少支持一个初步机制：森林腹地的分散生产活动，经由河谷的集散与交换，促使若干节点获得超出周围乡村的商业功能。

然而，资源存在与城镇兴起之间并非无须解释的自然因果。商人必须获得进入林地的机会，货物需要可持续的收购和运出渠道，交换地点还可能受到地方首领、军事集团或城镇自治组织的保护与控制。现有材料不能直接证明哪一种政治制度首先形成，也不能把所有河岸城镇归入统一的建城年代。较合理的工作假说是：**资源腹地—河谷集散—地方权力**三者的互动，使一些地点逐步由交易聚落转变为具有区域影响的城镇。

这类聚落的城市性，不宜仅用城墙或政治头衔衡量。若某一河岸地点持续汇集远距离商人、转运森林产品并服务周边生产聚落，即使其行政等级不高，也可能在经济地理上具有较大腹地。相反，一处军事堡垒即使地位显著，也未必具有相同的市场组织能力。此处应避免将聚落等级、军事等级与经济中心性三者混同。

# 五、北方河岸城镇与跨族群市场：哈加德的意义

哈加德（Hargard）位于朱姆内河（Jumne River）沿岸。其地域记载把河谷物产与不同人群的交换活动联系起来，另一组北方记述则提及海象牙、鲸油、鱼类等海洋资源向南流通。这些材料并不能证明每一种海产品必经哈加德，但足以说明北方存在山地、河谷、海岸及内陆市场之间的多方向交换需求。

哈加德因此适合被看作“跨族群河岸市场”的研究案例。此类城镇的形成机制不只在于临河，而在于它能否为不同生产区域提供相遇、交换和再分配的场所。朱姆内河在库赛特人中另称喀拉卡孜河（Karakaz），地名差异还反映同一水道进入不同人群的地理知识与活动范围。名称的跨语言分布不能自动证明贸易路线连续，却提示河谷可能具有超越单一政治文化区的交往意义。

对哈加德应进一步追问：其市场服务于哪些上游林地和下游城镇？贸易活动由王权、地方首领还是商人社群组织？海洋产品和内陆资源是否在同一市场中交换？这些问题不能凭“河流是运输动脉”的概括直接作答，但已经具有明确的资料搜寻方向。与沙拉斯相比，哈加德所揭示的不是殖民港口与迁都关系，而是多种资源地域在河岸市场中的连接。

# 六、草原边缘城镇：农牧交换与边境权力

大陆中部草原与周边耕作地域之间的差异，使城市形成面临另一组条件。关于帝国东进的叙述指出，军队进入广阔草地后难以沿用原有农田供给方式，因而在草原边缘的贸易城镇巩固其控制。这里至少存在三种不同的社会地理关系：定居农耕地区的粮食供给、草原流动人群的畜牧活动，以及国家围绕贸易节点实施的驻军和税务控制。

因此，草原边缘城市不应仅被解释为自然分区的“边界标志”。它们可能是两种生产方式之间的交换场所，也可能是军事控制与商路保护的据点；两种职能可以叠置，却不必在同一时期等量存在。城市周边耕地能否供养驻军、畜牧产品如何进入市场、当地税务如何与游牧群体互动，均影响其实际中心性。

一个值得比较的历史过程是：某座城镇在帝国东进时成为前线据点，在后来的草原政权统治下可能继续承担市场功能。政治归属发生改变，并不意味着其腹地与交换关系立即消失；但要证明经济职能持续，需要分时期的地志、物产与商人活动证据，而不能只根据城名在不同政权叙述中反复出现。

# 七、绿洲与干旱地域：定居的集中和分散

纳哈撒（Nahasasa）的干旱地貌、地下水点、绿洲、山口和干河谷，为南方聚落提供了另一种空间约束。可利用水源并非均匀分布，因而定居地点可能集中在绿洲、河谷洪泛地和山口附近。这里的“集中”首先是自然条件造成的机会差异，并不能直接说明城市由某一种制度创立。

绿洲聚落可能同时承担农业生产、商队补给和地方权力控制。三种职能的空间范围并不相同：耕作腹地取决于水源与土地，商旅联系可能跨越远距离荒漠，政治控制则还取决于部族关系、军事能力和征税方式。将所有绿洲简单写成同质的“商队城市”，会掩盖农业村庄、市场据点和政治中心之间的差异。

达玛尔河（Damar River）附近的河漫滩农业记载，进一步说明南方聚落并非只能依赖孤立泉眼。局部洪泛平原可能支持较密集耕作，但这不能外推为整个纳哈撒都具有稳定灌溉河网。应在下一阶段比较阿塞莱地域的城市、绿洲村庄和山口据点，检验水源、生产腹地与商队活动究竟如何组合。

# 八、城堡、村庄与城市：等级关系不能由名称预设

卡拉迪亚聚落研究还必须面对城堡、村庄与城市三类地点之间的关系。军事据点可能保护通道或农田，却未必发展为独立市场；村庄可能以农牧生产为主，也可能承担渡口、盐矿或资源集散功能；城市既可能是政治首府，也可能以港口、贸易或制造业为核心。它们不能依据分类名称直接排列成经济规模固定的金字塔。

庞斯（Pons）旧桥被洪水毁坏后，上下游其他渡口继续承担过河活动的地方记载，说明交通职能可能在多个村庄之间重新分配。罗卡那与厄毗诺萨两处隔河设防的城堡，则展示军事节点如何围绕河谷组织空间。两例都说明：重要的地域功能未必只集中在大城市，较小聚落与堡垒也可能控制交通瓶颈、保障生产腹地或成为区域政治边界的支点。

若要建立严格的聚落等级体系，至少需要同一时期的居民规模、生产与交换范围、行政隶属及城市间往来资料。现有聚落点位可以帮助识别空间接近性，却不能替代人口统计或市场腹地调查。对城市网络的论证应从具体联系出发，避免以坐标密度直接宣布某地为“一级中心”。

# 九、历时变化与三种城市形成机制

综合上述案例，可以将大陆城市形成暂归为三种相互交叠的机制。

其一是**迁徙、殖民与政治整合**：沙拉斯和巴拉维诺斯体现沿海定居与政治中心迁移，俄耳堤西亚显示殖民文化与主权归属可能分离。这类城市的历史首先涉及人群迁移、统治关系与制度安排，而非单纯的地理位置优越。

其二是**资源汇聚与跨地域交换**：斯特吉亚林地河谷城镇和哈加德的案例提示，城镇可能因连接森林、河谷、海洋和远方市场而发展。这里必须区分自然资源、商品流通与市场组织；三者相互依赖，却不能由其中一项直接推断其余两项已经成熟。

其三是**边境控制与交通转换**：草原边缘贸易城镇、河谷桥渡与堡垒、纳哈撒山口和绿洲，体现国家、商旅和地方社群对空间瓶颈的利用。这类地点的政治重要性可能高于其人口规模，亦可能在主权更替后继续承担跨区域联系。

三种机制不是三个互斥的城市等级。一个沿海殖民地可以成为首都，继而成为贸易港；一个河岸市场可以因战争变为边防据点；一处绿洲可以兼具农耕、税收与商队补给。真正的研究对象是这些功能如何在不同历史阶段组合、分离与转移。

# 十、结论

卡拉迪亚大陆的聚落体系不宜理解为一组按1084年政治疆界分别形成的国家城市网。早期沿海殖民、帝国政治中心转移、珀拉斯海多主权城市、东北森林资源交换、北方跨族群河岸市场、中部草原农牧接触及南方绿洲定居，共同表明城市形成具有多种历史路径。

现有材料支持三项相对稳健的判断：第一，殖民起源、政治主权和经济职能可以在同一城市中分离；第二，城市与乡村的联系不仅由距离决定，还取决于资源组织、交换制度和地方权力；第三，聚落体系具有跨越自然区与政治边界的联系，不能由静态疆域图替代。尚不能证实的是统一的大陆城市等级、人口排名、城市间贸易量及完整的分时期市场腹地。

下一阶段的研究不宜再停留在抽象类型。应优先开展沙拉斯—巴拉维诺斯的城市职能转换、斯特吉亚河谷城镇与森林资源腹地、草原边缘农牧市场，以及纳哈撒绿洲—商队—乡村关系四组专题比较，以具有年代、社会行动者和交换行为的地志证据检验本文提出的三种机制。

**不能滥用没有卖方—买方信息的邻近生产**：沙拉斯旁的萨万特village_V7_1养马、韦桑village_V7_2种橄榄，是本地直接物产，未直接指明出售给沙拉斯市民；与拉尔纳克文本不能同级。俄耳堤西亚周围阿耳波提斯的梯田蓄水、维尼拉的海鱼及伽伦戈利亚供帝国铸币的银矿，显示其周边不同产业，但不能把每一类产品归入已经证实的城市供销清单，尤其不得由供帝国铸币外推“俄耳堤西亚有铸币厂”。

**《战帆》非常态供粮不替代平时货流**：瓦兰迪亚史线已定向回读NavalDLC／naval_dialog_strings.xml／TMdL4gJH、cc9JuNoL、9wYQGoha，记一位航海者家族回忆沙拉斯围城时有船民因城内高价而运粮，后受戴·科尔坦追究、家庭流亡。三段同属一证人叙述，可支持战时海上供给与价格动机的文学史料存在，但不能由此判断城市全年粮食自给率、全体船员政治立场，或定出无独立纪年的围城年份。城市政治中心、港口、农业消费和家族权利仍需按时代及商品分开处理。

**后续对总论的约束性修正**：关于大陆城市形成的四变量“起源—文化—主权—经济职能”仍保留，新增第五个操作化问题：*生产者—货物—买方—时层* 是否得到直接史料印证。不同记录的“当前城市绑定村庄”只是一个特定版本的经营/模拟关系，不能据之补写数百年无缝贸易史；若没有具体商品流向，只保留为C级潜在腹地解释。
