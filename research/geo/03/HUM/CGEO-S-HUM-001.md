# CGEO-S-HUM-001｜卡拉迪亚大陆城市形成与聚落体系研究
## ——政治中心、资源交换与边疆节点的历史空间组织

系统地理专题·历史人文地理｜修订稿 v0.3｜2026-10-26

# 摘要

本文考察卡拉迪亚城市与乡村聚落如何在迁徙、政治整合、资源生产和跨区域交换中形成差异化的空间关系。研究区分聚落起源、主权归属、政治中心性、经济职能与乡村联系，并比较沿海殖民城市、森林河谷市镇、北方河港、草原边缘聚落和南方干旱地域。材料表明，城市中心性至少通过三种机制形成：政治权力对定居和统治重心的重新组织；生产地与消费地之间的商品集散；边疆通道、河渡和军事需求所产生的节点功能。这些机制能够在同一城市叠加，也可能彼此分离。地点级供给记录进一步显示，城市腹地并非由距离自动决定：有的村庄向特定城市居民供粮，有的生产地向多个城镇或某类买方销售，有的资源被用于国家和军事目的，还有一些地点虽有生产记载，却没有明确买方。帝国中东部与东南的源级材料进一步表明，军马供给、矿产的国家用途、城市手工业原料交易与边境服务是不同的社会空间关系；地主的土地用途选择和地方群体的政治整合也参与塑造生产地域。现有证据支持多个尺度不一的局部交换关系，却不足以证明全大陆存在统一、连续且制度整合的城市市场体系。

**关键词：** 历史人文地理；城市形成；聚落体系；政治中心；城乡关系；市场腹地；边疆空间

# 一、引言：城市为何形成于此，又如何维持其中心性

城市的形成不能仅由港湾、河流、森林、草原或绿洲等自然条件解释。自然条件提供可供利用的空间机会，但不会自行组织移民、分配土地、建立安全秩序或创造稳定需求。相似的地理条件可以产生不同的聚落结果；同一城市也可能在不同历史阶段经历政治中心、商业节点和军事据点等功能的分离与重组。城市形成研究的关键，不只是识别地点，而是解释社会行动如何把地点转化为具有区域影响的聚落。

本文围绕三个问题展开：殖民迁徙、政治统治和城市文化起源是否必然重合？乡村生产在何种条件下构成城市腹地，商品交换又如何改变聚落关系？河谷、海岸、草原边缘和干旱通道中的城市与小型聚落，如何在不同生产方式和政治权力之间发挥中介作用？

本文的中心论点是：**卡拉迪亚的聚落体系不是由单一等级原则组织的静态城市网，而是由政治中心、生产地域、市场节点与交通控制点相互交叠而形成的历史空间结构。** 城市中心性取决于具体的社会关系，而非单由地理位置或主权身份决定。本文以城市沿革和地方地志检验这一论点，并将直接记载的交换关系与跨区域解释分开处理。

# 二、分析框架与证据层级

聚落体系至少包含五个彼此相关但不必一致的维度：形成过程（迁徙、殖民、征服、土地授予或市场聚集）、政治归属、经济与行政职能、乡村生产联系，以及这些联系的持续性。一座城市的文化起源不能直接说明其后来的统治者；政治中心迁移不能自动证明旧中心的贸易衰退；资源丰富也不能单独证明当地已经形成市场。

本文区分三种证据强度。地方地志明确记载生产者、商品和销售或供给对象时，可以确认具体的交换关系；城市沿革、区域叙述和政治记载可以支持聚落形成机制的解释，但未必证明具体交易；由多个个案归纳的区域模式则属于可反驳的综合解释。资源存在不等于商品生产，商品生产不等于销售，国家用途不必然等于市场交易。同一区域内的若干个案，也不能仅凭邻近关系合并成完整供应链。

本文材料包括城市沿革、区域地志与地点级生产叙述。不同文本的叙述尺度和时间指向并不相同；同一创作体系内的相关记载不作为相互独立的证词重复计数。文本版本差异用于确定具体叙述的适用范围，不直接解释为卡拉迪亚社会内部的年代变化。文本键、译名和版本校勘另见[研究过程与史料校勘日志](https://github.com/Nobody-zz/awake-calradia-research-atlas/blob/main/research/geo/03/HUM/CGEO-S-HUM-001-research-log-and-source-audit-2026-10-26.md)。

# 三、殖民迁徙与政治中心：沿海城市的功能分化

沙拉斯与帕拉汶德的沿革呈现了殖民定居和政治中心转移之间的关系。沙拉斯在卡拉德人的殖民记忆中占据早期海岸定居的重要位置；帕拉汶德则被称为卡拉狄乌斯建立的第二座重要殖民地，并在后来取代沙拉斯成为首都。其历史意义不在于排列城市的“年龄”，而在于殖民定居、政治中心与港口功能并未始终集中于同一地点。

首都迁移会重新配置统治活动、贵族交往与政治资源的地理重心，却不必然使原有港口或地方市场失去作用。沙拉斯后来的海务活动、贸易和贵族消费叙述，说明政治中心的转移不能直接等同于旧中心经济功能的终结。围城期间，沿海船民曾因城内高价而送粮入城；这一记载反映战争条件下的应急供给，而非平时的常态贸易，却显示港口交通在政治危机中可能成为城市维持生活的关键条件。

俄耳堤西亚进一步揭示了殖民文化与政治主权的错位。该城被记述为卡拉德人在珀拉斯海建立的早期殖民地，但其相当长时期受到古亚兹统治，后来才随共和国扩张而被纳入。殖民社群的文化记忆、实际统治权和后来的政治整合并非同一过程。因此，海岸聚落体系不能简单写成单一国家逐步扩张、并将沿岸城市纳入统一内部市场的线性历史；多主权并存、殖民社群与地方城市权力可以共同塑造海岸空间。

这些个案说明，城市起源、政治归属和经济功能必须分别考察。现有材料能够说明沙拉斯与帕拉汶德之间的政治中心转移，也能说明俄耳堤西亚的殖民记忆与早期统治者并不重合；但不足以复原迁都路线、人口变化、关税制度或港口贸易量。

# 四、资源腹地与地方市场：森林、河谷和城镇

东北森林地区呈现出不同于殖民港市的空间机制。毛皮、木材等物产分布于较广的资源地域，生产活动未必集中在城市附近。地方叙述将林区资源、外来商人收购与河谷城镇的商业功能联系起来，提示城镇的中心性可能来自它在分散生产者与远距离交换者之间承担的集散作用。

资源丰度本身不能解释城市兴起。森林产品只有在生产劳动、收购关系、运输条件和交换需求能够衔接时，才可能形成区域经济联系。现有毛皮材料涉及资源地域、猎捕地点、商人收购据点和城镇贸易功能，构成多层次的证据组；但它们尚未被逐笔交易记录连接成完整供应链。野蜜或沼铁即使在区域叙述中具有重要性，也不能在缺乏地点级生产者与买方信息时直接纳入某座城市的供给范围。

哈加德的地方叙述将多族群河谷物产与向南销售联系起来，说明河谷可能成为不同生产地域之间的交换节点。然而，“向南出售”没有给出唯一城市买方，也不能证明所有河谷物产均经由同一港口或同一制度转运。水系连通、运输活动和商品贸易相互关联，却仍须分别论证。

具体销售记录显示，生产地域的市场范围可能超出最近城市的近郊。安杜恩的地志记载村民经营森林并将木材出售给城镇；马雷汶的两版英文叙述都将木料销售对象指向多个沿海城镇。阿斯·卡瓦尔的溪床黏土交易则将生产者、原料和陶工买方直接联系起来，但该关系只见于相应版本的叙述。这些例子表明，村庄与城市之间可能存在多目的地、跨尺度的联系，而非每个村庄只服务于最近的一座城市。

森林—河谷地区更适合被解释为若干地方生产关系和交换节点的组合，而不是拥有统一贸易制度的封闭经济区。关键问题在于不同商品如何进入交换、哪些聚落承担收购和转运，以及地方权力如何影响生产者接近市场的条件。现有材料尚不足以确定统一的林地权属、收购合同、价格、税收或运输组织。

# 五、北方海岸与河港：多方向交换而非单一供应链

北方海岸的经济空间由海洋资源、河谷生产和内陆聚落共同构成，但材料呈现的是方向不同、组织方式各异的交换关系。诺德长船向南出售海象牙、鲸油和鱼类，说明海产进入远向交换；哈加德的河谷物产向南出售，则显示内陆资源也可能进入更广的市场范围。两类材料并未证明海产出口与河谷物产南售属于同一条连续供应链。

格雷蒂斯湾的季节性集市提供了另一种聚落形成线索：跨海商人先被集市吸引，地方首领随后筑墙、建厅并自称雅尔。在这一具体叙述中，市场活动先于地方权力强化。它说明交易集聚可能成为地方政治组织发展的条件之一，却不足以建立普遍的“市场先于城市”规律，也不能证明集市已经具有统一税制、港务机构或全年固定贸易。

生产与运输环节同样需要区分。雅斯克韦格的地志记载村民用牛力将木材拖至海岸用于造船，明确呈现畜力运输与造船用途之间的联系；斯温斯塔克的橡树林则被描述为北方造船木材的来源，但没有明确买方或运输路线。前者支持一个具体运输过程，后者主要支持资源与用途之间的关系。将两者合并为统一的造船供应制度，会超出材料所能证明的范围。

北方聚落体系应被理解为多个市场和资源关系的并置与局部交会。海上出口、季节集市、河谷资源南售、木材运输和城镇粮食供给，可能在某些节点发生联系，但目前不能证明它们已组成全年连续、统一管理的海陆贸易体系。研究重点应是识别不同商品、消费者和政治情境下的空间联系，而不是预先绘制一条推测性的全大陆航线。

# 六、草原边缘与军事生产：市场联系和国家需求

草原边缘的聚落关系受到农耕与牧业生计差异、移动人群、军事需求及政治控制的共同影响。帝国向东扩张的叙述指出，军队进入广阔草地后难以沿用原有农田供给方式，并通过草原边缘贸易城镇巩固控制。这提出了一个历史地理问题：边缘城镇既可能是不同生计方式之间的交换地点，也可能承担驻军、交通保护和政治控制职能；这些功能是否在同一地点、同一时期并存，仍须由具体材料判断。

马匹交易说明草原聚落可以在流动畜群与定居消费端之间发挥中介作用。喀拉罕的记载将从流动部落购马、当地繁育与向库赛特军队供马联系起来；柯希·阿吉克的基础版记载则描述当地人从东面游牧者购马，再转售给城镇中的库赛特贵族。两条链的买方不同：前者指向军队，后者指向城镇贵族。它们说明畜牧生产、流动人群和定居市场之间存在多种联系，却不证明两地属于同一采购制度、固定商路或长期持续的中介网络。

国家用途也不能直接等同于市场交易。伽伦戈利亚的银矿被联系到帝国铸造第纳尔的历史；涅俄科律斯的地主育马场则与向帝国骑兵供马相连。后者呈现生产与军事接收端的关系，前者主要说明资源与国家用途之间的联系。两者都提示政治权力能够影响地方资源的用途，但不能据此推断统一产权、税收、强制采购或收益分配制度。

东部高地与特美亚谷地的马匹生产进一步显示，军事需求可能与土地收益选择共同推动地方专业化。俄耳特拉的地志把东方草原种畜、育种与向帝国骑兵供马相连；涅俄科律斯记载地主在近期清林的土地上建立育马场并供马；埃戈斯卡则称地主把牧地转用于更有利可图的养马。前两者直接指明军事接收端，后者只说明土地用途和相对收益，三者不能合并为同一采购制度。更合理的判断是，部分生产地域与军需需求存在直接连接，而相邻或同类养马地仍可能面向其他市场。

东南边境的村庄还显示，国家关联不止于商品交付。厄瑞玻洛斯的一版地志记载村民把溪底黏土卖给达努提斯卡及附近城镇陶窑；另一版保留采黏土，却同时将其描述为纳入达努提斯卡辖区并负责监视林地袭扰者的边境村落。泰格瑞索斯的另一版叙述更明确：原先抗拒帝国权威的Eleftheroi群体后来获得达努提斯卡执政官授予的正式特许，以协助守边作为交换。这些案例支持一个有限的推论：边境空间可能通过地方生产、制度承认与防务服务共同整合；但只有泰格瑞索斯明确记载特许交换，不能将同一权利形式推广到厄瑞玻洛斯或整个帝国。

草原边缘城市的中心性不是自然分区边界的简单投影。它可能来自市场中介、军需接收、交通控制或这些功能的阶段性叠加。若要论证某一市场在主权更替后持续存在，需要分时期的生产者、买方和交易记载，不能只凭地点在不同政治叙述中反复出现。

# 七、干旱地域的定居与水土劳动：纳哈撒

纳哈撒的聚落分布受到水源可得性、洪泛地形、山口和干河谷的共同制约。水源分布不均，农业定居因而可能集中于绿洲、局部河漫滩和能够利用地下水或集雨的地点。但自然条件只是生产可能性的基础；水源如何取得和维护、土地如何投入耕作，以及产物是否进入城市市场，仍取决于劳动组织与社会关系。

艾兹贝特·纳胡勒的材料将蓄水池、井和山地集雨等多种水源与小麦种植相连，并明确说明粮食用于供养附近的Qasira。这支持一个地点级的乡村供粮关系，但不能证明Qasira全部或大部分粮食依赖该村，也不能由水源设施直接推断水权、税粮制度、劳动义务或交付数量。

洪泛农业、井水、蓄水池与坡面集雨应被视为不同的水土利用方式，而非统一灌溉体系的不同表现。达玛尔河附近的河漫滩生产可以说明局部洪泛环境支持耕作，却不能外推为整个干旱地域拥有稳定的灌溉河网。同样，绿洲可能兼有农业、商旅和政治功能，但三者的空间范围并不相同。没有明确买方的农业、渔业或矿业记载，应保留为地方生产证据，而不自动归入最近城市的腹地。

纳哈撒个案说明，自然条件能够限定生产机会，却不单独决定聚落等级和经济功能。要解释地方中心性，还需考察水土劳动、农业产出、交通节点和政治关系之间的实际联系；现有材料尚不足以复原这些关系的完整制度安排。

# 八、城市腹地：从同心圆模型转向社会关系

城市腹地不应被预设为围绕城市向外递减的同心圆。生产地与接收端之间的联系可能指向一座城市、多个城镇、特定职业群体、驻军或流动消费者；也可能只说明资源的国家用途，甚至只记录生产而没有买方。不同关系在空间尺度和组织方式上并不相同。

第一类是**明确指向城市居民或城市供给的关系**。拉尔纳克的地志记载当地农民种植谷物并卖给帕拉汶德市民；乔诺巴斯在相应版本的叙述中被明确联系到向奥莫尔供粮；艾兹贝特·纳胡勒的麦作与Qasira的粮食需求相连。这些例子表明，城市消费能够将乡村生产与城市生活直接联系起来。但接收端明确，不等于已经知道供给通过合同买卖、税粮交付还是其他机制完成。

第二类是**买方类别或市场范围明确，但终端地点不唯一的销售**。安杜恩向城镇销售木材，马雷汶向多个沿海城镇销售木料，基础版克莱格·班向巴旦尼亚城镇陶工出售黏土。这些材料说明生产地域的市场范围可能跨越单一城市近郊，但未提供固定路线、交易量、价格或各城镇所占份额。它们支持多目的地或类别性市场关系，而不是一张已经完整复原的区域贸易网络。

第三类是**由中介连接不同生产者和消费者的关系**。柯希·阿吉克的马匹转售、诺德商人在西比尔收购毛皮，以及哈加德向南销售河谷物产，都显示中介或集散节点可能把地方生产与更远市场联系起来。但这些个案的中介角色和买方尺度各异，不能据此推断存在统一商人组织。

第四类是**国家或军事用途关系**。涅俄科律斯向帝国骑兵供马、喀拉罕向库赛特军队供马，具有明确的军事接收端；伽伦戈利亚的银矿则与帝国铸币用途相连。这些材料表明政治权力可以塑造生产和资源利用方向，却不自动证明市场买卖、强制征调、产权安排或财政制度。

第五类是**生产存在但买方不明**。维尼拉在不同叙述中分别出现捕鱼与葡萄种植活动，均未明确买方；纳哈撒若干村庄的农作、渔业和矿业也不能仅凭邻近城镇而直接纳入其供给体系。正确判断是现有证据尚未确定商品的接收端，而非断言其从未进入市场。

远向销售、战时应急供给与市场节点形成也须单独处理。诺德长船南向销售海产，奥姆卡尼将腌制猪脂销往北方各地，沙拉斯围城期间出现因高价而送粮的活动，格雷蒂斯湾则有集市先于地方首领强化权力的叙述。它们分别涉及方向性出口、区域销售、非常态供给和市场聚集的政治后果，不构成同一条连续贸易链。

由此可得本文最重要的经验结论：**卡拉迪亚存在多个有史料支持的地方交换关系，但现有证据不足以将它们整合为统一的大陆市场体系。** 这一结论不是否定更广泛市场的可能性，而是指出城市腹地必须从实际生产者、商品、接收者和历史情境中重建，不能由邻近性、自然通道或政治边界直接推导。

# 九、聚落体系的历史机制及其可检验含义

上述比较支持三种相互交叠、但不能互相替代的城市形成机制。

第一是**迁徙与政治整合机制**。殖民定居和首都迁移改变政治中心的空间位置；殖民文化与主权的错位则说明城市身份可以先于或独立于国家整合而形成。

第二是**生产与交换的集散机制**。森林河谷、港市和草原边缘的部分城市，通过连接生产者、收购者和消费者形成区域中心性。其关键证据不是资源是否存在，而是商品是否被生产、如何流通、谁接收，以及这些关系是否在多个地点之间形成稳定联系。

第三是**通道控制与公共需求机制**。河渡、山口、海岸和边疆城镇可能因军事、运输或供给需求而获得超出其直接生产能力的地位。此类中心性可能具有政治性，但不能在没有证据时等同于统一行政管理或国家垄断。

三种机制可以在同一地点先后叠加，也可能长期分离。它们提出了可检验的问题：政治中心迁移后，原港口的交换功能是否延续？资源型城镇的市场范围是否随运输条件和地方权力变化？军事需求减弱后，边疆节点是否仍维持原有交换关系？现有材料为这些问题提供了研究起点，却不足以完成全面的历时重建。人口规模、市场半径、价格、货量、税收、土地权属和劳动合同，仍缺少足够的直接证据。

# 十、结论

卡拉迪亚的城市和乡村聚落并非由自然条件或政治疆界单独决定，而是在迁徙、政治整合、资源生产、市场交换和通道控制的交互作用下形成差异化的空间结构。沙拉斯与帕拉汶德显示政治中心与港口功能可以分离；俄耳堤西亚揭示殖民文化与主权归属并不必然同步；森林河谷、北方海岸和草原边缘个案则表明，城市中心性常由生产地、消费者和中介节点之间的具体关系构成。纳哈撒进一步说明，自然条件可以限制聚落和生产机会，却不能单独决定城市等级、市场范围或制度形态。

本文的两项主要结论是：其一，城市的历史地位应由形成过程、政治归属、经济职能和乡村联系分别解释，而不能用一个维度代替其他维度。其二，城市腹地是一种需要由商品和社会关系加以证明的历史联系，而不是从地理邻近或现行疆域自动推导出的区域边界。现有史料支持多种局部交换关系，却未能证明统一的大陆城市等级、固定市场半径或完整整合的贸易网络。

后续研究应从聚落类型罗列转向具体关系的历时重建：比较政治中心转移前后的城市职能，追踪资源生产与接收端之间的中介环节，并检验边疆和交通节点在不同政治条件下的持续性。帝国中东部与东南的比较显示，军需、矿产用途、陶业原料与边境服务可由不同机制组织；这为后续跨区域研究提供了可检验的比较维度。只有当生产者、商品、接收者、运输过程和制度条件得到更完整的历史证据支持时，才能进一步讨论这些地方网络是否构成更广泛的区域经济体系。
