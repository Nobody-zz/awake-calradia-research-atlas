## 一、当前结论

本轮完成了一个可以证伪的排除检验：**官方英文地志所锚定的达玛尔河走廊，不在已绘制的十条 river_* 场景路径的整体范围内。** 因此，不能把此前显示在图上的任一 river_* 线条直接认作达玛尔河。下一步应在原版 scene.xscene 的其余路径中筛选候选，并以原始 PHYM 数据复核。

原版资源审计记录：scene.xscene 的 Paths 容器共20条路径、686个控制点；前序审计将其中15条归为河流样式路径、5条归为海域／湖泊边界样式路径。此前地图只绘制名称以 river 开头的10条路径。其余路径的名称和几何不能从当前渲染图可靠还原。

### 2.2 十条 river_* 路径的范围排除

根据 [CGEO-MAP-RES-005](../90/EVD/CGEO-MAP-RES-005.md) 已归档的直接分析，十条显式绘制路径的总包围盒为：

- X：87.26—573.38 场景单位
- Y：255.84—535.89 场景单位

五个稳定达玛尔河文本锚点的原版聚落实体坐标来自官方 SandBox/ModuleData/settlements.xml：

| 地点 | 实体 ID | X | Y |
|---|---|---:|---:|
| Zalm | village_A7_4 | 390.254 | 97.643 |
| Mabwaz | village_A7_3 | 413.587 | 124.973 |
| Nahlan | village_A6_4 | 404.877 | 160.318 |
| Hamoshawat | village_A6_2 | 394.921 | 177.046 |
| Mijayit | village_A6_1 | 410.054 | 178.898 |

五个锚点的最高 Y 为178.898；十条 river_* 路径包围盒的最低 Y 为255.840。两者垂直间隔为：

\[255.840 - 178.898 = 76.942\]

因此，五个锚点全部位于这十条路径的整体包围盒之外。该结果足以排除“这十条 river_* 路径中的某条直接穿过五个稳定锚点走廊”这一解释；它不能排除其余十条路径、路径分支缺失、PHYM7 中存在无对应显式路径的河段，也不能据此命名某条候选路径。

## 三、当前最有价值的候选判断

在现有叠加图中，五个文本锚点靠近一个约位于 X=360—420、Y=0—220 的 PHYM7 灰色走廊；而十条已绘制 river_* 路径都位于 Y≥255.84 的整体范围内。结合 RES-001 对20条路径的分类，下一步优先检查**未被绘制的其他五条河流样式路径**。这只是基于空间范围与前序路径类型分类形成的候选集合；当前没有足够资料指出其中哪条就是达玛尔河。

不把 tigris、volga 或其他内部路径 ID 按名称联想直接等同于达玛尔河。内部 ID 只用于检索与排序；最终对应关系必须同时满足原始路径几何、PHYM7 分布、稳定聚落坐标和官方英文地志的空间顺序。

## 四、完成原始几何复核所需的最小输入

1. **原版 scene.xscene**：用于逐条提取20条路径的 ID、控制点与场景参数，首先解决候选 Path ID。
2. **原版 terrain.bin**：用于按 ZGR6RTRN 的 PHYM 解码规则恢复256个图块、四季 layer index，并从原始栅格精确提取 index 7。
3. 保留现有 SandBox.zip、已核验的聚落 CSV、河流叠加图和本轮坐标记录作交叉核验，不再要求重复上传这些派生材料。

若重新取得原始文件，必须先验证字节数与上述 SHA-256。通过校验后，按以下顺序执行：

- 解码 scene.xscene 中全部20条路径，不预先按名称过滤；
- 对每条路径计算与五个稳定锚点的最短点—线距离、与 PHYM7 栅格的覆盖率及沿线顺序；
- 从 terrain.bin 解码原始 PHYM7 并计算锚点到 layer-7 的精确栅格距离；
- 将候选路径的空间顺序与 Zalm → Mabwaz → Nahlan/Hamoshawat → Mijayit 的文本地理关系逐项比较；
- 如果没有任何路径同时满足这些条件，应保留“显式路径与达玛尔河未对应”的结论，不强行指认。

## 五、证据边界

- A 类：官方英文聚落地志、官方聚落实体 ID 与坐标。
- B 类：前序原始资源报告记录的路径数、控制点数与路径分类；本轮没有原始 scene.xscene 可重新读取。
- B 衍生类：从现存 PNG 重算的图像级 PHYM7 近邻结果及路径包围盒的可视化。
- 尚未完成：候选 Path ID 的直接识别、原始 PHYM index 7 的重新解码、河面几何和洪泛边界测绘。

**总判断：** 这轮将候选搜索范围从全部20条路径缩小到“未绘制的其他河流样式路径”，但没有给出未经证实的河流 ID。直接解析工作目前被原始二进制在当前环境中不可访问所阻断；恢复文件后可按第四节流程继续。
