# CGEO-MAP-RES-017｜《战帆》港口坐标证据分级与渲染图平移敏感性复核（v2.3）

2026-10-23；《卡拉迪亚大陆地理研究》地图测绘方法校勘。**状态：图像诊断工作论文；非海岸线定稿。**

## 摘要
RES-008 曾直接读取原始《战帆》`navmesh.bin`，在 radians/XYZ 欧拉变换候选模型下，用点在多边形测试验证 **29/29 town_port 和144/144 drop_point** 落在可航面；RES-012保留了29个港口的面ID和类型（CoastalSea 23、River 6）。RES-016 后来将这些坐标投至 RES-006 已渲染水域分类 PNG，只得到**1/29严格像素类别命中**。后一个结果只测试了**二次图像配准**，不能否定先前的原始Navmesh面检验。

本轮以原版 `CGEO-MAP-RES-006_战帆水域面类型.png`、RES-010聚落/港口坐标映射和 RES-012 `town_port_network_access.csv`复算，在渲染图上考察像素分类采样对平移的敏感性。

## 数据来源与证据级别
1. **原始解析，较高证据级别：** [RES-008](CGEO-MAP-RES-008.md) 对早先可读取的RNM1/LZ4/NMG9 Navmesh顶点与面多边形完成直接校验。XYZ/radians模型仍属于与编辑规范相容、未经引擎源码证明的工作模型。
2. **派生数据：** RES-012 的29个港口功能标记候选XY与面ID、面类别；[RES-011](CGEO-MAP-RES-011.md)的聚落锚点—水路锚点偏移。
3. **渲染图像：** RES-006 PNG 的 RGB 分类与根据图框刻度拟合的近似像素回标；RES-016 1/29由此而来，不是新的网格点在多边形验证。
4. **当前复核边界：** 本轮可访问档案包含官方settlements.xml压缩包、派生CSV、可复算脚本与渲染图，但未取得原始Navmesh/terrain二进制文件；不能声称独立复验游戏底层面内含关系。

## 方法
继承RES-016的像素回标 `pixel_x=56.25+1.10375*scene_x`、`pixel_y=1116.333−1.106667*scene_y`。以 RGB 欧氏差距小于12的River或CoastalSea色块为可辨类别；在原位比较零半径和5像素容差。随后在图像像素坐标两个方向 [-80,+80]、步长5像素的候选平移网格中搜索同类别邻域命中数量。所有平移**仅用于评价渲染图配准**；不得修改游戏场景坐标。

为减少把全样本最大值误判为准确标定的风险，采用随机种子20261023的五折留出检验；每次仅以训练样本选平移，再统计未参与拟合的港口命中。

## 结果

| 指标 | 数值 |
|---|---:|
| 港口数量 | 29 |
| RES-012已有类型 | River 6；CoastalSea 23 |
| 官方settlements.xml城镇位置—港口候选点位移 | 中位4.8982，范围3.0351—6.9575场景单位 |
| RES-016原回标严格RGB匹配 | **1/29** |
| 原回标按5像素邻域采样 | **4/29** |
| 全样本探索平移最大值 | **19/29** |
| 训练最大值所用像素平移 | X **+35**，图像Y **+65** |
| 按原图刻度粗略换算的表观平移 | scene X +31.71；scene Y -58.73；**不是实际地理修正** |
| 五折留出匹配合计 | **14/29** |
| 同一五折原位基线 | **4/29** |

五折训练所得平移分别为 (+35,+65)、(+30,+65)、(+35,+60)、(+35,+75)、(+35,+65)像素，留出匹配数3、3、3、3、2。结果提示二次图像间存在可能的系统性位移，远大于聚落—港口功能标记之间约5场景单位的典型偏移；但图像水域面宽大连通，搜索范围广，最佳平移存在样本过拟合，剩余15个留出样本未必对齐。因此**不得将这一诊断量当成新的官方坐标变换**。

## 学术结论及勘误
- RES-016的1/29应表述为“按所用图框模型，只有1个像素恰好命中声明的渲染类别”，**不得重述为28个港口实际位于陆地**。
- RES-008先前直接Navmesh的29/29水域面内含结论应保留，但明确标记对变换模型的依赖；不能用较低证据级别的PNG采样直接推翻。
- `settlements.xml`聚落位置与`scene.xscene`港口标记不同。两类地理对象各自保留坐标，禁止通过将城镇点移动到海边来“配准”。
- RES-005的HGHT高程颜色、RES-006的Navmesh水域类别与真实海岸线彼此不同；只有恢复原始地形/水面几何、验证版本专属坐标轴后才可绘制最终海陆分布图。
- 原版与《战帆》资料保持两套分离，不能共享未经验证的像素坐标变换。
