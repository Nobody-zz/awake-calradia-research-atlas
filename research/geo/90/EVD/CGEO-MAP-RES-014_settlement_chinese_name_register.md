# CGEO-MAP-RES-014｜聚落中文地名规范表

版本：v1.2｜2026-10-25

## 判定规则

1. `settlements.xml` 中的英文名称与实体 ID 是地理对象主键；中文名必须按同一实体 ID 核对。
2. 基础版53座城镇的中文名，以项目上传的官方《游戏百科中文文本》`encyclopedia-zh-cn.md` 中的 `### 中文名 (town_ID)` 标题为准。该导出文件说明其名称来自 Native 的 `std_common_strings_xml`；当前归档的 `Native.zip` 未包含该原始简中名称表，因此本轮确认的是“官方百科导出标题与实体ID匹配”，不声称已从压缩包重新提取每个独立名称键。
3. `SandBox`／`NavalDLC` 的独立 `Settlements.Settlement.name.*` 中文键若存在，按该键与同版本 `settlements.xml` 的英文名、实体ID逐一核验。若独立名称键缺失、但官方简中地志正文中出现中文称谓，只能登记为“官方地志正文用名”，不能提升为独立名称键证据。
4. 模块版本间英文实体名或ID映射变化时，必须分别登记；若中文键沿用旧值，应标为本地化映射／同步异常，不把旧值冒充新版英文名的已核定译名。
5. 对于当前证据确实不足的地理专名，保留英文主名与实体ID，标注“研究暂译”或“来源待核”，不凭发音补造官方译名。

## 版本映射重点

- **Kohi Ajik／Tismil**：SandBox基础版的 `castle_village_K7_2` 为Kohi Ajik（中文名键“柯希·阿吉克”），`village_K2_2` 为Tismil（“帖斯密勒”）。NavalDLC英文实体名在这两个ID间互换，但简中名称键仍沿用旧值。因此DLC中不能把这两项旧中文键值直接视为已正确对应新版英文实体的译名。
- **Etirfurd／Echarfurd**：`village_V1_2` 的英文名在NavalDLC由Etirfurd改为Echarfurd，而两版中文名称键仍为“埃蒂尔菲德”。应记录为中文键沿用旧值，不能声称中文名称已随英文名称完成更新。
- **NavalDLC新增诺德聚落**：例如瓦尔维克、格雷蒂斯湾、特龙德拉格、哈加德、雅斯克韦格、瓦格纳菲特、斯温斯塔克、达格比、比约伦比尔等，已在DLC简中名称表中找到独立名称键。以这些同键结果为准，不采用早期开发日志人工译稿覆盖当前游戏键值。
- **城堡附属聚落**：乌瑟莱姆、弗林托格、福林、克莱格·班等中文形式在官方简中地志正文中可见，但当前归档没有为这些条目复现独立名称键；应明确证据类型，不把正文用名说成独立名称键。

## 解释与限制

名称来自官方百科导出，不代表当前归档已经保存了对应的全部原始Native名称语言表。名称键是否直接存在、官方百科标题如何显示、官方地志正文如何称呼，三者分别记录。名称核验不替代实体位置、文本键映射或版本差异审计。
