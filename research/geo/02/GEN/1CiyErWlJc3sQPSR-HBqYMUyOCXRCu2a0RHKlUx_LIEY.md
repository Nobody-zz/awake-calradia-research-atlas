# CGEO-O-GEN-001｜卡拉迪亚大陆地理总论

## 研究工作底稿 · 资料准备中 · 非正式论文稿 · 2026-10-22

# 一、研究任务

将卡拉迪亚大陆作为一个有内部空间联系与地域差异的地理整体研究，解释其山地、海陆、水系、自然景观与人类活动之间的空间关系，不按阵营依次介绍设定。  
研究对象为《骑马与砍杀Ⅱ：霸主》原版及《War Sails》DLC构成的官方地理资料。两套地图差异须标注，但地图版本史仅作为方法问题处理。

# 二、需要实证回答的核心问题

1．卡拉迪亚大陆的空间范围、海陆形态和已知边界如何确定？是否存在无法从官方资料确认的边界或比例？  
2．主要山地、平原、草原、森林地带与沙漠如何组合？应按自然地理特征而非政权疆界划分哪些地理板块？  
3．河流、湖泊与近海如何组织大陆内部的水文与交通联系？哪些联系仅是游戏导航机制而非世界内部水文事实？  
4．不同区域的气候、植被与土地利用是否具有可解释的地域分异？证据不足时应怎样表达不确定性？  
5．聚落、农牧业和贸易通路与地形、水源、海岸之间存在怎样的空间对应关系？

# 三、拟论证结构（待随证据修订）

引言：研究对象、资料范围与地理学问题。  
第一节：卡拉迪亚的地理位置、范围及海陆格局。  
第二节：主要地形单元和大陆自然地理骨架。  
第三节：河流、湖泊、海岸与区域间连通性。  
第四节：气候、植被与自然地域差异。  
第五节：聚落、交通与历史经济活动的地理基础。  
第六节：自然地理区域划分及版本资料造成的认识限制。  
结论：对大陆整体地理结构形成可验证的综合认识。

# 四、已核实的官方资料起点

GEO-EVD-0001：TaleWorlds《Dev Blog: Setting Sail》（2025-07-03）明确描述Nordvyg地势崎岖、山地与森林谷地、冬季寒冷。可作为北方地区初步自然地理证据，但不能推算温度、降水或海拔。  
GEO-EVD-0002：同一资料明确将Beinland描述为Nordvyg以西隔海相望的岛屿；将Jumne河地区描述为Nordvyg东部，河流向南延伸并联系库赛特方向与Laconis、Tanaesis湖区。需在指定正式游戏版本中检核空间细节。  
GEO-EVD-0003：TaleWorlds《War Sails Q\&A \#3》（2025-07-10）明确确认原版与DLC采用两套世界地图。该事实限制跨版本混用，但不直接证明虚构世界内部地理变化。  
GEO-EVD-0004：官方War Sails世界地图技术文档中的海域、河流与湖泊导航类型，属于机制说明，不能直接当作自然地理的通航条件。

# 五、证据空缺与首批核验工作

尚需核对：大陆原版与DLC选定构建版本、主要海陆形态、山地与平原空间分布、各主要水系及地理实体名称的原文依据。  
尚需核对：官方百科或文化设定中的各自然地域描述；明确直接史料与地图目视观察之间的差别。  
不可预先断言：大陆总面积、真实纬度与经度、山脉海拔、河流精确长度、未获证实的气候成因、官方未确认的流域边界。  
正式论文必须以完成的证据链为根据；本底稿只是研究准备，不应视为论文成果。
