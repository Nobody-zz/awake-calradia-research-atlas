# 卡拉迪亚研究档案

本仓库保存 AWAKE 项目的卡拉迪亚历史与地理研究文档快照，以及研究档案网站的静态源码。

- 网站入口：[site/index.html](site/index.html)
- 研究文档索引：[research/README.md](research/README.md)

## EdgeOne Pages 部署

从 GitHub 导入本仓库，选择静态站点，将输出目录设为 `site`；当前版本无构建命令。请保持仓库私有，并仅授权 EdgeOne 读取此仓库。

## 后续研究维护约定

- 本仓库是 AWAKE 卡拉迪亚历史与地理研究成果的正式版本库。后续形成可复用的研究结论、论文修订、证据审计、地图分析或研究规范时，应更新相应的 `research/` 文档，并同步维护 `research/README.md` 索引。
- 不把聊天中的临时答复视为已归档成果；需要长期保留的成果应实际写入仓库，并以提交记录追踪修改。
- 研究时优先核查项目资料库、对话中已有的原始文件和官方游戏资料，不应仅因资料不在 Google Drive 中就要求重新提供。无法访问或确已过期的文件应明确说明，再请求补传。
- 严格区分游戏内原始证据、官方文本、二手资料、研究推断与尚未证实的假说；保留来源、版本、路径及不确定性说明，不以推断冒充原始证据。
- 仓库归档研究笔记、引用、索引、可复核的分析结果和必要的元数据；不提交未经许可的游戏二进制文件或整包受版权保护的原始资源。
- 网站静态副本、研究 Markdown 快照与 Google Docs 原件之间目前不会自动同步。每次更新后应检查相关索引与页面链接，避免误称已同步。
