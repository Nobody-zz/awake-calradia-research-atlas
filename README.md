# 卡拉迪亚研究档案

本仓库保存 AWAKE 项目的卡拉迪亚历史与地理研究文档快照，以及研究档案网站的静态源码。

- 网站入口：[site/index.html](site/index.html)
- 研究文档索引：[research/README.md](research/README.md)

## EdgeOne Pages 部署

从 GitHub 导入本仓库，选择静态站点，将输出目录设为 `site`；当前版本无构建命令。请保持仓库私有，并仅授权 EdgeOne 读取此仓库。

## 当前边界

网站是从既有 Sites 站点复制的静态版本，页面内的研究资料链接仍指向 Google Docs，尚未改为本站文档链接。研究文档为 2026-10-22 从 Google Drive 导出的 Markdown 快照；后续云盘修订不会自动同步。仅部署静态页面不提供登录、上传或在线编辑功能。
